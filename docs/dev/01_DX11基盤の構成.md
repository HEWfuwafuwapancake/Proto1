# DX11 基盤の構成

授業（DX21）のひな形をもとに、3D ゲームを作り始められるようにした土台です（`HEW2026GitTest` から、水のレイトレーシングを除いて持ってきたもの）。
起動すると、空に浮かぶ緑の浮島・その上に立つプレイヤー（赤いカプセル）とダミーの敵3体（青いカプセル）と、画面表示（上に残り秒数・左上にスコア・ダミーの頭の上にダメージ%）が出ます。
カメラは敵へロックオンする TPS カメラです（左右の弾きで対象を切り替え、角度・距離・注視点を別々のバネで追う。つかんでいる間・敵がいないときは自由に回せる）。

浮島・プレイヤー・ダミーは仮の形です。企画書（`docs/plan/`）に合わせて作り変えていきます。

## 操作
| 操作（キーボード＋マウス） | パッド（DUALSHOCK 4） | 動き |
|---|---|---|
| W / A / S / D | 左スティック | 歩く（前 = カメラが向いている向き） |
| Space | × | ジャンプ |
| ← → / マウスを素早く左右へ | 右スティックを左右へ弾く | ロックオンする敵を、指定側の次の敵へ切り替える |
| マウスの上下 / ↑ ↓ | 右スティックの上下 | カメラを上下に回す。敵がいないとき・つかんでいる間は左右も自由に回せる |
| 左クリック / 右クリック | L1 / R1 | 左右の触腕（伸ばしてつかむ／もう一度で投げる） |
| R | OPTIONS | やり直し（いつでも。制限時間・スコア・ダミーが最初に戻る） |
| V | SHARE | 振動の ON / OFF（起動したときは OFF。ON にすると短く振動して知らせる。今の状態はタイトルバーに出る） |
| Tab | — | マウスのロック（カーソルを隠して見回す）の ON / OFF |
| ESC | — | 終了 |

**今はマウス操作を止めています**（2026-10-24、管理者の指示。カーソルを取られないように）。マウスのロックをしないので、
マウスでカメラを回す・ターゲットを切り替えることと、Tab は効きません（左右クリックの触腕は使えます）。
戻すときは `main.cpp` の `WM_ACTIVATE` の `MouseSetLock` と、`Update` の Tab の3行のコメントを外します。
戻したときは、ウィンドウを選ぶと自動でマウスがロックされ（カーソルが消える）、ほかのウィンドウに切り替えたときや終了確認が出たときは自動でロックが外れます。
浮島から落ちて場外に出ると、浮島の真ん中に戻ります。
ダミーにぶつかると押せます。押して浮島から落とすと、2 秒後に最初の場所に 0% で戻ります（Debug ビルドでは出力ウィンドウに「ダミー〇：場外」「復活」と出る）。
触腕で敵をつかむと手元へ引き寄せ、同じボタンをもう一度押すとカメラの左右の向きへ水平に投げます。保持は3秒で解除され、投げると12%加算します。F1の仮攻撃は削除しました。

| `src/input/` | キーボード・マウス・パッド、入力を「行動」に変える仕組み |

## 腕の共通の仕組み・腕の足し方（No.35）

- `src/game/arm.h / .cpp` は左右の装備を持ち、`ARM_TABLE` から各腕の初期化・終了・片手のリセット／更新／描画・動作中／保持中の判定を呼ぶ。肩の位置・左右と保持中の色・モデル1個の配置・右手の X の鏡写しもここで共通にする。
- `src/physics/armcalc.h / .cpp` は使える腕の巡回と直接選択（DirectX なし）。`nullptr` の種類は選べない。十字キー ← → で左手、□ ○ で右手を巡回し、1〜6／Shift＋1〜6 で左手／右手を直接選ぶ。装備はタイトルバーに出す。
- `ArmUpdate(MatchIsPlaying())` はカメラとキャラの向きの更新後に毎フレーム呼ぶ。装備切り替えは時間切れ後も受け付け、腕の更新は試合中だけ左→右の順。切り替える手は今の腕を待機に戻してから付けかえる（敵はダメージなしで離す）。`ArmReset` は装備を変えない。
- 腕を足すときは `src/game/arm_〇〇.cpp` で `arm.h` の `ARM_FUNCTIONS` の全7項目を実装・定義し、`arm.cpp` の `ARM_TABLE` の該当行をその表へのポインターに置き換える。No.36 なら `ARM_GRAPPLE_FUNCTIONS`。ほかの腕のファイルは変更不要。新しいファイルのプロジェクト登録と、DirectX なしの計算・テストも追加する。

## グラップリング（No.36）

- `src/game/arm_grapple.cpp` の `ARM_GRAPPLE_FUNCTIONS` を `ARM_TABLE` に登録する。2 / Shift＋2 または既存の装備切り替えで使う。再入力で解除し、左右とも刺さった場合は後の手へ乗りかえる。敵の保持は取らない。
- `src/physics/grapplecalc.h / .cpp` は撃つ向き・飛行区間の敵優先の命中判定・引っぱり・ふちの内側への着地点・モデルの点を計算する（DirectX なし）。撃つ向き（`GrappleCalcAim`）は、ターゲットがいれば上下も含めて体の中心へ（浮島の下から撃っても浮島に刺さる）、いなければ触腕と同じ画面の正面へ水平に。引っぱり中は `PlayerSetPulled(true)` で通常物理を止め、復活・解除で戻す。
- 付け根とフックは左手を X 鏡写しにし、鏡写しなしは +90°、鏡写しありは -90° の `ArmCalcRollAxes` で肩の箱を下へひねる。`ArmDrawPiece` の省略時のひねりは 0。ワイヤーは既存の円柱メッシュを使う `ShapeDrawCylinder` で描く。
- モデルの点は OBJ 読み込み後と同じ左手系（元の Maya 座標の Z を反転済み）を `GrappleCalcModelPoint` に渡す。モデルの読み込みと同じ X 鏡写し・ひねりを出口とフックの取付位置にも使う。

## 新しいオブジェクトを足すとき
`player.cpp` をコピーして作るのがいちばん早いです。

1. `〇〇Initialize / Finalize / Update / Draw` の4つの関数を作る
2. `main.cpp` の `Initialize`・`Finalize`・`Update`・`Draw` から呼ぶ
3. 箱・球・カプセルの仮の形なら、`Draw` で `ShapeDrawBox` / `ShapeDrawSphere` / `ShapeDrawCapsule`（`render/shape.h`）を呼ぶだけで描ける
   - ほかの形を自分で描くときは、`shape.cpp` のように次の順番で設定してから描く：
     `Shader_SetWorldMatrix(...)`（拡大縮小 → 回転 → 移動 の順に掛ける）→ `Shader_SetMaterial(...)`（色）→ 頂点バッファ（とインデックスバッファ）をセットして `Draw` / `DrawIndexed`
4. 動きの計算（当たり判定・速さなど）は `src/physics/` に DirectX を使わないファイルとして分け、単体テストする（`playercalc` が見本）
5. ファイルを Visual Studio のプロジェクトに追加する（`.vcxproj` が変わるので一緒にコミット）
6. ヘッダーの関数には Doxygen 形式（`/// @brief`）の日本語コメントを付ける

物を浮島の上に置きたいときは、`StageGet().TopY`（浮島の上の面の高さ）を y に入れます。浮島の範囲の中かは `StageCalcIsOnPlatform` で調べます。

## プレイヤーとカメラ
- `main.cpp` の `Update` で、`ActionUpdate` → `StageUpdate` → `PlayerUpdate` → `DummyUpdate` → `CameraUpdate` → `PlayerUpdateFacing` → `ArmUpdate` → `MatchUpdate` の順に呼ぶ（時間切れのあとは、プレイヤー・ダミー・向き・腕の動きの更新を飛ばし、装備切り替えは受け付ける）（ダミーは動いたあとのプレイヤーに押され、カメラはそのあとのプレイヤーを追いかける）。
- ダミーの体の動き（重力・着地）は、プレイヤーと同じ `PlayerCalcStep` に「歩かない・ジャンプしない」を渡して動かしている。
- プレイヤーとダミーの体は、足元から作った縦のカプセル（`DummyCalcBodyCapsule`）どうしで当たり判定をする。横から重なったらダミーだけを横に押す（プレイヤーは押し戻されない）。真上から乗ったときはプレイヤーを押し上げる。
- プレイヤーの移動の向きは、カメラの左右の向き（`CameraGetYaw()`）で決める。W（左スティックを上）で、カメラが向いている向きへ歩く。
- キャラの左右の向きは `PlayerGetYaw()`。ターゲットがいればターゲットへ、いなければ歩く方向へ `TURN_SPEED` の上限つきで回る。対象も移動もなければ最後の向きのまま。腕のボタンを押した瞬間、または `ArmIsActive()`（触腕なら伸長・保持・収縮中）が true の間は、更新後のカメラの正面へ即座に向く。肩の球はキャラの向きで置く。No.30 の伸長方向は下の「触腕」を参照。投げる方向はカメラの正面へ水平にする。
- 動きの計算は `PlayerCalcStep`（`physics/playercalc.h`）：横の速度 → ジャンプ（立っているときだけ）→ 重力 → 着地（浮島の上の面を上から通り過ぎたときだけ）。浮島の横の面とはぶつからない。
- カメラ（No.29 のバネと No.33 のロックオン）は、毎フレーム次の順に動く（計算は `physics/cameracalc.h`）。
  - 最初に敵の生存・場外・保持状態を調べる。開幕・やり直し・対象が消えたときは `CameraCalcPickFocus` で正面に最も近い敵（全周・距離無制限）を選ぶ。左右の弾きは `CameraCalcNextTarget` で対象への向きを基準に指定側の最小角を選ぶ。保持中は対象を退避して自由カメラへ、解放後は退避した敵、選べなければ正面の敵へ戻る。`CameraGetTarget()` はロック中のダミー番号、なし・保持中は-1。
  - ロックオン中は、以下の自由カメラの手順1の左右角を敵への水平角に、手順3の注視点の目標を `CameraCalcFocusPoint` に置き換える。上下は手動。切り替え後 `SWITCH_TIME` の間は角度のバネに `SWITCH_SMOOTH_TIME` を使い、速度を持ち越す。ジャンプ中の接地高さの保持は共通。
  - 対象がいないとき・保持中は次の自由カメラとして動く。
  1. 手動入力を左右・上下の目標角度へ足す（上下は -35°〜0°）。試合中は横入力に比例して左右の目標角度を回す（sway）。手動操作後は `MANUAL_PAUSE` 秒止める
  2. 左右・上下の角度を別々の臨界減衰バネ（`CameraCalcSmoothDampAngle` / `CameraCalcSmoothDamp`）で追う。速度は呼ぶ側で値ごとに保持する
  3. 注視点の XZ は `LOOK_DEADZONE` を超えた分だけ目標を動かす。Y は `PlayerIsOnGround()` で最後に立っていた足元＋頭の高さを記憶し、ジャンプ中は変えない。足元が浮島の上面より下へ落ちたら落下を追う。XZ・Y を別のバネで追う
  4. 注視点からカメラへの線が浮島にぶつかるなら、ぶつかる手前（面から `STAGE_MARGIN`）まですぐ近づける（`CameraCalcClipToStage`）。離れるときだけ距離のバネで戻す
  5. 追った角度・距離と注視点から `CameraCalcOrbitPosition` で位置を出す。復活・やり直しではバネを使わず目標へ合わせ、速度をすべて0にする
- カメラは浮島としかぶつからない。ダミーなどは通り抜けて見える。

## 描画の順番（`main.cpp` の `Draw`）
1. `Clear()` で画面と深度バッファを消す
2. **3D**：`SetDepthEnable(true)` → `CameraDraw()` → ライトON → 浮島・プレイヤーを描く
3. **2D（UI）**：`SetDepthEnable(false)` → ライトOFF → `HudDraw()`（描いた順に上に重なる）
4. `Present()` で画面に出す（垂直同期あり。`dx11.cpp` の `VSYNC` で切り替えられる）

## メインループ（`main.cpp` の `WinMain`）
- `Update` と `Draw` は **1秒に60回**（17・17・16ミリ秒の間隔を繰り返す）。待っている間は `Sleep(1)` で休むので、CPU をほとんど使わない
- 来ているウィンドウメッセージ（マウスの移動など）は、毎回全部処理してからフレームを進める
- **タイトルバーに FPS** が出る。60 より下がっていたら、処理が重くて間に合っていない
  （1フレームの秒数は 1/60 秒で固定しているので、FPS が下がるとゲーム全体がゆっくりになる）
- **垂直同期**（`dx11.cpp` の `VSYNC`）：モニターの書き換えに合わせて表示するので、画面のちらつき（ティアリング）が出ない

## 時間の使い方（`src/core/gametime.h`）
- `main.cpp` の `Update` の最初で `GameTimeUpdate()` を呼び、時間を1フレーム分進める。
- 動きは **「1秒にどれだけ進むか × `GameTimeGetDeltaTime()`」** で書く（例：`playercalc.cpp` の移動。`body.X += body.VelocityX * dt`）。
  こう書いておくと、`GameTimeSetScale(0.0f)` で時間を止めたとき（ヒットストップ）に動きも止まる。
- 1フレームの秒数は 1/60 秒で固定（実際にかかった時間ではない）。同じ操作で毎回同じ結果になり、吹っ飛びなどの計算が安定する。
- 「○秒たったら」は `TIMER` を使う：`TimerStart(timer, 90.0f)` → 毎フレーム `TimerUpdate(timer, GameTimeGetDeltaTime())` → `TimerIsFinished(timer)`。
- カメラを回す速さ（矢印キー・右スティック）も「1秒に何度 × dt」。マウスは動かした量そのまま（dt を掛けない）。
  そのため、`GameTimeSetScale(0.0f)` で時間を止めると、矢印キーと右スティックでは回らなくなる（マウスでは回る）。

## 入力の使い方（`src/input/action.h`）
- ゲームの側は、キーやボタンではなく **行動** を見る：`ActionIsTrigger(ACTION_ARM_LEFT)`（左の触腕を押した瞬間）、`ActionGetMove()`（移動の向き）など。
  キーボードでもパッド（DUALSHOCK 4）でも同じように動く。

## 当たり判定の使い方（`src/physics/collision.h`）
- 形は3つ：`SPHERE`（中心・半径）、`CAPSULE`（線分の両端・半径。プレイヤー・ダミーは縦、触腕は斜め）、`BOX`（向きなしの直方体。浮島）。
- `CollisionSphereSphere` / `CollisionSphereCapsule` / `CollisionCapsuleCapsule` / `CollisionSphereBox` は `HIT_RESULT` を返す。
  `Hit` が true なら、1つ目の形を `Normal` の向きに `Depth` だけ動かすと離れる（重ならないように押し出すときに使う）。ちょうど触れているだけなら `Hit` は false。
- 攻撃（触腕など）は、始めるときに `HitRecordClear`、当たったら `HitRecordTryAdd(record, 相手の番号)` が true のときだけダメージや吹っ飛びを与える（同じ攻撃で2回当たらない）。

## 触腕（No.13）
- `src/game/tentacle.h / .cpp`：`arm.cpp` から渡される片手の入力、敵との連携、OBJ をつないで揺らす描画（読み込み失敗時は球）。最大長8、伸長24/秒、収縮30/秒、保持3秒、投げ12%・強さ2を調整用定数で管理する。パッドの振動（伸びる間は最大・つかむ・投げる）もここから `PadRumble` で出す。
- `src/physics/tentaclecalc.h / .cpp`：待機・伸長・保持・収縮、命中順、時間切れ、浮島との接触を DirectX なしで計算する。`TentacleCalcExtendRatio` は伸長中の伸びた割合（0〜1）。
- No.30 の伸長方向は、押した瞬間の `CameraGetTarget()` があれば各肩から対象カプセルの中心へ、なければカメラ正面へ水平に固定する。`TentacleCalcAim` で高さを除いて正規化し、水平距離がほぼ0ならカメラ正面を使う。対象が遠くても向けるが最大長8は変わらず、伸長中は追尾しない。投げる方向は再入力時の `CameraGetYaw()` から作る水平の向きを使う。
- 左腕の後に右腕を処理し、`DummyGrab` の保持状態で二重つかみを防ぐ。`HIT_RECORD` は1回の伸長ごとにリセットする。
- `DummyUpdate` は保持中の通常物理を止める。`TentacleUpdateHand` はカメラ更新後に保持位置を決め、`DummyMoveHeld` で反映する。
- プレイヤー復活を `PlayerDidRespawn()` で検出して両腕を解除する。敵は元の位置で離し、復活先へ運ばない。
- 投げは `DummyRelease` → `DummyHit` でダメージ・速さを計算し、`KnockbackCalcDirectedVelocity` で上下を含む方向へ飛ばす。通常攻撃の固定角の計算は維持する。
- 最大距離または浮島に達した空の腕は戻る。保持する敵は半径・半高で拡張した浮島の箱を越えない位置に止める。

## 試合の流れ（No.14）
- `src/game/match.h / .cpp`：やり直しの入力、触腕・プレイヤー・ダミー・カメラの初期化の呼び出し。`src/physics/matchcalc.h / .cpp`：得点・時間・状態の計算（DirectX なし）。
- 得点は `DummyGetTotalOutCount()` が**前のフレームより増えた分**。同じフレームに2体落ちれば +2。時間切れと同じフレームの場外も入る。時間切れのあとは増えない。プレイヤーが落ちても減点しない。
- 時間切れ：`ArmReset()`（つかんでいる敵を離す）→ 状態が「時間切れ」→ 次のフレームから、プレイヤー・ダミー・腕の動きが止まる（カメラは回せる。装備切り替えは受け付ける）。
- やり直し（OPTIONS / R。いつでも）：`ArmReset` → `PlayerInitialize` → `DummyInitialize`（場外の回数も 0）→ `CameraInitialize` → `MatchInitialize`（制限時間と得点を戻す）の順。`GameTime` と装備は戻さない。
- 残り時間・スコアは画面に出る（下の「画面表示（No.15）」）。タイトルバーは FPS・左右の装備・振動のオン／オフ。Debug では出力ウィンドウにも得点・時間切れ・やり直し・装備の変更が出る。

## ロックオンの計算（No.33）

- `cameracalc` に中央の敵の選択・最短角の回転・プレイヤー全身が画面に残る視点の上限をまとめる。DirectX は使わない。
- `CameraCalcPickFocus` / `NextTarget` / `YawTo` / `FocusPoint` と単体テストを使う。`ArmIsHolding()` で自由カメラへの切り替えを決める。キャラの回転は No.32 で共通にした `core/mathutil.h` の `TurnYaw` を `PlayerCalcFacing` から使う。
