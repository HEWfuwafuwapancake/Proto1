# DX11 基盤の構成

授業（DX21）のひな形をもとに、3D ゲームを作り始められるようにした土台です（`HEW2026GitTest` から、水のレイトレーシングを除いて持ってきたもの）。
起動すると、丘に囲まれた砂のくぼ地・その上で回る立方体・左上の半透明パネル（2D）が表示されます。
カメラはマウスとキーボードでワールドの中を自由に動けます。

地形・カメラ・立方体・2D パネルは「動く土台」としてのサンプルです。企画書（`docs/plan/`）に合わせて作り変えてください。

## 操作
| 操作 | 動き |
|---|---|
| マウス | 見回す |
| W / A / S / D | 前・左・後ろ・右に移動 |
| Space / Ctrl | 上昇 / 下降 |
| Shift（押しながら） | 速く移動 |
| ← → ↑ ↓ | キーボードで見回す |
| Tab | マウスのロック（カーソルを隠して見回す）の ON / OFF |
| ESC | 終了 |

ウィンドウを選ぶと、自動でマウスがロックされます（カーソルが消えます）。
ほかのウィンドウに切り替えたときや、終了確認が出たときは自動でロックが外れます。

### カメラの感度・速さを変える
`camera.cpp` の上のほう（「調整用の値」）にまとまっています。

| 値 | 意味 | 初期値 |
|---|---|---|
| `MOUSE_SENSITIVITY` | **マウス感度**。大きいほど速く回る（0.001f〜0.005f くらいが目安） | `0.00125f` |
| `MOUSE_INVERT_Y` | `true` でマウスの上下を逆にする | `false` |
| `KEY_ROTATE_SPEED` | 矢印キーで回る速さ | 2° / フレーム |
| `MOVE_SPEED` | 移動の速さ | `0.15f` / フレーム |
| `RUN_MULTIPLIER` | Shift を押したときの速さの倍率 | `3.0f` |

## 新しいオブジェクトを足すとき
`cube.cpp` をコピーして作るのがいちばん早いです。

1. `〇〇Initialize / Finalize / Update / Draw` の4つの関数を作る
2. `main.cpp` の `Initialize`・`Finalize`・`Update`・`Draw` から呼ぶ
3. `Draw` では次の順番で設定してから描く
   - `Shader_SetWorldMatrix(...)` … 位置・回転・大きさ（拡大縮小 → 回転 → 移動 の順に掛ける）
   - `Shader_SetMaterial(...)` … 色
   - 頂点バッファ（とインデックスバッファ）をセットして `Draw` / `DrawIndexed`
4. ファイルを Visual Studio のプロジェクトに追加する（`.vcxproj` が変わるので一緒にコミット）
5. ヘッダーの関数には Doxygen 形式（`/// @brief`）の日本語コメントを付ける

物を地面の上に置きたいときは、`FieldGetHeight(x, z)` で高さを調べて y に入れます。

## カメラの当たり判定
- カメラは半径 `COLLISION_RADIUS`（`camera.cpp`）の球として扱い、立方体とぶつかる。
- `CubePushOutSphere(center, radius)`（`cube.cpp`）：球が立方体と重なっていたら、外へ押し出す。
  立方体の回転と大きさ（軸ごとに違ってもよい）を含めて、箱の形そのもので判定する。
- カメラは「動かす → 重なっていたら押し出す」の順で動く。押し出す向きは面に垂直なので、斜めに当たると面に沿って滑る。
  1回に半径より長く動くときは何回かに分けて動かすので、走っても（Shift）すり抜けない。
  動いていないときも毎フレーム押し出すので、回転してきた立方体にめり込んだままにならない。
- 押し出しのあとに、ワールドの端・地面の制限をかける（`camera.cpp` の `ResolvePosition`）。
  傾いた立方体の底と地面にはさまれて、制限が押し出しを取り消したときは、横（立方体の中心から離れる向き）にずらして抜ける。
- ぶつかる物を増やすときは、その物にも同じような「押し出す関数」を作り、`camera.cpp` の移動のループの中で呼ぶ。

## 描画の順番（`main.cpp` の `Draw`）
1. `Clear()` で画面と深度バッファを消す
2. **3D**：`SetDepthEnable(true)` → `CameraDraw()` → ライトON → 地形・立方体を描く
3. **2D（UI）**：`SetDepthEnable(false)` → ライトOFF → 2Dを描く（描いた順に上に重なる）
4. `Present()` で画面に出す（垂直同期あり。`dx11.cpp` の `VSYNC` で切り替えられる）

## メインループ（`main.cpp` の `WinMain`）
- `Update` と `Draw` は **1秒に60回**（17・17・16ミリ秒の間隔を繰り返す）。待っている間は `Sleep(1)` で休むので、CPU をほとんど使わない
- 来ているウィンドウメッセージ（マウスの移動など）は、毎回全部処理してからフレームを進める
- **タイトルバーに FPS** が出る。60 より下がっていたら、処理が重くて間に合っていない
  （移動や回転は「1フレームでどれだけ進むか」で書いているので、FPS が下がるとゲーム全体がゆっくりになる）
- **垂直同期**（`dx11.cpp` の `VSYNC`）：モニターの書き換えに合わせて表示するので、画面のちらつき（ティアリング）が出ない

## 気をつけること
- **ポリゴンの表は時計回り。** 見る側から見て頂点が時計回りに並んでいない面は描かれません（バックフェースカリング）。
- **シェーダーの定数バッファ**は `shader.h` / `shader.cpp` の構造体と `shaderCommon.hlsli` の並びをそろえること。片方だけ変えると色や位置がおかしくなります。
- **シェーダー（`.hlsl` / `.hlsli`）は BOMなしUTF-8** で保存する。BOM があるとコンパイルが `X3000: Illegal character` で失敗します。
  C++ のファイル（`.cpp` / `.h`）は **BOM付きUTF-8**。
- ビルドすると `.cso`（コンパイル済みのシェーダー）がプロジェクトのフォルダにできます（Git には入れない）。
  exe を直接ダブルクリックすると .cso が見つからずエラーになるので、Visual Studio から実行してください。
