# 腕のモデル（OBJ）の原点と長さ

No.34 で Maya の `.mb` から書き出した腕の OBJ の情報です。腕のプランを作るとき・取付位置を決めるときに読む（`docs/handoff.md` から移した）。
書き出しは `.\tools\export-arm-obj.ps1 <腕>`（中身は `tools/maya/export_arm_obj.py`）。
書き出したら `ObjCalcTest::AssetModels_AllObjFilesParse` で、`assets/models/` の全 OBJ が読み込めることを確かめる。

- Claude の確認（No.34 時点）：`.mb`・OBJ が LFS に入っている／書き出し直しても `git diff` なし／Y の輪切りごとの範囲・中心と3方向の投影図で、全部 -Y へ伸び、グラップリングのフックは原点が軸受けの中心で爪2本が -Y へ伸びる（爪の開きは Z ＝ゲームの上下）。旧付け根の -Y 端（22.72）はワイヤー出口と一致。No.42 では前腕の -Y 端がひじから11.820275 cm。
- あとの腕のプランで気をつけること（Claude が見つけた）：グラップリングの付け根は、原点（肩の箱の +X の端）より腕の筒が X に -1.61 ずれ、肩の箱は -X へ約8 cm 張り出す（左右の手でどちら向きかは画面で管理者に聞く）。磁石は腕が +Z（ゲームの上）へ大きく曲がり、先は肩から約 (-2.9, -17.4, +9.7) cm（No.38 で決める）。
- 全シーン cm、骨0・アニメ曲線0・画像テクスチャ0。`executeScriptNodes=False` で読み、元ファイルは保存しない。拡大・ポリゴン削減なし。全 OBJ が5000三角形以下。
- メカの共通付け根は**作らなかった**。各腕の肩自体が別形状（grapple の `pCube28` は454三角形、drill の `polySurface4` は354、shield の `pCube14` は316）。同名の残存部品を頂点比較すると、`polySurface11`・盾の `polySurface14` などは完全一致するが、別の腕の部品。`polySurface5` はシーン間で最大約3.070 cm、`polySurface9` は約4.213 cm の頂点差もある。各腕のルートに属する部品だけを採用した。
- **原点は下表の Maya ワールド座標を引く**。その後ドリルのビットだけ X に +45° 回す（元の軸 `(0,-1,+1)` → `-Y`）。ほかは回転なし。X が横・-Z が下、右手系 cm のまま。長さは原点から **-Y 側の端までの投影長**で、全高や肩から次の部品の接続位置ではない。

- **部品分けで判断したこと・次の実装への注意**：
- グラップリングの細い `pCylinder32` はワイヤーなので OBJ から除外。`pCylinder18` の発射機構は lower に残した（No.42 で旧 base を分割）。フックは飛んでいく軸受＋爪2本だけ。ワイヤー出口は元の `(2.408076,-4.412123,-1.858183)` 付近（発射機構の下端）、フックの原点とは別。
- ハサミは刃 `sweep2` / `sweep3` を両方分離できた。刃自身の pivot は接合面付近で、ちょうつがいの中心ではないため、両方とも `pCylinder13` の pivot を使う。開閉軸は X。
- ドリルは長い後方の軸も含む。軸後端から先端まで約18.06 cm。ビットの OBJ は後端が原点・軸が -Y のまま使い、ゲーム側で下記の元の握りへ組み立てる（書き出し直さない）。
- 盾は手・指を base に残し、盾だけを分離。元の構えを保つため板は回さない。原点より +Y に5.412460 cm、-Y に2.901904 cm 張り出すので、表の長さは盾の全高ではない（全高8.314364 cm）。磁石の曲がった腕の姿もそのまま。
- 各シーンのルート外の他の腕の残骸、および非表示の `|polySurface12` / `|polySurface14` は除外。すべての除外パスをスクリプトが表示する。部品表とルート内のメッシュが違うと停止する。
- 確認：mayapy で全種類の書き出しと範囲・原点・三角形数を確認。`grapple` 単独再実行でも10個の OBJ のハッシュが変わらず、元の5ファイルのコピーも Downloads と一致。部品の判断には元メッシュの3方向投影図も使用。vswhere で見つけた MSBuild で Debug x64 ビルド成功（警告・エラーなし）。ゲーム画面・単体テスト・Release は未実施、Claude 担当。

## ドリルの元の握り（案A、2026-10-27）

- 肩 pivot から見た軸後端は `(0.311337, -5.719436, -5.081741)` cm、先端への軸は `(0,-1,+1)/√2`（Maya の Z 反転前）。倍率は 0.08。軸後端から手は 6.9〜12.05 cm、ドリルの胴は 6.37〜14.42 cm、先端は 18.060484 cm にある。
- **Maya の +Z はそのままだと腕の下側に描かれる**。OBJ 読み込み時に Z が反転し、`TentacleCalcPieceAxes` の Z は上を向くため。ドリルの付け根だけ腕の軸のまわりに 180° ひねり、Maya の +Z（手のひら・指・ドリルの先）を腕の上側へ戻す。右手は従来どおり X を鏡写しにする。
- `DrillCalcAxis` はこの付け根と同じ軸・Z 反転・左右の鏡写しで後端と単位方向を求める。ビットを後端からその方向へ描き、判定も同じ軸の後端から 12.0〜18.060484 cm（半径は従来の 0.35）に置く。
- 腕を -45° に下げるとビットは前へ水平になり、軸後端は肩より約 0.61 下（腰の高さ）になる。突きの腕の傾きも握りの軸から求め、伸縮させない。
