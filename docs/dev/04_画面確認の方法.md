# 画面確認の方法

見た目が変わるタスクの確認（段階3）で、ゲームの画面を撮るときに読む（`docs/handoff.md` から移した）。計算だけのタスクでは画面は撮らない。

## 画面を撮る

- 画面操作のツールがなくても、PowerShell で撮れる。ゲームを `Start-Process -WorkingDirectory <リポジトリ>` で起動し、user32 の `SetForegroundWindow`（`Alt` を押したまま呼ぶ。下を参照）・`keybd_event`・`mouse_event`、`System.Drawing` の `CopyFromScreen` でウィンドウを撮る。
- キーやクリックを送る前に毎回 `GetForegroundWindow()` がゲームか確かめ、違えば止める。日本語を書いた .ps1 は BOM付きUTF-8。撮った画像は結果を書く前に必ず見る。
- Alt を押して離すとゲームのシステムメニューが開いて Enter を吸うので、Alt を押したまま前に出し、F13 を1回押してから Alt を離す。ほかのウィンドウが上に出ることがあるので、撮る直前にもう一度前に出す。
- Debug 出力は DBWIN_BUFFER を読む一時スクリプトで取れる（`DBWIN_BUFFER_READY`・`DBWIN_DATA_READY` のイベントと `DBWIN_BUFFER` の共有メモリ。文字は CP932）。

## 腕を横から見る

- カメラは敵を見続けるので、腕を横から見たいときは `camera.cpp` の `Camera::MakeMatrices` でビューを置きかえた一時ビルドを、OutDir・IntDir を scratchpad に分けて作る（コミットしない。終わったら壊したところだけを Edit で戻す）。
- **ビューの見ている点を肩（`ArmCalcShoulder` に `Player` の位置・向きを渡した点）にすると、肩が画面の真ん中に来て、部品が肩についているか分かる**。
- 真横（キャラの左へ 2.5、前へ 0.6、肩と同じ高さ）から見ると、部品が上下どちらに曲がっているか分かる。
