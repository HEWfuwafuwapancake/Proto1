## 2. 次にやること

### No.195　メニューと戦闘のSEを調整する（Claude向け・承認待ち）

最初にメニューの操作と声の重なりを直す。戦闘は、声を整理してから距離と左右を付け、その状態で腕ごとの音量を決める。同じ音量設定・同じ距離で比較できるようにする。

#### 1. メニューの応答とキャラ選択

- **戻る音の出だし。** `assets/sounds/se/選択画面/選択・カーソル移動/戻る.wav` は全長約302ms。左右どちらかの振幅が初めてフルスケールの1%に届くのは約73ms後。先頭の無音・小さい部分だけを波形と耳で詰め、立ち上がりを残して16bit PCMで保存する。BackSpaceとパッドの×を押した瞬間に聞こえ、頭にクリック音が入らないことを確認する。
- **「戻る」の意味（方針案）。** おすすめは「前の画面へ戻った／準備を取り消した」という結果に戻る音を1回対応させること。オプションの「戻る」とMODE SELECTの「タイトルに戻る」は、決定で選んでもBackSpace／×でも同じ音。進む操作は決定音。もう一案は押したボタンに音を対応させ、現行の違いを残すこと。`game/menuse.cpp` の `back / decide` だけでは結果を区別できないため、受理した操作を `Game::UpdateMenu`・`SceneCalc::Step` から渡す。自動遷移や無効入力で鳴らさない。
- **「標準に戻す」（提案）。** `SCENE_EVENT_TUNING_RESET` を受けた時に、試合設定・腕耐久の表・視点感度を適用前後で比較する。変更ありは今の変更音を1回、すべて標準なら「戻る.wav」を1回。画面には留まり、差分検出のカーソル音を二重に鳴らさない。
- **案内ボイス。** `MenuSe` に案内専用の `SeVoice` を1つ持たせる。キャラ選択（内部名 `SCENE_TITLE`）に入るときの「キャラクターを選んでね」と、MEKAGIRL準備時の「よろしくおねがいね」はこの枠で再生する。`SeVoice::Play` は前の声を止めてから次を鳴らす。準備取消・キャラ選択からの退出時にも止める。モードへ戻る、マップ選択を経て即開始、切断で退出する経路で声が残らないこと。決定音は短い操作音として独立させる。
- **オンライン開催のBack。** `Game::UpdateFrame` は `SCENE_TITLE && IsOnline() && IsLobbyBack()` ですぐ `Finalize()` する。ホストが準備済みなら、最初のBackは選んだ機器からの準備取消だけを受理してロビーに留まる。`game/netsession`・`net/sessioncalc` でホストの `m_LocalReady` とReadyマスクの自分のビットをそろえて戻す。接続中のメンバーとその準備は保持し、既存の状態通知で参加側にも反映する。再選択・再決定でき、未準備で改めてBackを押したときに退出する。開始済みとの境界を確認する。オンラインの表示・選択音もネット側のReadyを見る。今回の報告対象はホストのキャラ選択画面。JOINの退出、オフラインの参加解除、開始後のマップ選択は回帰確認する。

#### 2. 戦闘SEの位置・音量・声

- `src/audio/se.*`・`sound.*` に、音源位置・聞き手からの距離・画面の左右を扱う戦闘用の再生経路を足す。ゲーム側から攻撃者・被弾者の枠と音の発生位置を渡す。発射・振り・ガード・破壊はその腕、着弾・爆発は実際の命中点や爆心で鳴らす。レーザーの `Fire` は現在発射音だけ。遠隔命中で発射音を被弾者側へ移さず、採用した着弾音を命中地点で鳴らす。溜め・回転など持続する音は `SeVoice` の停止・再生管理を生かし、移動・カメラ旋回中も定位を更新する。
- **聞き手の案。** ソロ・オンラインはこのPCの操作キャラを距離の基準、そのカメラの右方向を左右の基準にする。同じ距離なら「自分が当てた／当てられた」音を大きく、第三者同士は少し下げる案。基準音量×距離減衰×当事者倍率で調整する。自分が遠くで当てた着弾音にも距離は効く。XAudio2の出力チャンネル数と素材のmono／stereoに合わせて配分し、中央・左右で音量が跳ねないようにする。音の判定は各PCの再生だけに使う。
- **同じPCの分割画面は要確認。** スピーカーを共有するため各人だけに聞かせることはできない。おすすめはローカル参加者全員を当事者とし、音源に一番近い参加者の距離とカメラで各音を1回だけ鳴らす（同距離は枠順）。もう一案は1P視点固定。共有出力では落下したローカル参加者の声が全員に聞こえる。
- **声を減らす。** `Fighter::PlayVoice` と呼び出しを見直し、%増加で鳴る被弾ボイスと `armStarted` による無差別なランダム攻撃ボイスを外す。落下ボイスはそのキャラを操作するPCだけ。CPU・ダミー・他PCの落下では鳴らさない。通常の攻撃音・着弾音は別々の出来事として重ねてよい。同じ動作で同じ音を二度鳴らさない。
- **採用を選べる追加案。** ① 長押し攻撃ボイスはキャラ別に「格闘／武器／射撃」と腕を対応させ、実際に振る・突進する・撃つ瞬間に1回。溜め・中断・単押しは無声。既存の攻撃声4本は番号だけなので、試聴して合う台詞と腕を決める。② 撃墜ボイスは `FighterManager::Update` の `RecordOut` 前後で実際に自分の得点が増えたときに1回。自滅・他人の得点は対象外。③ 共通被弾SEを採るなら弱／中／強の非ボイスを被弾位置で小さく1回。おすすめの基準は実際の吹っ飛び力。吹っ飛ばないダメージ技の扱いは弱から試す。もう一案はダメージ%。腕固有の着弾音と聴き比べ、埋もれる組み合わせには足さない。専用の撃墜台詞・3段階の被弾素材は担当と選ぶ。まず腕の音だけで試聴できるところまで進める。

#### 4. 完了の判定

1. 純粋な計算を単体テストする。オンラインの準備→取消→再準備→開始、距離の遠近・左右の反転・同距離での当事者優先を確認。段階3で `vswhere.exe` からMSBuildを探しDebug / Release x64警告0、`.\tools\run-tests.ps1` と `.\tools\run-tests.ps1 -Release`。新しい計算をまとめて壊して失敗を確認し、戻して再実行する。
2. **メニュー試遊。** オプションとMODE SELECTで「戻る」項目／BackSpace／×を比較。変更済み・標準の2状態でリセット。キャラ選択に入って即MEKAGIRL決定→取消→即退出、別の回で即試合開始。各操作音の回数と、声の終わりを聴く。オンライン開催は2つ起動し、ホストの取消→参加側の表示→再決定→開始、未準備での退出を確認。ソロと同一PC対戦も試す。
