### 以下、確認済みのプラン

### ねらい

PC を2〜4台つなぎ、1台に1人ずつで No.25 と同じ試合（90 秒・KO 数・空きはダミー）を遊べるようにする。**離れた場所の人とも遊べる**ようにする。
外部ライブラリは使わず、Windows 標準の **Winsock（UDP）** で作る（`ws2_32.lib`。`#pragma comment(lib, ...)` でつなぐ）。
遠くの人とは **Tailscale**（無料の VPN アプリ。遊ぶ人全員が入れて同じグループにログインする）でつなぐ。各 PC に付く `100.x.x.x` の IP を `--join` に渡すだけで、ゲームのプログラムは LAN と同じまま動く。同じ LAN なら Tailscale なしでもつながる。

### やり方の考え方（おすすめ：入力だけを送る「ロックステップ」）

- No.25 は「4つのスロットに人かダミーが入り、入力はスロットごとに読む」形で、1フレームは 1/60 秒で固定、乱数もない。
  そのため、**全員の PC で同じゲームを同時に動かし、送り合うのは毎フレームの入力だけ**にできる（位置や % は送らない）。
- 自分の入力は **N フレーム先**のフレームの分として送る（入力の遅れ。起動の引数 `--delay N`、指定なしは 3 フレーム = 0.05 秒）。そのフレームの全員の入力がそろうまで、ゲームは進めずに待つ。
  参加側の入力は「自分 → ホスト → 自分」と往復するので、遠い相手（ping 80〜100ms）では `--delay 6`〜`7` にする。遅れはホストの値を全員で使う（つなぐときにホストが配る）。
- 形は「ホストに集める」形：参加側はホストへ自分の入力を送り、ホストが全員分をまとめて全員へ配る。ホストもふつうに遊ぶ（1P）。
- UDP は届かないことがあるので、毎回「まだ届いたと言われていない分」の入力を最大 8 フレーム分まとめて送る（届いたフレーム番号を返してもらう）。
- ずれ（デシンク）の見張り：60 フレームごとに、全員の位置・%・KO 数から作った数字（チェックサム）を比べ、違えば Debug 出力とタイトルバーに出す。
- 巻き戻し（ロールバック）は作らない。遅い回線ではときどき止まるが、プロトでは LAN と近い相手で確かめれば十分と考える。

|---|---|---|---|
| 触腕（今のまま） | 伸ばしてつかむ | 投げる | % ＋12・吹っ飛ぶ |
| グラップリング（No.36） | フックを撃ち、刺さった所へ自分が引っぱられて飛ぶ。刺さるのは敵と浮島のふち | 途中で押すと離す | 敵なら着いたときの体当たりで小さく吹っ飛ばす（＋5）。ふちに刺されば場外から戻れる |
| ドリル（No.37） | 伸ばさずに突き出す（近い敵だけ）。当たった敵に 0.5 秒くい込み % が小刻みに大きく増える（＋4 × 5回） | なし（自動で戻る） | 最後に水平に押し出す（上にはあまり飛ばない） |
| 磁石（No.38） | ターゲット（いなければ正面）を自分の前まで引き寄せる（ダメージなし） | 引き寄せている間なら反発して強く吹っ飛ばす | 反発で % ＋8 |
| デカ盾（No.39） | 前に構えて遅く歩く（離しても構えたまま、2 秒で下ろす） | 構えている間なら盾で押す | 前の敵を % に関係なく一定の強さで押し出す（% ＋0）。ガードの効き目は No.24 のあと |
| ハサミ（No.40・最後） | 相手の腕を切り落とす | — | 切られた相手は新しい腕を探す。相手が腕を使う No.24 と、腕を拾う No.27（腕カプセル）のあと |
