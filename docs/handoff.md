## 2. 次にやること

### 2.1 ゲーム本体の仕様（2026-11-10、管理者の依頼のまとめ）

- 1試合は**約3分**で、今と同じ**スコア制**（場外へ落とした数を競う。ストックはなし）。
- **腕は最初は持っていない**。フィールドのあちこちに出る**腕の入ったカプセル**を拾って装着する。
- 腕には**使用回数**があり、使い切ると**崩壊**して、新しい腕を拾う必要がある。**3分の間に全部の腕を試せる**回数にする。
- 回数が減るのは、**敵かオブジェクトに使ったときだけ**（触腕で復帰する、ガンランスの弾を撃つなど）。空振りでは減らない。
- 復活は、**敵が近くにいないランダムなスポーンポイント**（リスキル防止）。
- **ガンランス**：単押しは普通の銃のように弾を撃つだけ。長押しは敵へ突進し、突き刺せたら**突き上げて弾を3発撃ち込む**演出にする。
- **キャラ選択のあとに GAME / DEBUG を選ぶ**。GAME はカプセルを拾わないと腕が手に入らない。DEBUG は**今のまま**（武器をいつでも切り替えられる、90 秒、最初の場所で復活、回数は減らない）。

### 2.3 プラン（上から順に。1タスク＝1 PR）

共通：乱数は `rand()` を使わず、DirectX なしの計算クラスの中の整数の乱数にする。オンラインはロックステップなので、全員の PC で同じ順に同じ値が出る必要がある（種はホストが STATE で配り、RETRY ごとに同じ計算で進める。オフラインは時刻から作る）。数はすべて各ファイルの「調整用の値」に置く。エフェクトは作らない決まりなので、崩壊は腕が消えて HUD が「素手」に変わるだけにする。

**No.107 GAME / DEBUG の選択**
- `physics/scenecalc`：`GAME_RULE`（GAME / DEBUG）と `SCENE_RULE_SELECT` を足す。流れは GAME START → キャラ選択 → **GAME / DEBUG** → モード選択。戻るはキャラ選択へ。RETRY は同じルールのまま。
- `game.cpp`：`UpdateMenu` に新しいシーンを足す。`hud.cpp`：選択画面を足す（足りない英字も）。
- オンラインは**ホストのルールを全員に使う**（参加する人の選択は使わない）。`net/sessioncalc` の STATE にルールと乱数の種を足し、`LOCKSTEP_VERSION` を 8 にする。起動の引数 `--host`・`--join` は選択を通らないので DEBUG にする。
- 確認：`scenecalc` のテストを直す。画面で選択と戻るを見る。

**No.108 3分・ランダムな復活（GAME だけ）**
- `Match`：制限時間を GAME 180 秒にする（DEBUG は今の 90 秒）。得点・時間切れ・結果画面は今のまま。
- 新しい `physics/spawncalc`：候補（浮島8か所＋高台4つの中心）のうち、生きている相手全員から `SPAWN_SAFE_DISTANCE`（案 10）以上離れた点から乱数で選ぶ。全部近いときは、いちばん近い相手がいちばん遠い点にする。
- `FighterManager::Update`：`DUMMY_EVENT_RESPAWN` を受けたらその場で選んだ点へ移す（復活の瞬間の敵の位置を見るため。`DidRespawn` のカメラの処理はそのまま効く）。DEBUG は今の最初の場所のまま。
- 確認：`spawncalc` のテスト。画面で敵のそばに復活しないことを見る。

**No.109 素手・使用回数・崩壊**
- `ARM_TYPE_NONE`（素手。何もしない腕クラス）を `ARM_TYPE_COUNT` の直前に足す。`m_Arms[hand][m_Types[hand]]` がどこでも有効なまま動かせる。数字キー 1〜6 の番号は変わらない。DEBUG の切り替えでは選べないようにする。
- GAME は試合の始めと復活のときに両手とも素手にし、`ArmManager::Update` の装備切り替えを止める。DEBUG は今のまま（回数は減らない）。
- `Arm` に `ConsumeUse(int count = 1)` を足し、各腕が「効いた瞬間」に呼ぶ。`ArmManager` が手ごとの残り回数を受け持つ（計算は新しい `physics/armusecalc`）。

| 腕 | 回数 | 回数が減るとき |
|---|---|---|
| 触手 | 3 | 敵をつかめた・足場に付いた・回転が敵に当たった |
| ハンマー | 2 | 敵に当たった（何人でも1回） |
| ナックル | 3 | 敵に当たった |
| C4 | 2 | 起爆して敵に当たった（設置では減らさない。置いた爆弾が起爆できなくなるため） |
| ガンランス | 8 発 | 弾を撃った（空振りでも弾は減る）。突き刺しは撃った数だけ |
| 刀 | 3 | 居合が当たった・ワープで飛んだ |

- 崩壊は回数が 0 になったあと、**今の動作が終わってから**にする（`IsActive` に加えて、飛んでいる弾・遅れて入る居合が残っている間は待つ `IsBusy` を足す。待つ間は新しい入力を受けない）。投げの途中で腕が消えて相手を持ったままにならないようにする。
- `hud.cpp`：腕の名前の横に残り回数を出す。`LOCKSTEP_STATE` に腕の種類と回数を足す。
- 確認：`armusecalc` のテスト。空振りで減らないことと、使い切ると素手になることを画面で見る。素手でキャラ本体の腕が見えるかも見る。

**No.110 腕カプセル（GAME だけ）**
- 新しい `physics/capsulecalc`：位置と種類の一覧、出現のタイマー、拾う判定。新しい `game/armcapsule`：`Game` が持ち `Initialize / Reset / Finalize / Update / Draw` で動かす。
- 始めに8個、以後 1.5 秒ごとに1個、最大16個（すべて案）。場所は浮島の上の乱数（ふちから少し内側）。4分の1は高台の上。
- 種類は6種を1巡ずつ袋から引く（完全な乱数だと出ない腕ができるので、最初の6個で全種類が出るようにする）。
- 触れるだけで拾う（`CollisionSphereCapsule`）。同じフレームはスロットの若い順。拾うのは人だけ（ダミーは腕を持たない）。空いている手の左 → 右の順に付く。両手がふさがっていたら拾わない。
- 見た目は `ShapeDrawCapsule` の仮の形で、種類ごとに色を変える。上下の揺れは描画だけ。
- `Game::Update` の順は 体 → カプセル → カメラ → 向き → 腕 にする。
- 確認：`capsulecalc` のテスト。画面で拾うと腕が付くことを見る。ふたつ起動のオンラインで DESYNC が出ないことを見る。

**No.111 ガンランスの作り直し**
- 単押し：弾を1発撃つだけにする（ためと爆発をなくす。案：+6%・強さ 1.0・間隔 0.25 秒）。`GunlanceCalc` のためをやめ、テストも作り直す。
- 長押し：今の突進のまま相手へ向かう。当たったら `FighterManager::Grab` でつかむ（ガード中は `Grab` が失敗するので、突進が止まるだけ）。
- 演出は 突き刺す → 突き上げる（約 0.35 秒）→ 0.2 秒おきに3発 → 最後の1発で `Release` で上へ吹っ飛ばす（案：+6 / +8 / +8 / +12%・強さ 3.0）。弾が3発ないときは、ある分だけ撃って吹っ飛ばす。
- 相手の位置は `MoveHeld` で動かす。**位置の計算には `GetShoulder` を使う**（`GetDrawShoulder` はアニメの骨から出す描画専用の値で、計算に使うとオンラインでずれる）。
- 演出の間は `IsHolding` を true、移動の倍率を 0 にする。殴られて中断（`Interrupt`）したら相手を離す。時間切れの `Reset` でも離す。
- 突き上げのクリップ（左右の手）を `tools/maya/build_weapon_clips.py` に足し、`ATTACK_CLIP` にも足す。
- 確認：`gunlancecalc` のテスト。ダミーに突き刺して、突き上げと3発を画面で見る。
