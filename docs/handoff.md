## 2. 次にやること：No.48 の実装（Codex）

まず同じ LAN で遊ぶ（Tailscale は使わない）。起動の引数なしで、ゲームの中から対戦方法を選んでつなげるようにする。No.19 はこのあと。

**画面の流れ**：GAME START（○／Enter）→ モード選択（↑↓・決定）→ 各モード。

| 項目 | 決定したとき |
|---|---|
| SOLO | 選んだ機器を 1P にして、すぐ試合（ほかの3体はダミー） |
| LOCAL VS | 今のタイトル（○／Enter で参加、1P の再決定で開始） |
| ONLINE HOST | ホストを開いて今のオンラインのロビーへ。ロビーにこのPCの IPv4 を大きく出す |
| ONLINE JOIN | IP 入力 → 決定でつないで今のオンラインのロビーへ |
| BACK | GAME START へ |

- **IP 入力**：4つの区切り（0〜255）。キーボードは数字・`.`・Backspace で打ち、Enter でつなぐ。パッドは十字キー ←→ で区切りを移り、↑↓ で値を変える。最初は自分の IPv4 の前の3つ（例 `192.168.1.`）を入れておく。つなげないアドレス（範囲外・空）は決定を受け付けない。
- **戻る**：メニュー・IP 入力・ロビーでは Backspace／× で1つ前へ。ロビーから戻ると通信を閉じる（`NetSession` を閉じてオフラインへ）。
- **切断・参加拒否**：今のオフラインのタイトルではなく**モード選択**へ戻す（理由は今どおりタイトルバー）。
- **結果の TITLE**：ローカルはモード選択へ。オンラインは今どおりロビーへ（接続を保つ）。
- **起動の引数** `--host` / `--join <IP>` / `--delay` は残す（メニューを飛ばして直接ロビーへ。2つ起動の確認用）。メニューから開くホストの delay は 3。
- 試合中の操作・ロックステップ・パケットは変えない（版 `LOCKSTEP_VERSION` も上げない）。

**作り方**
- 画面の流れ：`src/physics/scenecalc` に GAME START・モード選択・IP 入力のシーンを足す（DirectX なし、テストする）。今の `SCENE_TITLE` はロビー（参加画面）として残す。
- IP の編集・文字列化・検査：`src/net/sessioncalc` に DirectX・Windows なしで足す（テストする）。
- `NetSession`：試合の途中で開く・閉じる（`Initialize` を何度でも呼べる、閉じたら `IsOnline()` が false）。`Game` がメニューの結果で呼ぶ。
- 表示：`hud.cpp` に各画面。5×7 の文字に G・H・B・数字 0〜9・`.` を足す（`glyphcalc`、テストする）。
- テストは主な動きだけ。足した計算をまとめて1回わざと壊し、落ちることを確かめる。
