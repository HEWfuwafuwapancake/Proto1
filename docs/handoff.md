### No.39 のプラン案：デカ盾（管理者の確認待ち、2026-10-27）

- **やること**：L1 / R1 で盾を前に構え、構えている間は遅く歩く。構えている間にもう一度押すと、盾で前の敵を押し出す（% に関係なく同じ速さ、% ＋0）。ガードの効き目（自分が受けるダメージを減らす）は No.24 のあと。
- **押し方（管理者が選ぶ）**：ボタンは L1 / R1 の1つだけなので、「押している間だけ構える」と「構えている間にもう一度押す」は両方そのままではできない（もう一度押すには一度離す）。
  - **A（おすすめ）**：押すと構える（離しても構えたまま）。構えている間にもう一度押すと盾で押す。構えは `GUARD_SECONDS` 2.0 秒で自動で下ろす。磁石の「押す → もう一度押す」と同じ操作になる。
  - **B**：押している間だけ構える。離してから `REPRESS_SECONDS` 0.25 秒は構えが残り、その間にもう一度押すと盾で押す（すばやく2回押す＝押し出し）。仕様の「押している間」のとおりだが、押し出しが少し出しにくい。
- **動き**（A の場合。数字は `arm_shield.cpp` の「調整用の値」。仮の値で、管理者が遊んで決める）：
  1. 待機中に押す → 構え（`GUARD_RAISE_SECONDS` 0.1 秒で腕をキャラの正面・水平へ）。構えている間、歩く速さ × `GUARD_MOVE_SCALE` 0.4。
  2. 構えている間にもう一度押す → 押し出し：肩からキャラの正面（`GetPlayer().GetYaw()`）へ長さ `BASH_RANGE` 2.0・半径 `BASH_RADIUS` 0.9 のカプセル（`CollisionCapsuleCapsule`）に重なる `Available` な敵を全部、キャラの正面（水平）へ速さ `BASH_SPEED` 12・上向き `BASH_UP` 0.15 で押し出す（% ＋0。% に関係なく同じ速さ）。腕を `BASH_SECONDS` 0.15 秒だけ前へ突き出す → 休み。
  3. 押さずに `GUARD_SECONDS` 2.0 秒たつ → 下ろす → 休み。
  4. 休み（`COOLDOWN_SECONDS` 0.3 秒）：押しても何もしない。プレイヤーが復活したら待機に戻す。
  - 押し出した瞬間は触腕の投げと同じ振動。色：構え・押し出し中は `GetColor(true)`。敵はつかまないので `IsHolding()` は false（カメラはロックオンのまま）。
- **今の作りに小さく足すもの**：
  - 遅く歩く：`Arm` に `virtual float GetMoveScale() const`（ふつうは 1.0。盾は構え中 0.4）、`ArmManager::GetMoveScale()`（左右の小さいほう）、`Player::Update` で `MoveSpeed` に掛ける。ほかの腕のファイルは触らない。プレイヤーは腕より先に動くので、1フレーム前の構えで遅くなる（気にならない差）。
  - % に関係ない押し出し：`DummyManager::Push(int index, const VEC3& velocity)`（% を足さず、速度を与えて吹っ飛び中にする）。`Launch` は % で速さが変わるので使わない。
  - B を選んだときだけ：押している状態を読む `Arm::IsPressing()`（`ActionIsPress`）。
- **見た目**：`arm_shield_base.obj`（長さ 19.250364 cm、倍率 0.08）を共通の `GetShoulder()` から、`arm_shield_plate.obj` を base の取付位置（OBJ の座標で base の原点から (0.229, -15.022, 0.103) cm。Maya の pivot の差）に、base と同じ軸で描く（`GrappleCalcModelPoint`）。向きは待機が `GetRestDirection()`、構え・押し出し中はキャラの正面へ水平（`ArmCalcBlendDirection`）。
  - **上下の向き（半回転が要るか）は、実装のあと Claude が肩を中心にした一時ビルドで真横から確かめ、管理者に見せる**（OBJ は読み込みで Z が反転する。No.38 で磁石の先が下に描かれていた）。両方の OBJ に `vn 0 0 0` はない（確かめ済み）。
- **新しいファイル**：`src/physics/shieldcalc.h / .cpp`（DirectX なし・テストする。`class ShieldCalc`：状態 `SHIELD_STATE`（待機／構え／押し出し／休み）・時間を `m_〇〇` に持ち、`Reset()`・`Step(…)`（「押し出した」を返す）・`Get〇〇`。押し出しのカプセルと速度は自由関数）、`src/game/arm_shield.h / .cpp`（`ShieldArm : public Arm`）、`arm.cpp` の `ARM_FACTORIES` の盾の行。
- **テスト**（主な動きだけ）：押すと構える／構え中に押すと押し出して休み／2 秒で下ろす／休み 0.3 秒で待機／復活で待機／押し出しはカプセルに重なる `Available` な敵だけ・速さは % に関係なく同じ。
