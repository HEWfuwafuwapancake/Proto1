  | ファイル | 中身 | 長さ（原点 → 次のつなぎ目、cm） | 三角形 |

- **新しいファイル**：
  - `src/render/objcalc.h/.cpp`（DirectX を使わない。テストする）：OBJ の文字列から三角形の頂点（位置・法線）の並びを作る。`v`・`vn`・`f`（`v`／`v//vn`／`v/vt/vn`、マイナスのインデックス、四角形以上は扇形に三角形へ分ける）。
    法線がない面は面の向きから求める。知らない行（`o`・`g`・`s`・`mtllib`・`usemtl`・`vt`・`#`）は読み飛ばす。**右手系から左手系へ：Z を反転し、三角形の並び順を逆にする**（DX11 は時計回りが表。`dx11.cpp` の `CullMode`）。壊れた行（足りない数・範囲外のインデックス）は失敗を返す。
  - `src/render/model.h/.cpp`：`ModelInitialize / Finalize`、`ModelLoad(パス)`（ファイルを読んで `objcalc` に渡し、頂点バッファを作る。失敗したら -1）、`ModelDraw(番号, 原点, X軸, Y軸, Z軸, 色)`（3つの軸は大きさ込み。ワールド行列にして `shape.cpp` と同じシェーダー・マテリアルの色で描く）。
- **うねうねの計算（`tentaclecalc` に足す。テストする）**：
  - `TentacleCalcWigglePoint(肩, 先端, s, 位相, 揺れの大きさ, 波の数)`：肩→先端の線の `s`（0〜1）の点を、横に `A·sin(πs)·sin(2π·波の数·s − 位相)`、腕に直角な縦に `A·0.5·sin(πs)·cos(…)` だけずらした点。**s=0 と 1 では必ず肩・先端そのもの**。横は「腕の向き × 上」、腕が真上・真下なら +Z を使う。肩と先端が同じ点なら肩を返す。
  - `TentacleCalcPieceAxes(始点, 終点, 下にしたい向き)`：モデルの -Y を始点→終点に向け、モデルの -Z が「下にしたい向き」になるべく向く、直交する3つの単位ベクトル。始点と終点が同じ・下にしたい向きと平行なときも壊れない。
- **`tentacle.cpp` の描き方（`TentacleDraw` だけ。当たり判定・動き・色は変えない）**：
  - 肩→先端の長さ L。付け根・節×n・先っぽの元の長さ（cm × `MODEL_SCALE`）を並べ、n は `L` から付け根と先っぽを引いて節の長さで割って四捨五入（0 以上）。合計と L の比で s の位置を決め、各部品はとなりの点どうしの間に置き、長さ方向だけ間の距離に合わせて伸び縮みさせる（横の太さは `MODEL_SCALE` のまま）。
  - L が付け根＋先っぽより短いとき（待機中も）は n=0 で縮めるが、最小 `MIN_STRETCH` 倍まで。L がほぼ 0 のときの向きは、プレイヤーの正面（`PlayerGetYaw`）の水平方向。
  - 位相は `GameTimeGetElapsed() × WIGGLE_SPEED`（左右の腕で `WIGGLE_ARM_PHASE` ずらす）。揺れの大きさは `WIGGLE_AMPLITUDE × min(1, L / WIGGLE_FULL_LENGTH)`、つかんでいる間は × `WIGGLE_HOLD_SCALE`。
  - 下にしたい向きはワールドの下（0, -1, 0）。モデルが読めなかったときは今の球の描き方のまま。
  - 調整用の値（初めの値）：`MODEL_SCALE` 0.15（cm → ゲームの単位。節の太さの半分 約 1.2cm が今の半径 0.18 とほぼ同じになる。付け根 1.53・節 0.48・先っぽ 0.67）、`MIN_STRETCH` 0.2、`WIGGLE_AMPLITUDE` 0.25、`WIGGLE_WAVES` 1.5、`WIGGLE_SPEED` 8.0、`WIGGLE_ARM_PHASE` 1.6、`WIGGLE_FULL_LENGTH` 3.0、`WIGGLE_HOLD_SCALE` 0.3。
- **テスト**：`objcalc_test.cpp`（三角形・四角形の分け方、3つの面の書き方、マイナスのインデックス、Z の反転と並び順、法線がないとき、壊れた行）、`tentaclecalc_test.cpp` に足す（両端が肩・先端、揺れ 0 でまっすぐ、ずれが腕に直角、真上・真下・長さ 0、軸が直交する単位ベクトルで -Y が腕の向き）。

- **マージ**：Claude・Codex がこの流れで作った PR は、テストとビルドが通れば、管理者に聞かずにその AI が `gh pr merge <番号> --merge --admin --delete-branch` でマージしてよい（2026-10-23、管理者が「基本マージして問題ない」と決めた。Codex も同じと 2026-10-23 に決めた）。他の人の PR はマージしない。
- **TPS カメラ**（2026-10-24、No.29・33 の見直しで決めた）：カメラは臨界減衰バネ（SmoothDamp）で、角度・高さ・距離・見ている点を別々に追う（単純な Lerp は使わない）。小さな動き・ジャンプでは揺れない。上下の範囲は狭め。
  **ARMS 式のロックオン**：開幕は正面の敵、右スティックを弾くと弾いた方向の次の敵へ。ターゲットがいないとき・つかんでいる間は自由なカメラで、横に移動したときだけカメラがついてくる。（No.9 で決めた「自動で回り込まない」を変えた）
- **キャラの向きと腕の向き**（2026-10-24、管理者が決めた。No.32・33）：ターゲットがいるときはターゲットを向き、いないときは進む向きを向く（モンハン式）。腕は画面の正面へ伸び、伸ばすときにキャラも画面の正面を向く。
- **画面の揺れ**（2026-10-24、管理者が決めた）：今は作らない。作るときはパーリンノイズなどで、時間とともに弱まり、追従の計算を乱さないよう最後のカメラの位置に上乗せする（敵が攻撃してくる No.24 のとき）。
- **試合の流れ**（2026-10-23、No.14 で決めた）：時間切れのあとはプレイヤー・ダミー・触腕が止まる（カメラは回せる）／やり直しはいつでも／プレイヤーが落ちても減点なし／カウントダウンなし（シーンの流れは No.18）／No.15 までの表示はタイトルバー。
- **画面表示**（2026-10-23、No.15 で決めた）：残り時間は秒だけ／ダミーの % は各ダミーの頭の上（3体とも同じ色のため）／英字は 5×7 のドットで、使う文字だけ（フォントは読み込まない）／見本の `polygon2D` は消した／色は白で演出なし。
- **ダミー**：3体・その場に立つだけ。プレイヤーがぶつかると押せる（押して落とせば「場外 → 復活」を試せる。2026-10-23、No.11 で決めた）。場外に落ちたら 2 秒後に最初の場所に戻る。

- **Claude の許可**：Claude Code の自動モードの安全チェックが、マージや `start-work.ps1`（中で develop を `git merge` する）、Notion の更新を止めることがある。

  - `PowerShell(.\tools\start-work.ps1:*)`：作業を始めるスクリプト
  - Notion の `notion-update-page` ツール（名前の `mcp__〇〇__` の部分は PC ごとに違うので、その PC のツール名で入れる）

## 4. 別の PC・新しいセッションで始めるとき（Claude・Codex がやること）

Claude（Claude Code）でも Codex でも、共有の `Proto1` フォルダで同じ手順で続きから始める。もう一方の AI が作業中でないことを確認する（`AGENTS.md`）。

2. `git status` だけを先に見る（自分のものではない変更があればユーザーに聞く）
3. `.\tools\fetch-latest.ps1` で develop を最新にし、`gh pr list` で開いている PR を確かめる

## 5. 作業を終えるとき

- このファイルの「今の状態」「次にやること」「最終更新」を書き直す（どの PC の、どの AI（Claude／Codex）で更新したかも）
- `tasks.md` と Notion の状態をそろえる（Notion を書き換えられない AI は、管理者に「Notion の No.〇 を〇〇に」と伝える）
- 次にやるタスクのプランをまだ出していないときは、「次にやること」に「プランに入れること」のメモを残す（次の AI がそこから始められるように）
- 途中で終わるときは、作業中のブランチを `save-work.ps1` で GitHub に送っておく（別の PC で `start-work.ps1 <同じ作業名>` すると続きから始められる）
