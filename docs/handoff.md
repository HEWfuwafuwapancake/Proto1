### 2.1 ゲーム本体の仕様（2026-11-10、管理者の依頼のまとめ）

- 1試合は**約3分**で、今と同じ**スコア制**（場外へ落とした数を競う。ストックはなし）。
- **腕は最初は持っていない**。フィールドのあちこちに出る**腕の入ったカプセル**を拾って装着する。
- 腕には**使用回数**があり、使い切ると**崩壊**して、新しい腕を拾う必要がある。**3分の間に全部の腕を試せる**回数にする。

- **ガンランス**：単押しは普通の銃のように弾を撃つだけ。長押しは敵へ突進し、突き刺せたら**突き上げて弾を3発撃ち込む**演出にする。
- **キャラ選択のあとに GAME / DEBUG を選ぶ**。GAME はカプセルを拾わないと腕が手に入らない。DEBUG は**今のまま**（武器をいつでも切り替えられる、90 秒、最初の場所で復活、回数は減らない）。

### 2.3 プラン（上から順に。分担と PR の出し方は 2.4）

**No.109 素手・使用回数・崩壊**
- `ARM_TYPE_NONE`（素手。何もしない腕クラス）を `ARM_TYPE_COUNT` の直前に足す。`m_Arms[hand][m_Types[hand]]` がどこでも有効なまま動かせる。数字キー 1〜6 の番号は変わらない。DEBUG の切り替えでは選べないようにする。
- GAME は試合の始めと復活のときに両手とも素手にし、`ArmManager::Update` の装備切り替えを止める。DEBUG は今のまま（回数は減らない）。
- `Arm` に `ConsumeUse(int count = 1)` を足し、各腕が「効いた瞬間」に呼ぶ。`ArmManager` が手ごとの残り回数を受け持つ（計算は新しい `physics/armusecalc`）。

| 腕 | 回数 | 回数が減るとき |
|---|---|---|
| 触手 | 3 | 敵をつかめた・足場に付いた・回転が敵に当たった |
| ハンマー | 2 | 敵に当たった（何人でも1回） |
| ナックル | 3 | 敵に当たった |
| C4 | 2 | 起爆して敵に当たった（設置では減らさない。置いた爆弾が起爆できなくなるため） |

| 刀 | 3 | 居合が当たった・ワープで飛んだ |

- 崩壊は回数が 0 になったあと、**今の動作が終わってから**にする（`IsActive` に加えて、飛んでいる弾・遅れて入る居合が残っている間は待つ `IsBusy` を足す。待つ間は新しい入力を受けない。ただし、つかんでいる間は投げの単押しを受ける）。投げの途中で腕が消えて相手を持ったままにならないようにする。
- `hud.cpp`：腕の名前の横に残り回数を出す。`LOCKSTEP_STATE` に腕の種類と回数を足す。
- 確認：`armusecalc` のテスト。空振りで減らないことと、使い切ると素手になることを画面で見る。素手でキャラ本体の腕が見えるかも見る。
