### 2.3 腕を作るときの書き方（全部の腕で共通。Codex・Claude はここを守る）

**ファイルとクラス**

- 1本の腕 ＝ `src/game/arm_〇〇.h / .cpp` の `Arm` の派生クラス `〇〇Arm`（例：`KnuckleArm`）。1インスタンスが片手1本。左右それぞれ全種類を起動時に作り、装備の切り替えでは作り直さない（`ArmManager`）。
- その腕だけの計算（状態の流れ・連鎖の選び方など）は `src/physics/〇〇calc.h / .cpp` の DirectX・Windows なしのクラス `〇〇Calc` か関数 `〇〇Calc〜` に置き、`tests/Proto1Tests/〇〇calc_test.cpp` でテストする。**共通の計算（No.59 の `ArmPhaseCalc`・`AreaCalc`、No.70 の `ProjectileCalc` など）だけで足りる腕は、`〇〇calc` を作らない**（中身のないファイルは作らない）。
- 登録：`arm.h` の `ARM_TYPE` の最後（`ARM_TYPE_COUNT` の前）に足し、`arm.cpp` の `ARM_FACTORIES` に `CreateArm<〇〇Arm>`、`ARM_NAMES` に日本語名を足す。新しいファイルは `Proto1.vcxproj`・`.vcxproj.filters`（`src\game` / `src\physics` のフィルター）に、計算の `.cpp` はテストのプロジェクトにも「既存の項目」で足す。
- 依存の向き：`physics` は `game` を使わない。腕から相手をさわるのは `GetFighters()`（`FighterManager`）の関数だけ。`Fighter` の中を直接書き換えない。

**クラスの形**（`arm_shield.h / .cpp` が見本。新しい腕もこの並び）

```cpp
// arm_knuckle.h
#pragma once

#include "game/arm.h"
#include "physics/armphasecalc.h"

/// @file arm_knuckle.h
/// @brief 片手のナックルの入力・打撃と描画

/// @brief 拳で殴る腕。相手が近いと杭が出て強くなる
class KnuckleArm : public Arm
{
public:
	/// @brief 待機状態にする（モデルはないので読み込まない）
	/// @param hand 左 0・右 1
	/// @param links 腕が使うゲームの部品への参照
	KnuckleArm(int hand, const ARM_LINKS& links);
	/// @brief 溜め・打撃・休みを進め、打撃を始めたフレームに当たりを調べる
	/// @param trigger 入力を設定する（true：押した瞬間、false：それ以外）
	void Update(bool trigger) override;
	/// @brief 仮の形（腕の円柱と拳の箱）を描画する
	void Draw() override;
	/// @brief 待機へ戻す
	void Reset() override;
	/// @brief 待機以外なら true を返す
	bool IsActive() const override;
	/// @brief 敵をつかまないので、常に false を返す
	bool IsHolding() const override;

private:
	ArmPhaseCalc m_Phase;
	float m_Straighten = 0.0f; // 描画だけのまっすぐ度（0：待機、1：正面）。
};
```

- 状態は `private` の `m_〇〇`。外から読むものは `GetXxx() const`。`g_〇〇`・外から呼ぶ自由関数は作らない。
- コンストラクタは `Arm(hand, links)` を呼び、モデルがあれば `LoadModel` で読んで、最後に `Reset()`。DirectX を使う初期化はコンストラクタでしてよい（`ArmManager::Initialize` から作られるため。`g_Game` の構築時ではない）。
- `Update(bool trigger)` の順番：① `dt = fmaxf(0.0f, GameTimeGetDeltaTime())` ② 計算クラスの `Step`（取りやめは `GetPlayer().DidRespawn()`）③ 当たりを調べて `GetFighters()` の関数で効かせる ④ 振動 `Rumble` ⑤ 描画だけの値（`m_Straighten` など）を進める。
- `Draw()` は状態を変えない（`const` でなくても、描くだけにする）。
- `Reset()` は保持・引っぱりなど相手に残した状態を必ず戻す（装備の切り替え・時間切れ・やり直し・自分が吹っ飛んだときに呼ばれる）。
- 歩く速さを変える腕は `GetMoveScale()` を `override` する（構え中だけ 0.4 など）。ジャンプの速さは変えない。

**調整用の値**

- その腕の `.cpp` の先頭の「// 調整用の値」に `static constexpr` で全部まとめる（秒数・距離・半径・ダメージ・強さ・振動）。計算に渡す値は `〇〇_PARAMS` 構造体にまとめる（`SHIELD_PARAMS` が見本）。
- 数の目安（今の腕）：触腕の投げ ＋12%・強さ2、磁石の反発 ＋8%・強さ2.5、ドリル ＋4%×5回・最後に強さ1.5、グラップリングの体当たり ＋5%。吹っ飛ぶ速さ ＝（4 ＋ % × 0.12）× 強さ（0% で強さ2なら 8 m/秒）。新しい腕の数は下のプランの初期値から始め、管理者が遊んで決める。

**狙い・当たり・効かせ方**（No.59 で `Arm` に足す共通の関数を使う。腕ごとにコピーしない）

- 肩は `GetShoulder()`、待機の向きは `GetRestDirection()`、キャラの正面は `GetForward()`（No.59）。
- 狙いは `GetAim(keepHeight)`（No.59）：ロックオン中は肩から相手の体の中心へ、いなければ画面の正面へ水平。`keepHeight` が true なら上下も含める（`GrappleCalcAim`）、false なら水平だけ（`TentacleCalcAim`。**高さを捨てる**ことに注意）。近接は false、射撃は true が基本。
- 当たり：相手は `for (int i = 0; i < FIGHTER_COUNT; ++i)` で `GetFighters().GetTarget(i, GetSlot())` を読み、`Available` が false なら飛ばす（自分・復活待ち・ほかの人につかまれている相手は false）。形の判定は `collision.h` と `AreaCalc`（No.59）。1回の攻撃で同じ相手に2回効かせないときは `HitRecord`。
- 効かせ方（全部 `FighterManager`。攻撃した人が記録され、場外にしたら得点になる）：

| したいこと | 関数 |
|---|---|
| % を足して吹っ飛ばす（向きは上下を含めて自由） | `Launch(i, GetSlot(), 向き, ダメージ, 強さ)` |
| % だけ足す（小刻みの攻撃） | `AddDamage(i, GetSlot(), ダメージ)` |
| % を変えずに一定の速さで押す | `Push(i, GetSlot(), 速度)` |
| つかむ・動かす・離す（投げる） | `Grab` / `MoveHeld` / `Release` |
| しびれ・遅く・燃える・隠れる | `ApplyStatus`（No.75） |
| ガードを崩す | `BreakGuard`（No.80） |
| 自分の % を減らす | `Heal`（No.69） |

- 吹っ飛ばす向きは「水平の向き ＋ 少し上」を正規化して使う（`AreaCalcLaunchDirection(向き, 上)`、No.59）。
- No.80 のあとは、`Grab`・`Hit`・`AddDamage`・`Launch`・`Push`・`ApplyStatus` の先頭の引数に「攻撃が来た位置」（近接は自分の肩、飛び道具は弾の位置、爆発は爆心）を渡す。ガードされたら false が返る。

**オンライン対戦で同じに動かすための約束**（No.26 のロックステップ。破ると DESYNC）

- 腕の動きは入力（`trigger`・`GetPlayer()` の入力）と `GameTimeGetDeltaTime()` だけで決める。`rand`・時計・`ActionGet〜` の直接読み取り・描画の結果を、動きの計算に使わない。ばらつきが欲しいとき（ガトリングの弾のぶれなど）は、撃った回数から決まる決まった並びを使う。
- カメラ（`GetCamera()`）は各スロットの入力から全員の PC で同じに動くので、狙いに使ってよい（今の腕と同じ）。
- 回転の見た目（ガトリングの銃身など）だけに使う値は、描画の中で `GameTimeGetElapsed()` から作ってよい。

**描画（仮の形）**

- モデルのない腕は `DrawStubArm(向き, 長さ, 色)`（No.59。肩から円柱を描き、手の位置を返す）＋ `ShapeDrawBox` / `ShapeDrawSphere` / `ShapeDrawCylinder` で武器を描く。色は `GetColor(効いているか)`（左右の色と、効いている間のオレンジ）。
- 待機は `GetRestDirection()`、構え・攻撃は狙いの向きへ、描画だけの「まっすぐ度」を 0.1 秒で 0↔1 に進めて `ArmCalcBlendDirection` でまぜる（今の腕と同じ）。
- 当たり範囲の表示（2.1 の 4）は、その腕のメンバーに残り秒数を持ち、`Draw` で描く。
- モデルができたら `LoadModel` と `DrawPiece` に替える（OBJ は読み込みで Z が反転する。曲がった形は `MODEL_ROLL` が要ることがある。開発ログの「磁石の腕をひねり 0 で描き〜」）。

**コメント・文字コード**

- クラス・`public` なメンバー関数・ヘッダーの関数と構造体に Doxygen 形式の日本語コメント（`/// @brief`）。bool の引数は「〜を設定する（true：〜、false：〜）」、構造体はメンバーを全部説明する。
- `.cpp` / `.h` は BOM付きUTF-8・CRLF。文字列は CP932 で表せる文字だけ（波ダッシュなどは使わない）。

**テストと確かめ方**

- 計算のファイルを足したら、主な動きだけをテストする（端っこ・おかしな入力だけのテストは足さない）。1/60 秒刻みで時間を進めたときの時間切れも1つ確かめる（開発ログの「盾の2秒タイマー」）。新しい計算のファイルは、まとめて1回わざと壊してテストが失敗するのを確かめる。

- **ワープ**：`Fighter` に `Teleport(const VEC3& position)`（位置を置き、水平の速さを 0。接地はそのまま）を足す。カメラは今のバネで追う（遠くへ飛ぶと少し遅れて追いつく）。保持されている・吹っ飛んでいる間は腕が使えないので出ない。
- **リペア**：手を胸の前に寄せ、緑の球を描く（直している間だけ）。
- **ロケットパンチ**：拳が飛んでいる間、腕は手首までの短い円柱だけ描く。
- **キャノン・ミサイルの爆発**：範囲の球を 0.15秒表示。
- **ガトリング**：銃身は細い円柱 3 本を腕のまわりに置き、撃っている間だけ回す（描画だけ）。ぶれは撃った回数で −2°・＋2°・0°… の決まった並び。
- **火炎放射**：炎は扇の中心の線に、だんだん大きくなる橙の球を 5 個並べる（時間で少し前後に動かす。描画だけ）。
- **フリーズ**：水色の球を扇の中心の線に並べて 0.2秒。
- **スモーク**：煙は1本の腕に1つ。煙がある間にもう一度押しても何もしない。煙の中の人は殴れば当たる（見えにくくするだけ）。
- **バリア**：ガードの間でも、もう片方の腕は使える（強すぎたら「バリアの間は腕を使えない」に変える。遊んで決める）。
- **アックス**：ダミーはガードしないので、ガード崩しは LOCAL VS（相手がデカ盾かバリア）で確かめる。

### 2.6 進め方と確かめ方

- 1タスク ＝ 1ブランチ ＝ 1 PR。段階2（Codex）は `docs/ai/` と `AGENTS.md` の【当面】の手順。Claude は段階3 で 2.3 の「テストと確かめ方」を行い、マージして tasks.md・Notion を ✅ にする。
- 段階3 の画面確認（腕ごと）：その腕をタイトルバーで確認してから、待機・攻撃の瞬間・当たったあとの3枚。ダミーで確かめられないもの（ガード・しびれで動けない・スモークのロックオン）は LOCAL VS で2人にして確かめる（キーボード＋パッド）。
- オンラインの DESYNC は、土台（No.59・70・75・80）のタスクで2つ起動して確かめる。腕だけのタスクでは、テストとビルドで済ませる。
