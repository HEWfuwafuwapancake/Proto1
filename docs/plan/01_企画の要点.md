# 企画の要点：腕ダフルアームズ（Proto1）

元の企画書：[企画書_腕ダフルアームズ.pptx](企画書_腕ダフルアームズ.pptx)（草案・1枚）

## 1. ゲームの概要（企画書より）

| 項目 | 内容 |
|---|---|
| タイトル | 腕ダフルアームズ |
| キャッチコピー | 変な腕でぶっ飛ばせ！ |
| ジャンル | 3D 乱闘アクション |
| プレイ人数 | 4人対戦 |
| プレイ時間 | 約3分 / 1試合 |
| 対応機種 | PC（パッド） |
| 視点 | 3D・背面視点（TPS） |

**コンセプト**
- **拾う！** 腕カプセルで腕チェンジ
- **組む！** 左右の腕は別々に装備
- **飛ばす！** 殴られるほど吹っ飛ぶ → 場外でアウト（逆転あり）
- **崩れる！** ステージがどんどん縮む
- 腕の組み合わせで戦い方が変わる

**そのほかの要素**
- 奪い取れ！：場外に落とすと腕がドロップ
- 合体！：同じ腕×2 でパワーアップ
- 地形も武器！：柱をつかんで場外から復帰

**腕の種類**

| 腕 | できること |
|---|---|
| ★ 触腕（タコ） | つかんで投げる |
| ★ メカアーム | 重い一撃・ガード |
| ★ ゴムアーム | 振り子で移動（柱をつかんで復帰） |
| ドリルアーム | 押し出す |
| 磁石アーム | 引き寄せ・反発 |
| カニのハサミ | 腕を封じる |

## 2. このプロトタイプで確かめたいこと

**「変な腕で相手をつかむ・殴る・投げて、場外へぶっ飛ばす」のが、パッドと TPS 視点で気持ちよく遊べるか。**
（はじめは触腕だけで確かめ、今は8種類の腕で確かめている）

- 腕を伸ばす・殴る・投げるが、狙ったとおりにできるか
- ダメージ％がたまるほど遠くへ飛ぶ（スマブラ式）が、分かりやすく気持ちいいか
- 制限時間の中でスコアを稼ぐ遊びが、短い時間でも楽しめるか

## 3. プロトでやること・やらないこと

| やること | やらないこと（プロトでは入れない） |
|---|---|
| TPS（背面）視点の 3D 乱闘アクション。1人（SOLO）・同じ PC で最大4人（LOCAL VS）・オンライン | 合体・腕を奪う・柱で復帰 |
| 8種類の腕（触手・ハンマー・ナックル・レーザー・刀・モーニングスター・槍・ミサイル）を、カプセルから拾って左右別々に装備する | ステージが崩れる・縮む |
| 空いた枠は CPU（強さ3段）かダミー（オンラインの空き枠はダミー） | 装備中の腕を自分で持ち替える操作（GAME のルール） |
| 対戦マップ6つ（郵便局・市場・ネオンビル群・コロシアム・廃駅・浮島） | |
| PS4 / PS5・XInput・Switch Pro 形式のパッドと、キーボードだけでも遊べる | |

## 4. プロトのルール

| ルール | 内容 |
|---|---|
| ルールの選択 | キャラ選択の画面で **GAME / DEBUG** を選ぶ（1P、オンラインはホスト）。そのあと 1P がマップを選ぶ |
| 制限時間 | **GAME は 180 秒、DEBUG は 90 秒** |
| 腕の装備 | GAME は両手とも素手で始まり、カプセルに触れると空いている手（左 → 右）に装備する。両手が埋まっているときはカプセルが残る。DEBUG は触手から始まり、試合中に腕を自由に切り替えられる |
| 腕の耐久 | GAME では腕ごとに耐久（最大100）があり、当たった・外れたで減る。使い切った腕は動作が終わると崩壊し、素手に戻る。DEBUG は減らない |
| ダメージ％ | 攻撃が当たると増える。試合開始と復活のときは 0％ |
| 吹っ飛び | **ダメージ％が高いほど、同じ攻撃でも遠くへ飛ぶ**（スマブラ式） |
| 場外 | 足場の下へ落ちるか、ステージの外周から決まった距離より外へ飛ぶと場外（距離はオプションで変えられる） |
| 復活 | 1.5 秒後。GAME は相手から離れた場所にランダムで復活し、両手とも素手に戻る。DEBUG は最初の場所に復活する |
| スコア | **相手を場外にぶっ飛ばしたら +1**。落ちても減点なし。ストックなし |
| 試合の終わり | 時間切れで終了し、順位を表示する。もう一度・キャラ選択へ・タイトルへを選べる |

## 5. 操作方法

操作の一覧（キーボード・パッドの両方）は [05_操作一覧.md](../team/05_操作一覧.md)、腕ごとの効き方は [03_新しいアームの仕様.md](03_新しいアームの仕様.md) にある。

- パッドは USB でつなぐ（Switch Pro 形式は Bluetooth も可）。DS4 / DualSense・XInput（GameSir Super Nova など）・Switch Pro 形式を混ぜて最大4台。Switch 2 Pro コンは USB で読む（確認待ち）。
- ボタンは位置で合わせる（下 → ×、右 → ○、左 → □、上 → △）。振動はソニーと XInput、ライトバーはソニーだけ。
