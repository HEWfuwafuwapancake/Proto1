# 企画の要点：腕ダフルアームズ（Proto1）

元の企画書：[企画書_腕ダフルアームズ.pptx](企画書_腕ダフルアームズ.pptx)（草案・1枚）

## 1. ゲームの概要（企画書より）

| 項目 | 内容 |
|---|---|
| タイトル | 腕ダフルアームズ |
| キャッチコピー | 変な腕でぶっ飛ばせ！ |
| ジャンル | 3D 乱闘アクション |
| プレイ人数 | 4人対戦 |
| プレイ時間 | 約3分 / 1試合 |
| 対応機種 | PC（パッド） |
| 視点 | 3D・背面視点（TPS） |

**コンセプト**
- **拾う！** 腕カプセルで腕チェンジ
- **組む！** 左右の腕は別々に装備
- **飛ばす！** 殴られるほど吹っ飛ぶ → 場外でアウト（逆転あり）
- **崩れる！** ステージがどんどん縮む
- 腕の組み合わせで戦い方が変わる

**そのほかの要素**
- 奪い取れ！：場外に落とすと腕がドロップ
- 合体！：同じ腕×2 でパワーアップ
- 地形も武器！：柱をつかんで場外から復帰

**腕の種類**

| 腕 | できること |
|---|---|
| ★ 触腕（タコ） | つかんで投げる |
| ★ メカアーム | 重い一撃・ガード |
| ★ ゴムアーム | 振り子で移動（柱をつかんで復帰） |
| ドリルアーム | 押し出す |
| 磁石アーム | 引き寄せ・反発 |
| カニのハサミ | 腕を封じる |

## 2. このプロトタイプで確かめたいこと

**「触腕で敵をつかんで場外へ投げ飛ばす」のが、PS4 コントローラーと TPS 視点で気持ちよく遊べるか。**

- 触腕を伸ばしてつかむ・投げるが、狙ったとおりにできるか
- ダメージ％がたまるほど遠くへ飛ぶ（スマブラ式）が、分かりやすく気持ちいいか
- 制限時間の中でスコアを稼ぐ遊びが、短い時間でも楽しめるか

## 3. プロトでやること・やらないこと

| やること | やらないこと（プロトでは入れない） |
|---|---|
| TPS（背面）視点の 3D 乱闘アクション | インターネット対戦・4人対戦 |
| PS4 純正コントローラー（DUALSHOCK 4）を PC に USB でつないで遊ぶ | ステージが崩れる・縮む |
| 腕は **触腕だけ**（左右とも触腕）：つかんで投げる | 腕カプセル・腕チェンジ・合体・腕を奪う・柱で復帰・ほかの腕 |
| 敵は **その場に立つダミー**（当たり判定あり） | 動いて攻撃してくる敵（ボット AI） |
| 制限時間の中で、敵を場外へぶっ飛ばすとスコアが増える | Maya のモデルの読み込み（はじめは箱・球・カプセルなどの仮の形） |

## 4. プロトのルール

| ルール | 内容 |
|---|---|
| 制限時間 | **90秒**（企画書の1試合は約3分。プロトは何度も試すので短め。あとで変えられるようにする） |
| 敵 | **ダミー3体**（自分 対 3体。企画書の4人対戦に合わせる） |
| ダメージ％ | 触腕で投げると、敵のダメージ％が増える（はたく攻撃は操作をシンプルにするため入れない。2026-10-24）。最初は 0％ |
| 吹っ飛び | **ダメージ％が高いほど、同じ攻撃でも遠くへ飛ぶ**（スマブラ式） |
| 場外 | ステージの外へ落ちたらアウト。ダミーはステージの上に戻って、ダメージ％は 0％ から |
| スコア | **ダミーを場外にぶっ飛ばしたら +1** |
| 試合の終わり | 時間切れで終了し、スコアを表示する。OPTIONS（キーボードは R）でやり直し |
| 自分が落ちたとき | ステージの上に戻る（プロトではスコアは減らさない） |

## 5. 操作方法

| 行動 | PS4 コントローラー（DUALSHOCK 4） | キーボード＋マウス |
|---|---|---|
| 移動 | 左スティック | W / A / S / D |
| カメラを回す | 右スティック | マウス |
| ジャンプ | × | Space |
| 左の触腕（伸ばしてつかむ／つかんでいる間にもう一度で投げる） | L1 | 左クリック |
| 右の触腕（同上） | R1 | 右クリック |
| やり直し | OPTIONS | R |
| 終了 | — | ESC |

- 触腕はカメラの左右の向きへ水平に伸ばし、投げる向きも水平にする。
- 画面中央付近・一定距離内の敵を自動でフォーカスし、その敵へカメラをゆっくり寄せる（sway）。手動操作中は弱まり、つかんでいる間は寄らない。
- PS4 コントローラーは USB ケーブルで PC につなぐ（Bluetooth はプロトでは確かめない）。

## 6. あとで決めること

- 触腕の長さ・伸びる速さ、つかめる時間、投げる強さ（No.13 のときに、試しながら決める）
- 吹っ飛びの計算の細かい式（No.12 のプランで出す）
- ステージの大きさと形（No.7 のプランで出す）
- Maya のモデルを使い始める時期（No.22。FBX か OBJ での書き出しをお願いする）
