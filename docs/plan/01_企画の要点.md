# 企画の要点：腕ダフルアームズ（Proto1）

元の企画書：[企画書_腕ダフルアームズ.pptx](企画書_腕ダフルアームズ.pptx)（草案・1枚）

## 1. ゲームの概要（企画書より）

| 項目 | 内容 |
|---|---|
| タイトル | 腕ダフルアームズ |
| キャッチコピー | 変な腕でぶっ飛ばせ！ |
| ジャンル | 3D 乱闘アクション |
| プレイ人数 | 4人対戦 |
| プレイ時間 | 約3分 / 1試合 |
| 対応機種 | PC（パッド） |
| 視点 | 3D・背面視点（TPS） |

**コンセプト**
- **拾う！** 腕カプセルで腕チェンジ
- **組む！** 左右の腕は別々に装備
- **飛ばす！** 殴られるほど吹っ飛ぶ → 場外でアウト（逆転あり）
- **崩れる！** ステージがどんどん縮む
- 腕の組み合わせで戦い方が変わる

**そのほかの要素**
- 奪い取れ！：場外に落とすと腕がドロップ
- 合体！：同じ腕×2 でパワーアップ
- 地形も武器！：柱をつかんで場外から復帰

**腕の種類**

| 腕 | できること |
|---|---|
| ★ 触腕（タコ） | つかんで投げる |
| ★ メカアーム | 重い一撃・ガード |
| ★ ゴムアーム | 振り子で移動（柱をつかんで復帰） |
| ドリルアーム | 押し出す |
| 磁石アーム | 引き寄せ・反発 |
| カニのハサミ | 腕を封じる |

## 2. このプロトタイプで確かめたいこと

**「触腕で敵をつかんで場外へ投げ飛ばす」のが、PS4 コントローラーと TPS 視点で気持ちよく遊べるか。**

- 触腕を伸ばしてつかむ・投げるが、狙ったとおりにできるか
- ダメージ％がたまるほど遠くへ飛ぶ（スマブラ式）が、分かりやすく気持ちいいか
- 制限時間の中でスコアを稼ぐ遊びが、短い時間でも楽しめるか

## 3. プロトでやること・やらないこと

| やること | やらないこと（プロトでは入れない） |
|---|---|
| TPS（背面）視点の 3D 乱闘アクション（SOLO・LOCAL VS・オンライン） | 合体・腕を奪う・柱で復帰 |
| DS4 / DualSense（USB）、XInput、Switch Pro 形式（057E:2009）を PC につないで遊ぶ | ステージが崩れる・縮む |
| 腕カプセルから触腕・ハンマー・ナックル・C4・ガンランス・刀を拾い、左右別々に装備する | 装備中の腕を任意に持ち替える操作（GAME） |
| SOLO の敵は **その場に立つダミー**（当たり判定あり） | 動いて攻撃してくる敵（ボット AI） |

## 4. プロトのルール

| ルール | 内容 |
|---|---|
| ルールの選択 | キャラを選んだあとに **GAME / DEBUG** を選ぶ。オンラインではホストのルールで遊ぶ |
| 制限時間 | **GAME は 180 秒、DEBUG は 90 秒** |
| 腕の装備 | GAME は両手とも素手で始まり、カプセルに触れると空いている手（左 → 右）に装備する。両手が埋まっているときはカプセルが残る。DEBUG は触腕から始まり、試合中に腕を自由に切り替えられる |
| 腕の使用回数 | GAME では腕を敵や足場に使ったときに減る。ガンランスは撃つたびに1発減る。使い切った腕は動作と残っている弾などが終わると崩壊し、素手に戻る。DEBUG は回数無制限 |
| ダメージ％ | 攻撃が当たると増える。試合開始と復活のときは 0％ |
| 吹っ飛び | **ダメージ％が高いほど、同じ攻撃でも遠くへ飛ぶ**（スマブラ式） |
| 場外と復活 | GAME は相手から離れた候補からランダムに復活し、両手とも素手に戻る。安全な候補がなければ、最も近い相手との距離が最大の候補を使う。DEBUG は最初の場所に復活する |
| スコア | **相手を場外にぶっ飛ばしたら +1**。ストックなし |
| 試合の終わり | 時間切れで終了し、スコアを表示する。OPTIONS（キーボードは R）でやり直し |

## 5. 操作方法

| 行動 | PS4 コントローラー（DUALSHOCK 4） | キーボード＋マウス |
|---|---|---|
| 移動 | 左スティック | W / A / S / D |
| カメラを回す | 右スティック | マウス |
| ジャンプ | × | Space |
| 左の触腕（伸ばしてつかむ／つかんでいる間にもう一度で投げる） | L1 | 左クリック |
| 右の触腕（同上） | R1 | 右クリック |
| やり直し | OPTIONS | R |
| メニューの選択（選んでいる項目を強調） | 左スティックの上下 | W / S |
| メニューの決定・TIME UP から結果へ | ○ | Enter |
| 終了 | — | ESC |

- 触腕はカメラの左右の向きへ水平に伸ばし、投げる向きも水平にする。
- カメラは角度・距離・見ている点を別々のバネでなめらかに追う。小さな動きとジャンプでは揺れず、試合中は横移動に合わせて円を描いて回る（sway。自分で回したあとは少し止まる）。
- DS4 / DualSense は USB 接続。GameSir Super Nova は受信機か有線の XInput モード、Switch Pro 形式（057E:2009）は USB・Bluetooth で使う。Switch 2 Pro コンは保留。ソニー・XInput・Switch を混ぜて最大4台。
- ボタンは位置で合わせる（下→×、右→○、左→□、上→△）。振動はソニーと XInput、ライトバーはソニーだけ。Switch Pro 形式の振動・ジャイロ・プレイヤーランプは使わない。
