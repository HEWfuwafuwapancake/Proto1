# No.13 触腕の実装プラン

最終更新：2026-10-23（Codex）。管理者が承認したプランに沿って実装済み。Debug / Release とも103テスト成功、ゲームビルド警告0。画面での起動・保持表示を確認。網羅的な手動試遊とパッド実機確認は未実施。

## 操作と動き

- 左右クリック／L1・R1 で、それぞれの腕をカメラの上下左右の向きへ伸ばす。伸ばす方向は押した瞬間に固定する。
- 最初に当たった有効なダミー1体をつかみ、腕を縮めて手元へ引き寄せる。保持位置はプレイヤーの前方・左右に分ける。
- つかんでいる間に同じボタンをもう一度押すと、その時点のカメラの向きへ投げる。引き寄せ中も投げられる。
- 空振りは最大距離で縮み、戻ったら再使用できる。伸縮中の連打は予約しない。
- 左右で別々の敵を持てる。同じ敵の二重つかみを防ぎ、同時命中は左腕を先に処理する。
- つかんでいる間は敵の通常移動・吹っ飛び・プレイヤーとの押し合いを止める。時間切れではダメージを与えず離す。
- プレイヤーの場外復活では両腕をリセットし、保持中の敵を復活先へ連れてこない。消えた敵への参照も解除する。
- 腕は球をつないで描画し、左右と保持中が色で分かるようにする。

## 最初に試す仮の値

最大長さ 8、伸びる速さ 24/秒、縮む速さ 30/秒、保持は命中から 3 秒。
投げは 12% 加算・強さ 2.0。値は調整用定数にまとめ、実際に遊んで調整する。

## 変更するコード

- `src/physics/tentaclecalc.h / .cpp`：待機・伸長・引き寄せ／保持・収縮の状態と時間、命中候補の選択、保持の所有関係を DirectX なしで計算する。
- `src/game/tentacle.h / .cpp`：入力、左右の腕、ダミーとの連携、球の描画を担当する。
- `src/game/dummy.h / .cpp`：当たり判定取得、つかめるかの判定、保持・解放・位置更新を追加する。F1 の仮攻撃を削除する。
- `src/game/camera.h / .cpp`：描画と共通の3Dの向きを取得できるようにする。
- `src/game/player.h / .cpp`：そのフレームで場外復活したことを腕側で判断できるようにする。
- `src/physics/knockbackcalc.h / .cpp` と `DummyHit`：既存の水平＋固定角の攻撃を維持しつつ、触腕用に上下を含む指定方向への投げを追加する。速さとダメージ計算は共通化する。
- `src/core/main.cpp`：既存の Player → Dummy → Camera の後に Tentacle を更新する。保持中の敵は DummyUpdate で通常物理を進めず、TentacleUpdate で保持位置を確定する。初期化・終了・描画にも追加する。
- `.vcxproj`・`.vcxproj.filters`、単体テスト、構成ドキュメントを更新する。

## 当たり判定と確認

伸長部分を斜めのカプセルとして `CollisionCapsuleCapsule` で判定し、1フレームの伸長で敵を飛び越えないようにする。
複数の敵に重なる場合は手前を選ぶ。`HIT_RECORD` で同じ伸長中の重複命中を防ぐ。
腕が浮島を通って裏側の敵をつかまないようにし、保持位置が足場にめり込む場合も補正する。

- 単体テスト：空振りと復帰、命中から保持・投げ・時間切れ、連打、左右の競合、複数候補の順序、復活時解除、時間停止、上下を向いた投げと既存の吹っ飛び計算。
- 追加テストは計算を一時的に壊して失敗を確認し、元に戻す。
- `run-tests.ps1` と Release のテスト、Debug / Release x64 のビルド（警告0）を確認する。MSBuild は vswhere で探す。
- 起動確認：左右のつかみと投げ、カメラを回して投げる、ダメージによる飛距離の増加、場外と復活。PS4 パッドの実機確認は No.6 と合わせて管理者が操作して確認する。
