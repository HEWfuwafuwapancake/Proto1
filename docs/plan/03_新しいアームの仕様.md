# 新しいアームの仕様

初期案は管理者確認済み（2026-10-26）。現在の6本は No.93〜133 の仕様を使う（最終更新：2026-11-13、Codex）。新しい腕のプランを作るとき・腕の動きを変えるときに読む。調整値は各腕のファイルの上にまとめる。

- 腕は L1 / R1（左右クリック）で操作する。単押し・長押しや、効いている間の追加入力は腕ごとに決める。
- 長押しの攻撃は、0.25秒押し続けるとため（構えた姿勢）に入り、押している間はためた姿勢で待ち、ボタンを離した瞬間にためを飛ばしてすぐ出す（No.156・160）。触手・ハンマー・ナックルが対象。ため中にガードなどでボタンを受け付けなくなったら出さずにやめる。レーザーは例外で、押し始めから3秒溜める（下の表）。
- 吹っ飛ぶ速さは（4.0 ＋ ダメージ% × 0.06）× 攻撃の強さ。100% で以前の 50% と同じ速さにする（No.121）。
- **GAME** では、腕カプセルに触れると空いている手（左 → 右）に装備する。使い切った腕は動作が終わると素手に戻る。復活時は両手が素手になる。最大耐久は全腕100、少しでも残っていれば強攻撃も使える。1動作の命中・空振り・中断は1回だけ消費する。設定「腕の耐久の持ち」で減る量を倍率で割り、切り上げる（無制限は減らない）。
- **DEBUG** では、数字キーで左手、Shift＋数字で右手を切り替える。Q / E で左手・右手の切り替えモードを選べる。パッドでは十字キー ← / → で手を選び、↓ / ↑ で次 / 前の腕に切り替える。耐久は減るが0でも壊れず、攻撃・ガードも使える。数字キー・十字キーで付け直すと100に戻る。
- **作り方**（No.44 のあと）：腕ごとの処理は `src/game/arm_〇〇.h / .cpp` の `Arm` の派生クラス、計算は `src/physics/〇〇calc.h / .cpp` の DirectX なしのクラス（テストする）。`arm.cpp` の `ARM_FACTORIES` の1行を `CreateArm<〇〇Arm>` にする。
  描画は `Arm::LoadModel` と `Arm::DrawPiece`（中で `TentacleCalcPieceAxes`）を使う（そのため OBJ の向きは触腕と同じ -Y が伸びる向きにそろえる）。グラップリングのワイヤーは細い円柱で描く。

- **ガードとパリィ（No.118）**：ZL / ZR（キーボード Z / X）で待機中のその手の腕を使い、前の左右80°を防ぐ。歩く速さは半分。構え始め0.2秒以内のパリィでは耐久が減らず、それ以降に防ぐと耐久が50減る。GAME では0になったら素手になる（DEBUG は耐久が減っても壊れない）。パリィは黄色い光と「PARRY!」、ガードは灰色の光と「GUARD」を出す（No.132）。構えを解いて0.5秒未満の構え直しではパリィなし。素手では構えられない。
- **掴まれ中の抵抗（No.117）**：ジャンプ・左右の腕・ダッシュの押した瞬間と、移動スティックの倒し直しを数え、6回＋ダメージ%÷25の切り上げ（上限14回）でダメージなしに離れる。
