# 新しいアームの仕様

管理者確認済み（2026-10-26）。新しい腕のプランを作るとき・腕の動きを変えるときに読む（`docs/handoff.md` から移した）。各腕の細かい値は、その腕のプランで決める。

- **全部の腕で同じ**：操作は L1 / R1（左右クリック）だけ。腕ごとに「押したとき」と「効いている間にもう一度押したとき」を決める（「操作はシンプルに」）。
  装備は試すための切り替えだけ（キーボードの Q / E で左手・右手の切り替えモード（押す回数で1〜3段目）→ 数字キー 1〜9・0。数字だけなら左手、Shift＋数字なら右手。パッドの十字キー ← / → で手を選び、↓ / ↑ で次 / 前の腕に切り替える。使える腕だけを順に一周する）。腕カプセルは作らない。色は今の左右の色と、効いている間の色だけ。
- **作り方**（No.44 のあと）：腕ごとの処理は `src/game/arm_〇〇.h / .cpp` の `Arm` の派生クラス、計算は `src/physics/〇〇calc.h / .cpp` の DirectX なしのクラス（テストする）。`arm.cpp` の `ARM_FACTORIES` の1行を `CreateArm<〇〇Arm>` にする。
  描画は `Arm::LoadModel` と `Arm::DrawPiece`（中で `TentacleCalcPieceAxes`）を使う（そのため OBJ の向きは触腕と同じ -Y が伸びる向きにそろえる）。グラップリングのワイヤーは細い円柱で描く。

| 腕 | 押したとき | もう一度押したとき | 敵への効き方 |
|---|---|---|---|
| 触腕 | 伸ばしてつかむ | 投げる | % ＋12・吹っ飛ぶ |
| グラップリング（No.36） | フックを撃ち、刺さった所へ自分が引っぱられて飛ぶ。刺さるのは敵と浮島のふち | 途中で押すと離す | 敵なら着いたときの体当たりで小さく吹っ飛ばす（＋5）。ふちに刺されば場外から戻れる |
| ドリル（No.37） | 伸ばさずに突き出す（近い敵だけ）。当たった敵に 0.5 秒くい込み % が小刻みに大きく増える（＋4 × 5回） | なし（自動で戻る） | 最後に水平に押し出す（上にはあまり飛ばない） |
| 磁石（No.38） | ターゲット（いなければ正面）を自分の前まで引き寄せる（ダメージなし） | 引き寄せている間なら反発して強く吹っ飛ばす | 反発で % ＋8 |
| デカ盾（No.39） | 前に構えて遅く歩く（離しても構えたまま、2 秒で下ろす） | 構えている間なら盾で押す | 前の敵を % に関係なく一定の強さで押し出す（% ＋0）。構え・押し出し中は前の左右 60° からの攻撃を防ぐ（No.80） |
| ハサミ（No.40・最後） | 相手の腕を切り落とす | — | 切られた相手は新しい腕を探す。相手が腕を使う No.24 と、腕を拾う No.27（腕カプセル）のあと |
| ナックル（No.60。パイルバンカーをまとめた） | 0.12秒引いて殴る（肩から 1.6・半径 0.5） | なし | ＋10%・強さ2.2。殴った瞬間に相手が肩から 1.0 以内なら杭で ＋14%・強さ2.8（休みが長い） |
| ブレード（No.61。ビームサーベルをまとめた） | 1振り目（扇：半径 1.8・左右 60°） | 0.35秒以内に押すと2振り目、もう一度で3振り目 | 1・2振り目 ＋4%（速さ 1.5 で押す）、3振り目 ＋6%・強さ1.8 |
| スピア（No.62） | 0.2秒溜めて突く（長さ 3.5・半径 0.35 の線） | なし | 線の上の相手全員に ＋9%・強さ2.0 |
| ハンマー（No.63） | 0.5秒振り上げて前の足元を叩く（歩く速さ 0.5） | なし | 前 1.6 の足元を中心に半径 1.6 の相手に ＋13%・強さ2.4（外へ＋上へ打ち上げる） |
