# 新しいアームの仕様

管理者確認済み（2026-10-26）。新しい腕のプランを作るとき・腕の動きを変えるときに読む（`docs/handoff.md` から移した）。各腕の細かい値は、その腕のプランで決める。

- 腕は L1 / R1（左右クリック）で操作する。単押し・長押しや、効いている間の追加入力は腕ごとに決める。
- **GAME** では、腕カプセルに触れると空いている手（左 → 右）に装備する。使い切った腕は動作が終わると素手に戻る。復活時は両手が素手になる。
- **DEBUG** では、数字キーで左手、Shift＋数字で右手を切り替える。Q / E で左手・右手の切り替えモードを選べる。パッドでは十字キー ← / → で手を選び、↓ / ↑ で次 / 前の腕に切り替える。使用回数は無制限。
- **作り方**（No.44 のあと）：腕ごとの処理は `src/game/arm_〇〇.h / .cpp` の `Arm` の派生クラス、計算は `src/physics/〇〇calc.h / .cpp` の DirectX なしのクラス（テストする）。`arm.cpp` の `ARM_FACTORIES` の1行を `CreateArm<〇〇Arm>` にする。
  描画は `Arm::LoadModel` と `Arm::DrawPiece`（中で `TentacleCalcPieceAxes`）を使う（そのため OBJ の向きは触腕と同じ -Y が伸びる向きにそろえる）。グラップリングのワイヤーは細い円柱で描く。
