## 今の作り（読んで確かめた所）

- 体の計算は `src/physics/playercalc.h / .cpp` の `PlayerBodyCalc::Step`。ジャンプは足場に立っているときだけ。落ちる速さに上限はない。
- 吹っ飛び中は `src/game/fighter.cpp` の `Fighter::Update` が `KnockbackCalcStep` だけを呼び、入力を読まない。
- `Fighter::CanUseArms()`（`fighter.h`）は吹っ飛び中 false。これを `arm.cpp`（腕の中断）・`fighter.cpp` の `UpdateFacing`・
  `fightermanager.cpp` の `PushBodies`（体当たり）が使っている。
- 重力は `fighter.cpp` の `GRAVITY = 25`（ふつうの落下と吹っ飛びの両方）、ジャンプは `JUMP_SPEED = 9`、歩きは `MOVE_SPEED = 6`。

## やること

### 1. 落下を少し遅くする

- `PLAYER_PARAMS` と `KNOCKBACK_PARAMS` に「落ちる速さの上限」を足し、下向きの速さがそれを超えないようにする（上昇は変えない）。
- はじめの値：`MAX_FALL_SPEED = 12`（ふつうのジャンプの着地は約 9 なので、ジャンプの感触は変わらない。高い所からと場外への落下だけ遅くなる）。

### 2. 空中ジャンプ

- 空中で1回だけジャンプできる（着地で戻る）。上向きの速さは地上と同じ `JUMP_SPEED`。落ちている途中でも、押した瞬間に上向きの速さへ置きかえる。
- 回数は `PLAYER_PARAMS` に持たせ、残りは `PlayerBodyCalc` が覚える。はじめの値：`AIR_JUMPS = 1`。
- 復活したとき・掴まれたとき（`Fighter::Grab`）は残りを戻す。

### 3. 吹っ飛び中もすぐ動ける

- 吹っ飛び中（`m_Launched`）も、待ち時間なしで次ができるようにする。
  - **移動の入力**：横へ加速できる。吹っ飛びの速度は消さず、入力の向きへ少しずつ足す（はじめの値：`AIR_CONTROL = 12`／秒²）。
    自分の入力だけで歩く速さより速くはならない（入力の向きの速さが `MOVE_SPEED` 未満のときだけ足す）。
  - **空中ジャンプ**：残りがあれば出せる。上下の速さだけを置きかえ、横の速さは残す。
  - **ダッシュ**：下の 4 のとおり。
  - **腕**：`CanUseArms()` から「吹っ飛び中は使えない」を外す。
- `CanUseArms()` を変えると体当たり（`PushBodies`）まで変わるので、**体当たりは今のまま**にする：
  `Fighter` に「体当たりで押し合えるか」（今の `CanUseArms` と同じ条件）の取得関数を足し、`PushBodies` の条件の1行だけをそれに替える。
- 吹っ飛びが終わる条件（足場の上で遅くなったら止まる）は変えない。
- しびれ（`STATUS_STUN`）中は、今までどおり何もできない。

### 4. ダッシュ

- `ACTION_DASH` を押した瞬間、移動の入力の向き（入力がなければキャラの向き）へ水平にダッシュする。
- はじめの値：速さ `DASH_SPEED = 18`、長さ `DASH_SECONDS = 0.2`（約 3.6 進む）、休み `DASH_COOLDOWN = 0.6` 秒（ダッシュが終わってから数える）。
- ダッシュ中は上下の速さを 0 にして落ちない。地上でも空中でも出せる。**空中では着地まで1回**。
- 吹っ飛び中に出したときは、吹っ飛びの速度を消さずに、ダッシュの速さ × 向きを横の速度に1回足すだけにする（吹っ飛びを帳消しにできないように）。
- 腕の突進（`ArmManager::GetRushVelocity`）が出ている間、掴まれている間、引っぱられている間（`m_Pulled`）、しびれ中は出せない。
- 計算は `src/physics/dashcalc.h / .cpp` に `DashCalc` クラスで書く（残り時間・休み・空中で使ったか・向きを覚え、1フレームごとに「今のダッシュの速度」を返す）。
  `Fighter` が1つ持ち、`Fighter::Update` で進める。DirectX は使わない。
- 見た目：専用のアニメは作らない（今の走りのまま速く動く）。

## テスト（主な動きだけ）

- 落下：長く落ちても速さが上限を超えない。ふつうのジャンプの高さは変わらない。
- 空中ジャンプ：空中で1回出せて2回目は出せない。着地で戻る。
- 吹っ飛び中：入力を入れると横の速さが入力の向きへ変わる。入力なしなら今までと同じ動き。
- ダッシュ：決めた時間だけ進んで止まる。休みの間は出せない。空中で2回目は出せず、着地で戻る。

## 確かめること（ゲームで）

- 高台から飛び降りる・場外へ落ちるのが前より遅く、ジャンプの感触は変わらないこと。
- 空中ジャンプ、地上と空中のダッシュ、ダッシュの休み。
- ダミーに吹っ飛ばされる手段がないので、吹っ飛び中の操作は LOCAL VS（2P をキーボードかパッド）か2つ起動のオンラインで試す。試せなければ PR に「未確認」と書く。
- 触手の足場への移動、刀の長押しのワープ、ガンランス・ナックルの突進が今までどおり動くこと。
