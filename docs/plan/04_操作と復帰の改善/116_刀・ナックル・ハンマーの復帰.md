## 今の作り（読んで確かめた所）

- 刀（`src/game/arm_katana.cpp`）：単押しは居合（構え 0.3 秒 → 一閃 → 残心。構えの出だし 0.2 秒は受け流し、受け流すと強い一閃。
  当たった相手には 0.4 秒後にダメージ）。長押しは狙った着地点へ一直線に飛ぶワープ（`BREACH_〇〇`。飛んでいる間は `SetPulled(true)` で体の計算を止め、
  `SetPosition` で自分で動かす）。着地点は `BreachCalcFindLanding` がカメラの向きの線から探す。
- ナックル（`arm_knuckle.cpp`）：長押しは `GetRushVelocity` で水平に突進する。この速度は**水平だけ**しか体に伝わらない。
- ハンマー（`arm_hammer.cpp`）：単押しはため 0.9 秒 → 前を叩く。長押しは衝撃波。
- 場外から戻れるのは触手だけ。

## やること

### 1. 刀の単押しを「ただの斬撃」にする

- 構え・受け流し・返しの一閃・踏み込み・遅れて入るダメージをなくし、押したらすぐ振る。
- はじめの値：振りかぶり 0.1 秒 → 斬る 0.1 秒 → 休み 0.25 秒。前の扇（半径 2.2・左右 60°）、＋8%・強さ 1.6、当たった瞬間にダメージ。
- `GetGuard` の受け流しの部分を消す（飛んでいる間の無敵はそのまま残す）。`ConsumeGuardedHit` を呼んでいる所も消す。
- アニメは今の居合のクリップ（`ATTACK_CLIP::KatanaIai`）の、抜いて斬る部分を使う（新しいクリップは作らない）。

### 2. 刀の長押しに、居合の斬撃を付ける

- 今のワープ（構える → 離すと空間を斬って飛ぶ）はそのまま。**着いた瞬間**に、飛んだ向きを前として居合の一閃の判定を出す。
- 判定とダメージは今の居合の値を使う（扇：半径 3.0・左右 60°、＋12%・強さ 2.4、当たった相手に 0.4 秒後にダメージ。斬撃の線の見た目もそのまま）。
- 使用回数は今までどおり、飛んだときに1回減る（斬撃では減らさない）。

### 3. 刀の長押しで場外から戻れるようにする

- 空中で構えて離したら、空間を斬っている間（`BREACH_CUT`）も `SetPulled(true)` で落下を止める。
- 場外に落ちている（足場の上にいなくて、足元が浮島の上面より下）ときに、カメラの狙いで着地点が見つからなければ、
  **いちばん近い足場の上の点**（ふちから少し内側）を着地点にする。
- 「いちばん近い足場の上の点」を求める計算は `src/physics/risecalc.h / .cpp` に書く（`STAGE` と位置を受け取る。DirectX は使わない）。

### 4. ナックル：空中の長押しは前斜め上へ突進する

- 地上の長押しは今のまま。空中で突進が始まったとき（`KNUCKLE_STRIKE` に入ったとき空中）は、狙いの向きを約 40° 上げた向きへ進む。
- 水平の速度しか体に伝わらないので、刀のワープと同じやり方（`SetPulled(true)`＋`SetPosition`）で自分で動かす。
  終わり・中断（`Reset`・`Interrupt`）で必ず `SetPulled(false)` に戻す。
- 進む量の計算（向きと速さから1フレームの移動）は `risecalc` に書く。速さ・時間は今の突進（`RUSH_SPEED = 28`・0.35 秒）を使う。
- 相手に当たったら止まるのは今までどおり。

### 5. ハンマー：空中の単押しは上へ跳ねる

- 地上の単押しは今のまま。空中で単押ししたときは、ためを 0.3 秒に縮め、振った瞬間に真上へ跳ねる（はじめの値：高さ 4.0 を 0.3 秒で上がる）。
  移動の入力があれば、その向きへ少し進む（はじめの値：水平 2.0）。
- 動かし方はナックルと同じ（`SetPulled`＋`SetPosition`。計算は `risecalc`）。
- 跳ね始めに、いつもの叩きの判定も出す（空中の相手に当たる）。

### 6. 使用回数（GAME）

- ナックル・ハンマーを空中の復帰に使ったら、相手に当たらなくても1回減らす（刀の長押しと同じ）。同じ動作で相手に当たっても、減るのは合わせて1回。

## 実装したこと（2026-11-12、Claude）

- 刀の単押し：振りかぶり 0.1 秒 → 斬る 0.1 秒 → 休み 0.25 秒。値は `arm_katana.cpp` の `TAP_〇〇`。居合の値（`IAI_〇〇`）は長押しで着いた瞬間の一閃に使う。
- 刀の長押し：空中で斬り始めると、斬っている間と飛んでいる間は落ちない。場外（空中で、足元が浮島の上面より下）では、狙いに着地点がなければ近い足場のふちから 1.0 内側へ飛ぶ。
- ナックル：空中の長押しは、突進が始まった瞬間に空中なら前斜め上 40°（`AIR_RUSH_PITCH`）へ、地上と同じ距離だけ進む。
- ハンマー：空中で単押しを始めると、ため 0.3 秒 → 振った瞬間に 0.3 秒で 4.0 上へ跳ねる（`HOP_〇〇`）。振る前に着地していたら跳ねない。
- 体は腕が `SetPulled`＋`SetPosition` で直接動かすので、足場の中を通り抜けることがある（下から上へ抜けて、上に出れば着地する）。
- ゲームを動かしての確認はまだ（ビルドとテストだけ）。
