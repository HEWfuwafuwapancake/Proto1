## 今の作り（読んで確かめた所）

- 掴みは `FighterManager::Grab` → `Fighter::Grab(holder)`。掴まれている間（`Fighter::IsHeld()`）、`Fighter::Update` は体を動かさず、入力も読まない。
- 離すのは `Fighter::Release(holder)`（掴んでいる人の番号が合っているときだけ）。
- 掴む側の腕（触手 `tentacle.cpp`、ガンランス `arm_gunlance.cpp`）は、毎フレーム `GetFighters().IsHeldBy(相手, 自分)` を見て、
  外れていたら自分で動作をやめる。**だから、掴まれた側を `Release` するだけで両方が正しく止まる。**
- 入力は `Fighter::IsTrigger(ACTION)`・`Fighter::GetMoveInput()` で読める（どちらも `public`）。ダミーは入力がいつも空。

## やること

- 掴まれている人が**連打**すると、決めた回数で抜ける。数えるのは次の入力：
  - ジャンプ・左腕・右腕・ダッシュ（`ACTION_JUMP`・`ACTION_ARM_LEFT`・`ACTION_ARM_RIGHT`・`ACTION_DASH`）を押した瞬間。
  - 移動スティック（キー）を倒し直した瞬間（倒した大きさが 0.3 以下に戻ってから 0.7 を超えたら1回）。
- 必要な回数は % が高いほど増える。はじめの値：`ESCAPE_BASE = 6` 回 ＋ %÷25（小数は切り上げ）。上限 `ESCAPE_MAX = 14` 回。
- 抜けたとき：その場で離れる（ダメージ・吹っ飛びなし）。抜けたあとは、ふつうに落ちたり動いたりできる。
- 掴まれ直したら、数えた回数は 0 に戻る。
- ダミーは抜けない（入力がないので何もしなくてよい）。

### 作り方

- 計算は `src/physics/escapecalc.h / .cpp` に `EscapeCalc` クラスで書く（数えた回数・スティックを戻したかを覚える。
  1フレームごとに「ボタンを押した数・スティックの大きさ・今の %」を受け取り、抜けたら true を返す。DirectX は使わない）。
- `FighterManager` が人数分の `EscapeCalc` を持ち、`FighterManager::Update` の中（体の更新のあと）で、掴まれている体について進める。
  抜けたら、掴んでいる人の番号を探して（`IsHeldBy` を 0〜3 で調べる）`m_Fighters[i].Release(holder)` を呼ぶ。
- 掴まれていない体の `EscapeCalc` は毎フレーム戻しておく。`FighterManager::Reset` でも戻す。

## テスト（主な動きだけ）

`escapecalc_test.cpp`：

- 決めた回数だけ押すと抜け、1回足りないと抜けない。
- % が高いと必要な回数が増える。
- スティックを倒しっぱなしでは1回しか数えず、戻して倒し直すと数える。

## 実装したこと（2026-11-12、Codex）

- `EscapeCalc` がボタンとスティックの倒し直しを数える。必要な回数は6＋%÷25の切り上げ、上限14。`FighterManager` が体の更新後に進め、達したらダメージなしで離す。
- 初期化・リセット・掴みの成立時に回数を戻す。同じフレームに掴まれ直しても持ち越さない。`PushBodies` と腕ごとのファイルは変更していない。
- Debug / Release ビルド警告0、単体テスト各341件通過。新しい計算をまとめて壊して3件が失敗し、復元後3件すべて通過した。
- 触手・ガンランスからの脱出、2人での操作、オンライン・振動は、管理者が「問題ないことにする」とした（2026-11-12）。
