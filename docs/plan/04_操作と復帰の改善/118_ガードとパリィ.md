## 決まっていること（管理者、2026-11-12）

- パリィ専用のボタンは作らない。**ガード**を足す。
- ZL（L2）を押すと左の腕、ZR（R2）を押すと右の腕でガードする。
- ガードは腕を犠牲にする。**パリィが成功すれば腕を失わない。**

## 今の作り（読んで確かめた所）

- ガードの仕組みはもうある：`ArmManager::GetGuard()`（`src/game/arm.cpp`）が左右の腕の `GetGuard()` の強いほうを返し、
  `FighterManager::CanAttack` が `IsGuarded` を見て、防いだ攻撃を無効にして `m_GuardedHit[防いだ人] = true` を立てる。
  `FighterManager::ConsumeGuardedHit(slot)` で「防いだか」を読んで消せる。
- `Hit`・`Launch`・`AddDamage`・`Push`・`ApplyStatus`・`Grab` は全部 `CanAttack` を通るので、**掴みもガードで防げる**。
  投げ（`Release`）と燃えるダメージは通らない（今のまま）。
- ガードの向きは「攻撃した人の体の中心」から判定する（`GuardCalcBlocks`。`src/physics/guardcalc.h`）。
- 腕の入力と使用回数は `ArmManager::Update` が受け持つ。腕を素手にするのは `ChangeType(hand, ARM_TYPE_NONE)`。
- 刀の居合が `ConsumeGuardedHit` を使っている（No.116 で消える）。**ぶつからないよう、こちらはガードを構えている間だけ読む。**

## やること

### 1. ガード

- `ACTION_GUARD_LEFT` を押している間は左手、`ACTION_GUARD_RIGHT` を押している間は右手の腕でガードを構える。
- 構えられる条件：その手が素手でない・その手の腕が待機中（`IsActive()` も `IsBusy()` も false）・`CanUseArms()`・しびれていない。
  GAME で使用回数が残っていない腕でも、まだ付いていれば構えられる。
- 構えている間：
  - 前の左右 80° を防ぐ（`GUARD_FRONT`。前はキャラの向き）。`ArmManager::GetGuard()` で、腕そのもののガードと強いほうを返す。
  - その手の腕は攻撃できない（その手の `ARM_INPUT` は空にし、押していた入力は離すまで引き継がない）。
  - 歩く速さは 0.5 倍（`ArmManager::GetMoveScale()`）。
- 両手で構えているときは、後から押した手で受ける。

### 2. 攻撃を受けたとき

構えている間、毎フレーム `m_Links.Fighters->ConsumeGuardedHit(自分のスロット)` を読む。true なら「このフレームに1回防いだ」。

- **パリィ**：構え始めてから `PARRY_SECONDS = 0.2` 秒以内に防いだ → 腕を失わない。構えはそのまま続けられる。
- **ふつうのガード**：それより後に防いだ → 攻撃は防ぐが、受けた手の腕が壊れて素手になる（`ChangeType(hand, ARM_TYPE_NONE)`）。
  - DEBUG のルールでは壊れない（回数が無制限なので）。
- 連打でいつもパリィにならないように、構えを解いてから `PARRY_REARM_SECONDS = 0.5` 秒の間に構え直したときは、パリィの受付なしで始まる（ガードはできる）。
- 計算は `src/physics/parrycalc.h / .cpp` に `ParryCalc` クラスで書く（片手1つ。構えているか・構えてからの秒数・解いてからの秒数を覚え、
  「防いだ」を渡すと パリィ／腕を失う のどちらかを返す。DirectX は使わない）。`ArmManager` が左右2つ持つ。

### 3. 見た目と手ごたえ

- 構えている手の肩の前に、小さな球を1つ描く（`ShapeDrawSphere`。パリィの受付中は明るい色、それ以外はふつうの色）。腕の構えのアニメは作らない。
- パリィが成功したらパッドを短く強く、腕が壊れたら長めに振動させる（`PadRumble`。`Arm::Rumble` と同じやり方）。

## テスト（主な動きだけ）

`parrycalc_test.cpp`（時間は 1/60 秒刻みで進める）：

- 構えてすぐ防ぐとパリィ、受付の時間を過ぎてから防ぐと腕を失う。
- 解いてすぐ構え直すと、すぐ防いでもパリィにならない。時間を空けて構え直すとパリィになる。

## 確かめること（ゲームで）

- LOCAL VS か2つ起動のオンラインで、GAME のルール：ガードで攻撃が効かず、受けた手が素手になること。タイミングを合わせると腕が残ること。
- 後ろからの攻撃は防げないこと。触手の掴みが防げること。
- DEBUG のルール：ガードしても腕が壊れないこと。素手の手では構えられないこと。
- ガードしていないときの腕の単押し・長押し・使用回数・崩壊が今までどおりなこと。
- オンラインで DESYNC が出ないこと（2つ起動）。試せなければ PR に「未確認」と書く。

## 実装したこと（2026-11-12、Codex）

- `ArmManager` と左右の `ParryCalc` にガードを追加。構え始めの0.2秒はパリィ、解いてから0.5秒未満の構え直しではパリィを受け付けない。
- 前の左右80°・歩く速さ0.5倍。構え中の手の攻撃入力は空にし、押したままの入力は離すまで持ち越さない。両手では後から構えた手で受ける。
- 通常ガードで GAME の腕を素手にし、DEBUG は残す。肩の前に球を描き、受付中は明るくする。パリィ・崩壊の振動を追加。
- Debug / Release ビルド警告0、テスト各343件通過。受付時間と構え直しの待ち時間をまとめて壊すと2件が失敗し、復元後2件通過。
