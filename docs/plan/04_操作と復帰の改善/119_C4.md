## 決まっていること（管理者、2026-11-12）

- 投げた C4 は、**着弾ですぐ爆発**する。
- **長押しで、大きめの爆弾を放り投げる。**
- 使用回数は、敵に当たったときだけでなく、**爆発が起きたら減る**。

## 今の作り（読んで確かめた所）

- `src/game/arm_c4.cpp`：長押しで投げて設置、単押しで設置済みを全部起爆。爆発は半径 3・＋15%・強さ 2.4。回数は相手に効いたときだけ減る。
- `src/physics/c4calc.h / .cpp`（`C4Calc`）：投げた弾・相手に当たって落ちている弾・設置済み（3つまで）を管理する。
  弾そのものは `ProjectileCalc`（`src/physics/projectilecalc.h`）。
- 爆発は `Arm::Explode`（自分には当たらない）。範囲の見せ方は `DrawRangeRing`。

## やること

### 1. 単押し：投げて、着弾ですぐ爆発

- 押したらすぐ投げる（狙いは今の `ThrowBomb` と同じ：ロックオン中の相手が届く所にいれば足元へ、いなければ前へいちばん遠くまで）。
- 弾が相手か足場に当たった瞬間、その場所で爆発する。はじめの値は今の爆発と同じ（半径 3.0・＋15%・強さ 2.4・上向き 0.8）。
- 投げたあとの構えは 0.3 秒（今の値）。前の弾が飛んでいても次を投げられる（弾は `ProjectileCalc` の上限まで）。

### 2. 長押し：大きい爆弾を放り投げる

- 長押しが始まったら、ため 0.5 秒 → 大きい爆弾を山なりに放り投げる。着弾ですぐ爆発する。
- はじめの値：半径 5.0・＋22%・強さ 3.2・上向き 1.0。弾は遅く（水平の速さ 8）、届く距離は 8。見た目は今の C4 のモデルを 1.8 倍で描く。
- ためている間は歩く速さ 0.5 倍。

### 3. 設置と起爆をなくす

- 設置済み・相手に当たって落ちる弾・`Detonate` と `C4_MAX` は使わなくなるので消す。
  `C4Calc` は「投げた弾を進め、このフレームに着弾した場所と大きさ（小・大）を返す」ものに作り直す。
- 足場にも相手にも当たらず場外の下の線まで落ちた弾は、爆発せずに消える。

### 4. 使用回数（GAME）

- **爆発が起きたら1回減る**（相手に当たらなくても減る。小さい爆弾も大きい爆弾も1回分）。場外へ落ちて爆発しなかった弾は減らない。
- 今の `ARM_MAX_USES` の C4 は 2 回（`arm.cpp`）。`arm.cpp` は No.118 が受け持つので**変えない**。
  少なすぎると感じたら、PR に「回数を〇にしたい」と書く（管理者が直す）。
- 回数を使い切っても、飛んでいる弾が爆発し終わるまで腕が壊れないよう、`IsBusy()` は弾が飛んでいる間と範囲を見せている間 true のままにする。

## テスト（主な動きだけ）

`c4calc_test.cpp` を作り直す（設置・起爆のテストは消す）：

- 投げた弾が足場に当たると、そのフレームに着弾の場所が返り、弾が消える。

- 足場にも相手にも当たらず落ちた弾は、着弾を返さずに消える。
- 小さい爆弾と大きい爆弾が、着弾のときに区別して返る。

## 確かめること（ゲームで）

- DEBUG：単押しで投げて、ダミーの足元で爆発して吹っ飛ぶこと。外しても足場で爆発すること。長押しで大きい爆弾が出て、範囲が広いこと。
- GAME：爆発のたびに回数が減り、使い切ると（最後の爆発のあとで）腕が壊れること。場外へ投げて爆発しなかったときは減らないこと。
- 左右どちらの手でも同じに動くこと。2つ起動のオンラインで DESYNC が出ないこと（試せなければ PR に「未確認」と書く）。

## 実装したこと（2026-11-12、Codex）

- 設置・手動起爆・相手に当たって落ちる弾を廃止。`C4Calc` は通常と大型の弾を合計16発まで持ち、相手か足場に当たったフレームの位置と大きさを返す。
- 単押しは通常弾、長押しは0.5秒ためて大型弾。半径・威力・速度・見た目の倍率はプランの初期値どおり。大型をためている間は歩く速さ0.5倍。
- 爆発ごとに1回消費し、場外へ落ちて爆発しなければ消費しない。弾の飛行中と爆発の表示中は崩壊を待つ。`arm.cpp` と `projectilecalc.*` は変更していない。
