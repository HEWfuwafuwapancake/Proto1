# No.120 ガンランスの単押しの弾で、当たった相手を硬直させない

- ブランチ：`gunlance-shot`
- 先に読む：[00_全体と進め方.md](00_全体と進め方.md)

## 今の作り（読んで確かめた所）

- 弾が当たると `GunlanceArm::StepShots`（`src/game/arm_gunlance.cpp`）が `FighterManager::Launch(…, SHOT_DAMAGE, SHOT_POWER)` を呼ぶ。
- `Fighter::Launch` → `SetLaunchVelocity` が相手を「吹っ飛ばされている状態」（`m_Launched`）にし、`m_FlinchFrames = FLINCH_FRAMES` で
  相手が出していた腕を中断させる。地面ですべっている間は歩けず、0.25 秒ごとに撃たれると腕がずっと使えない。これが「硬直」。

## やること

- 単押しの弾が当たったら、**ダメージ%を足すだけ**にする（吹っ飛ばない・腕も中断しない・押しもしない）。
  - `StepShots` の `Launch` を `FighterManager::AddDamage(target, GetSlot(), SHOT_DAMAGE)` に変える。
  - 効いたときだけ振動させたいので、`FighterManager::AddDamage` の戻り値を `void` → `bool`（効いたら true。`CanAttack` が false なら false）にする。
    呼んでいるほかの所は戻り値を使わなくてよい。ヘッダーのコメントに `@return` を足す。
  - 使わなくなる `SHOT_POWER`・`SHOT_UP` は消す。
- 長押し（突進 → 突き刺し → 撃ち込み → 最後の1発で吹っ飛ばす）は変えない。
- ガードされた弾は今までどおり効かない（`CanAttack` の中でガードの記録も残る）。
