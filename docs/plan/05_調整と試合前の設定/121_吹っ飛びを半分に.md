# No.121 吹っ飛びを今の半分くらいにする

- ブランチ：`knockback-half`
- 先に読む：[00_全体と進め方.md](00_全体と進め方.md)

## 今の作り

- 吹っ飛ぶ速さ ＝（`BaseSpeed` ＋ % × `Growth`）× 攻撃の強さ（`KnockbackCalcSpeed`、`src/physics/knockbackcalc.cpp`）。
- 値は `src/game/fighter.cpp` の `KNOCKBACK_BASE_SPEED = 4.0f`・`KNOCKBACK_GROWTH = 0.12f`。50% で 10、100% で 16（強さ 1 のとき）。
  管理者によると「50% くらいでだいぶ吹っ飛ぶ」。

## やること

- `KNOCKBACK_GROWTH` を `0.12f` → `0.06f` にする（コメントに「100% で今までの 50% と同じ速さ（2026-11-12、管理者）」と書く）。

| % | 今まで | 変更後 |
|---|---|---|
| 0 | 4 | 4 |
| 50 | 10 | 7 |
| 100 | 16 | 10 |
| 200 | 28 | 16 |

- 計算の式は変えない。`BaseSpeed` も変えない。

## 触るファイル

- `src/game/fighter.cpp`（「調整用の値」の1行）
- `docs/plan/03_新しいアームの仕様.md` に吹っ飛びの式と値を1行で書く（表の上の箇条書きに足す）

## テスト

`knockbackcalc_test.cpp` はテストの中で自分の値を使っているので変えない。既存のテストが通ること。

## 管理者が遊んで確かめること

- 50% あたりで吹っ飛びすぎず、100% を超えると場外まで飛ぶ感じになっているか。

## 実装したこと

- `KNOCKBACK_GROWTH` を 0.06 に変更した。基本速度4.0と計算式は維持し、100%で以前の50%と同じ速度になる。
- 腕の仕様書に、現在の吹っ飛びの式と値を記載した。
