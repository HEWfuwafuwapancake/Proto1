# No.122 刀の長押し：飛んでいる途中も通り道の敵に当てる

- ブランチ：`katana-dash-hit`
- 先に読む：[00_全体と進め方.md](00_全体と進め方.md)

## 今の作り（`src/game/arm_katana.cpp`）

- 長押し：構え（`BREACH_AIM`）→ 離すと空間を斬る（`BREACH_CUT`）→ `StartDash` で着地点へ一直線に飛ぶ（`BREACH_DASH`）→
  着いた瞬間に `IaiTargets` で居合の一閃（前の扇。ダメージは `IAI_DELAY_SECONDS` あとに `StepDelayedHits` で入る）→ `BREACH_RECOVER`。
- 飛んでいる間（`BREACH_DASH`）は、`StepBreach` の中で `GrappleCalcPull` で体を動かすだけで、当たりは調べていない。
- `m_Hits`（`HitRecord`）は1回の斬撃・一閃で当てた相手を覚える。着いたときに `m_Hits.Clear()` してから `IaiTargets` を呼んでいる。

## やること

- `BREACH_DASH` の間、毎フレーム「動く前の体の中心」から「動いたあとの体の中心」までのカプセル（半径 `DASH_HIT_RADIUS`）で、
  通り道の相手に当てる。体の中心は足元 ＋ `GetPlayer().GetHeight() * 0.5f`。
  - 当たりは `CollisionCapsuleCapsule(通り道, target.Body).Hit`。相手は `GetFighters().GetTarget(i, GetSlot())` で `Available` のものだけ。
  - 当たったら**すぐ** `GetFighters().Launch(i, GetSlot(), AreaCalcLaunchDirection(水平の m_Direction, DASH_UP), DASH_DAMAGE, DASH_POWER)`。
    水平の向きは `ArmCalcPitchDirection(m_Direction, 0.0f)`。
  - 斬撃の線を見せる：`m_SlashDirections[i]` に水平の向き、`m_SlashSeconds[i] = SLASH_SHOW_SECONDS`。振動は `HIT_RUMBLE_*`。
  - 1回の飛びで同じ相手には1回だけ。`StartDash` で `m_Hits.Clear()` し、通り道で当てた相手を `m_Hits.TryAdd(i)` で覚える。
  - **着いたときの `m_Hits.Clear()` を消す**。通り道で当てた相手には居合の一閃を重ねない（ほかの相手には今までどおり一閃が当たる）。
  - 使用回数は飛ぶときにもう減らしているので、通り道の当たりでは減らさない。
- 調整用の値（はじめの値）：`DASH_HIT_RADIUS = 0.9f`、`DASH_DAMAGE = 6.0f`、`DASH_POWER = 1.4f`、`DASH_UP = 0.6f`。
