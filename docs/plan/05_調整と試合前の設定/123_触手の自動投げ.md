# No.123 触手：つかんだら自動で投げる

- ブランチ：`tentacle-auto-throw`
- 先に読む：[00_全体と進め方.md](00_全体と進め方.md)

## 今の作り

- `TentacleCalc::Step`（`src/physics/tentaclecalc.cpp`）の `TENTACLE_HOLDING`：相手を手元（`holdPosition`）へ `ReturnSpeed` で引き寄せ、
  もう一度押す（`trigger`）と `event.Throw = true` で投げる。`HoldSeconds`（今 3.0 秒）たつと投げずに離す。
- `TentacleArm::Update`（`src/game/tentacle.cpp`）は `event.Released` を受けて `FighterManager::Release(…, event.Throw, cameraForward, THROW_DAMAGE, THROW_POWER)`。

## やること

- つかんでから `ThrowSeconds` たったら、**押さなくても投げる**。それより前にもう一度押したら、今までどおりすぐ投げる。
  - `TENTACLE_PARAMS`（`tentaclecalc.h`）の最後に `float ThrowSeconds = 0.0f; ///< つかんでから自動で投げるまでの秒数（0 以下なら自動で投げない）` を足す。
    最後に足すので、今の `{ … }` の初期化（テストも含む）はそのまま通る。
  - `TENTACLE_HOLDING` の判定を次の順にする：
    1. `trigger` → 投げる（今までどおり）
    2. `params.ThrowSeconds > 0` かつ `m_HoldTime >= params.ThrowSeconds` → 投げる（`event.Throw = true`）
    3. `m_HoldTime >= params.HoldSeconds` → 投げずに離す（今までどおり）
  - `tentacle.cpp` の `PARAMS` に `ThrowSeconds = 0.35f` を足す（引き寄せの 30/秒 で、最大の長さ 8 からでも手元に着く時間）。
    投げる向きは今までどおりそのときのカメラの正面（`cameraForward`）。
- 長押しの回転・足場へ飛ぶ動きは変えない。

## テスト（主な動きだけ）

`tentaclecalc_test.cpp` に1つ足す：

- `ThrowSeconds` を 0.35 にして、つかんだあと押さずに 0.35 秒進めると `Released` が相手の番号・`Throw` が true になる。
  その直前（0.3 秒）ではまだ離さない。

（既存のテストは計算を少し変えただけなので、壊して確かめるのは不要。通ることだけ確かめる）

## 管理者が遊んで確かめること

- 触手の単押しで、つかんでから押さなくても投げること。投げる向きがロックオンの向き（カメラの正面）になっていること。
- 掴まれた側の連打の脱出（No.117）が、投げられるまでの短い間でも壊れていないこと。
