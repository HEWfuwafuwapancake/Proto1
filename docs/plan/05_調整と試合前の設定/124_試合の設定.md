## 作るもの：`src/physics/tuningcalc.h / .cpp`（DirectX・Windows を使わない）

名前は `FighterManager::SetMatchSettings`（ルールと乱数の種）とぶつからないよう「Tuning」にする。

```cpp
/// @brief 試合の前にホストが決める項目
enum TUNING_ITEM : uint8_t
{
	TUNING_RUSH_DISTANCE, ///< 長押しの移動距離（倍率）
	TUNING_KNOCKBACK,     ///< 吹っ飛び力（倍率）
	TUNING_HAMMER_STUN,   ///< ハンマーの長押しのしびれの秒数
	TUNING_DAMAGE,        ///< ダメージ（倍率）
	TUNING_MAP_SIZE,      ///< マップの広さ（倍率）
	TUNING_CAPSULES,      ///< 腕カプセルの出現量（段）
	TUNING_ARM_USES,      ///< 腕の使用回数（倍率。いちばん上は無制限）
	TUNING_ITEM_COUNT,    ///< 項目数
};

/// @brief 試合の設定（項目ごとに「何段目か」だけを持つ。通信でもこの整数を送る）
struct MATCH_TUNING
{
	std::array<uint8_t, TUNING_ITEM_COUNT> Levels; ///< 項目ごとの段（0 から）
};
```

関数（すべて Doxygen の日本語コメント付き）：

| 関数 | 中身 |
|---|---|
| `MATCH_TUNING TuningCalcDefault()` | 全項目を「ふつう」の段にする |
| `int TuningCalcLevelCount(TUNING_ITEM item)` | 項目の段の数 |
| `int TuningCalcDefaultLevel(TUNING_ITEM item)` | 項目の「ふつう」の段 |
| `bool TuningCalcIsValid(const MATCH_TUNING& tuning)` | 全項目の段が範囲内なら true（通信で受け取った値を調べる） |
| `float TuningCalcValue(const MATCH_TUNING& tuning, TUNING_ITEM item)` | 今の段の値（倍率・秒。カプセルと使用回数は下の専用の関数を使う） |
| `int TuningCalcCapsuleCount(const MATCH_TUNING&)` | 最初に出すカプセルの数 |
| `float TuningCalcCapsuleSeconds(const MATCH_TUNING&)` | カプセルが1つ出る間隔の秒 |
| `bool TuningCalcIsUnlimitedUses(const MATCH_TUNING&)` | 使用回数が無制限の段なら true |
| `int TuningCalcArmUses(int baseUses, const MATCH_TUNING&)` | 腕の最大使用回数 ＝ 切り上げ（baseUses × 倍率）。baseUses が 0（素手）なら 0、それ以外は 1 以上 |

段の表（「調整用の値」に置く。★ がふつう＝今と同じ）：

| 項目 | 段 |
|---|---|
| 長押しの移動距離 | 0.5 / 0.75 / ★1.0 / 1.25 / 1.5 / 2.0 |
| 吹っ飛び力 | 0.5 / 0.75 / ★1.0 / 1.25 / 1.5 / 2.0 |
| ハンマーのしびれ（秒） | 0 / 0.5 / 0.8 / ★1.2 / 1.6 / 2.0 / 3.0 |

| 腕の使用回数 | 0.5 / ★1.0 / 1.5 / 2.0 / 無制限 |

## ゲームへの反映（値を使う所）

`Game` が `MATCH_TUNING m_Tuning`（はじめは `TuningCalcDefault()`）を持ち、`Game::GetTuning() const` で読む。
`Game::Restart` の中で、今のルール・種と一緒に各部品へ渡す（**`m_Fighters.Reset()` より前に**ステージの大きさを変える）。

| 項目 | 反映のしかた | 触るファイル |
|---|---|---|
| 長押しの移動距離 | ナックル `RUSH_SPEED`・ガンランス `RUSH_SPEED` に倍率をかける（時間は同じで、進む距離が変わる）。刀の `BREACH_RANGE`（狙える距離）にも倍率をかける | `arm_knuckle.cpp`、`arm_gunlance.cpp`、`arm_katana.cpp` |
| 吹っ飛び力 | `Fighter::Hit` と `Fighter::Launch` で求めた速さに倍率をかける（`Push` は変えない） | `fighter.h / .cpp` |
| ハンマーのしびれ | `WAVE_STUN_SECONDS` の代わりに設定の秒を使う。0 秒の段では `ApplyStatus` を呼ばない | `arm_hammer.cpp` |
| ダメージ | `Fighter::AddDamage` で足すダメージに倍率をかける（すべての攻撃・燃えるダメージがここを通る。`Heal` は変えない） | `fighter.h / .cpp` |
| マップの広さ | `Stage::SetSizeScale(float scale)` を足す：浮島の `HalfWidth / HalfDepth` と、高台の `CenterX / CenterZ` に倍率をかける（高台の大きさ・高さ・場外の線は変えない）。最初の立ち位置 `SPAWN_X / SPAWN_Z` と復活先 `ISLAND_RESPAWN_OFFSETS` にも同じ倍率をかける | `stage.h / .cpp`、`fightermanager.h / .cpp` |
| カプセルの出現量 | `ArmCapsuleCalc::SetAmount(int initialCount, double spawnSeconds)` を足し、メンバーで持つ（はじめは今の 8・1.5 なので、既存のテストはそのまま）。`ArmCapsule::Reset` の前に設定する | `capsulecalc.h / .cpp`、`armcapsule.h / .cpp` |
| 腕の使用回数 | `ArmManager::ResetForMatch(rule, tuning)` で設定を覚え、`ChangeType` の `m_Uses[hand].Reset(…)` に `TuningCalcArmUses(ARM_MAX_USES[next], tuning)` を使う。無制限の段では、DEBUG と同じく減らさず崩壊もしない（`m_Rule == GAME_RULE_DEBUG` を見ている所を「回数の制限がないか」を返す private 関数にまとめる。`GetRemainingUses` は -1） | `arm.h / .cpp` |

渡し方：

- `FighterManager::SetMatchSettings(rule, seed)` に `const MATCH_TUNING& tuning` を足し、各 `Fighter` に `SetTuningScales(float damage, float knockback)`（`Fighter` に private の `m_DamageScale`・`m_KnockbackScale`、はじめは 1）と、立ち位置の倍率を渡す。
- 腕は `ArmManager` が覚えた設定を `const MATCH_TUNING& ArmManager::GetTuning() const` で返し、`Arm` に `protected` の `const MATCH_TUNING& GetTuning() const`（`m_Links.Arms->GetTuning()`）を足して読む。
- 設定は試合の始まり（`Restart`。やり直しも含む）でだけ反映する。試合の途中では変わらない。

## テスト（`tuningcalc_test.cpp`。主な動きだけ）

- `TuningCalcDefault()` の値が今と同じ（倍率 1・しびれ 1.2 秒・カプセル 8 個と 1.5 秒・使用回数は元の回数）。
