# No.125 デバッグ用ウィンドウで試合の設定を変える（ホストだけ）

- ブランチ：`tuning-window`
- 先に読む：[00_全体と進め方.md](00_全体と進め方.md)、[124_試合の設定.md](124_試合の設定.md)

## 今の作り

- デバッグ用ウィンドウは `src/core/debugwindow.h / .cpp`。読み取り専用の `EDIT` が1つで、`main.cpp` の `RefreshTitle` が
  `DebugWindowSetText` で文字を入れる。Debug はいつも、Release は `--debugwindow` のときだけ作る。
- `core` は `game` も `physics` も知らない。値の受け渡しは `main.cpp`（`g_Game` を持つ）が行う。

## やること

### 1. デバッグ用ウィンドウ（`core`。ゲームの中身を知らない汎用の「選ぶ欄」）

- ウィンドウの上に今の文字の表示、下に「選ぶ欄」を並べる（ウィンドウの高さを 400 → 600 くらいに。`WM_SIZE` で並べ直す）。
- 1行 ＝ 左に名前（`STATIC`）、右に段を選ぶドロップダウン（`COMBOBOX`、`CBS_DROPDOWNLIST`）。最後に「ふつうに戻す」ボタン（`BUTTON`）。
  どれも user32 の標準のコントロールなので、ライブラリやリンクの追加はいらない。フォントは今と同じ `DEFAULT_GUI_FONT`。
- 足す関数（`debugwindow.h`。Doxygen の日本語コメント付き）：

| 関数 | 中身 |
|---|---|
| `void DebugWindowSetChoices(int row, const char* label, const char* const* options, int count)` | 行 `row` の名前と選べる文字を決める（起動時に1回。行は 0〜7） |
| `void DebugWindowSetSelection(int row, int index)` | 行の選んでいる段を表示する（ユーザーが選んだのと同じ値なら何もしない） |
| `bool DebugWindowTakeSelection(int row, int& index)` | 前に読んでからユーザーが選び直したら true と段を返す（「ふつうに戻す」は全部の行を「戻す」と知らせるため、別の関数で） |
| `bool DebugWindowTakeReset()` | 「ふつうに戻す」が押されたら true（読んだら消す） |
| `void DebugWindowSetChoicesEnabled(bool enabled)` | 選ぶ欄を使えるかを設定する（true：選べる、false：灰色で表示だけ） |

- 文字はゲームと同じマルチバイトで受け取り、今の `DebugWindowSetText` と同じ方法で Unicode にして入れる。
- 選び直しは `WM_COMMAND` の `CBN_SELCHANGE`、ボタンは `BN_CLICKED` で受け、静的な配列に「変わった」印を立てる。
- ウィンドウを作っていないとき（Release で `--debugwindow` なし）は、どの関数も何もしない・false を返す。

### 2. `Game`（ホストだけが変えられる）

- `void Game::SetTuning(const MATCH_TUNING& tuning)`：変えてよいときだけ `m_Tuning` を変える（範囲外は `TuningCalcIsValid` で無視）。
- `bool Game::CanEditTuning() const`：次のどちらかなら true。
  - オンラインでない（SOLO・LOCAL VS・モード選択の前も含む）
  - オンラインのホストで、試合中でない（`m_Scene` が `SCENE_MATCH` でない）
  - オンラインの参加側は常に false。
- オフラインでは試合中に変えてもよいが、効くのは次の試合の始まり（やり直しを含む）から（No.124 のとおり `Restart` で反映）。

### 3. `main.cpp`（つなぐ所）

- 起動時（`DebugWindowInitialize` のあと）に、7行の名前と段の文字を `DebugWindowSetChoices` で入れる。
  名前と文字は `main.cpp` の上の表に置く（`TuningCalcValue` などの値から作る。例：「長押しの移動距離」→「50%」…「200%」、
  「ハンマーのしびれ」→「0秒」…「3.0秒」、「カプセルの出現量」→「少ない」「ふつう」「多い」「とても多い」、「腕の使用回数」の最後は「無制限」）。
- 毎フレーム（`g_Game.Update()` の前）：
  1. `DebugWindowSetChoicesEnabled(g_Game.CanEditTuning())`（変わったときだけ呼べばよい）
  2. 変えてよいなら、`DebugWindowTakeReset()` → `TuningCalcDefault()`、`DebugWindowTakeSelection` → その段を `MATCH_TUNING` にまとめて `g_Game.SetTuning`
  3. いつも `g_Game.GetTuning()` の段を `DebugWindowSetSelection` で表示する（参加側はホストの値が出る。No.126 で配られる）

## テスト

計算のファイルは変えないので、テストは足さない。既存のテストが通ること。

## 管理者が遊んで確かめること

- Debug の exe で、デバッグ用ウィンドウの7項目を変えてから試合を始めると、それぞれ効くこと：
  ナックル・ガンランスの突進と刀のワープの距離、吹っ飛び、ハンマーの長押しのしびれ、ダメージ%、浮島と高台の広さ、
  GAME のカプセルの数と出る速さ、GAME の腕の使用回数（無制限で減らない）。
- 「ふつうに戻す」で全部ふつうに戻ること。オフラインで試合中に変えると、次の試合（やり直し）から効くこと。

## 実装したこと

- デバッグ用ウィンドウを高さ600にし、名前とドロップダウン7行・ふつうに戻すボタンを追加。サイズ変更でも並べ直す。
- `main.cpp` が段の表示文字を計算し、毎フレーム通知と設定を受け渡す。`Game` は編集権限と段の範囲を確認して保持する。
- 編集不可の間の古い通知は読み捨て、権限が戻ったあとに誤って反映しない。
