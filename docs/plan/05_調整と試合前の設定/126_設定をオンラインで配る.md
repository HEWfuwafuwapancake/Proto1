# No.126 オンラインでホストの設定を配る

- ブランチ：`tuning-online`
- 先に読む：[00_全体と進め方.md](00_全体と進め方.md)、[124_試合の設定.md](124_試合の設定.md)、[125_デバッグ用ウィンドウで設定.md](125_デバッグ用ウィンドウで設定.md)

## 今の作り（`src/net/sessioncalc.h / .cpp`）

- ホストは `SESSION_STATE` で顔ぶれ・`Rule`（1バイト）・`Seed`（4バイト）を配っている（`SESSION_RULE_BYTES` = 5）。
  参加側は STATE を受けると `m_Rule = message.Rule; m_Seed = message.Seed;`。
- `Game::GetRule()` は、オンラインなら `m_Net.GetRule()`、オフラインなら `m_Scene.GetRule()`。
- 通信の版は `LOCKSTEP_VERSION`（`src/net/lockstepcalc.h`、今は 8）。版が違う相手とはつながない。

## やること

- `SESSION_MESSAGE` に `MATCH_TUNING Tuning = TuningCalcDefault();`（STATE でホストが配る試合の設定）を足す。
- STATE の中身の後ろに、項目ごとの段を1バイトずつ（7バイト）足す。`SESSION_RULE_BYTES` を 5 → 12 にする
  （名前が合わなくなるので `SESSION_STATE_BYTES` などに変えてもよい）。`Decode` で `TuningCalcIsValid` が false なら読まない（false を返す）。
- `LOCKSTEP_VERSION` を 8 → 9 にする（古い exe とはつながない）。
- `SessionCalc`：
  - `m_Tuning`（はじめは `TuningCalcDefault()`）と `const MATCH_TUNING& GetTuning() const` を足す。
  - `void SetTuning(const MATCH_TUNING& tuning)`：**ホストで、試合中（`m_Running`）でないときだけ**変える。参加側では何もしない。
  - ホストは STATE を作るとき `message.Tuning = m_Tuning`、参加側は STATE を受けたとき `m_Tuning = message.Tuning`（Rule・Seed と同じ所）。
- `NetSession`（`src/game/netsession.h / .cpp`）に `GetTuning()`・`SetTuning()` を足して `m_Calc` へ渡す。
- `Game`：
  - `Game::GetTuning()` は、オンラインなら `m_Net.GetTuning()`、オフラインなら `m_Tuning`（`GetRule()` と同じ形）。
  - `Game::SetTuning()` は、オンラインのホストなら `m_Net.SetTuning()`、オフラインなら `m_Tuning` を変える（`CanEditTuning()` が false なら何もしない）。
  - ホストを開いたときは、その前にオフラインで決めていた `m_Tuning` を `m_Net.SetTuning()` で引き継ぐ。
- 試合の始まり（`Restart`）は全員が同じ STATE の値を使うので、設定がずれて DESYNC することはない
  （試合中はホストも変えられないため）。

## テスト（`sessioncalc_test.cpp`。主な動きだけ）

- ホストで `SetTuning` した値が、STATE を `Encode` → `Decode` して参加側の `GetTuning()` に同じ段で届く。
- 試合中（running）のホストの `SetTuning` は無視される。
- 範囲外の段が入った STATE は `Decode` が false。

（既存の計算に足しただけなので、壊して確かめるのは不要。既存の STATE の大きさを見ているテストがあれば、新しい大きさに直す）

## 管理者が遊んで確かめること

- 2つ起動（HOST と JOIN）で、ホストのデバッグ用ウィンドウで設定を変えると、参加側のデバッグ用ウィンドウにも同じ値が出て、灰色で変えられないこと。
- そのまま試合を始めて DESYNC が出ないこと。試合中はホストも変えられないこと。
