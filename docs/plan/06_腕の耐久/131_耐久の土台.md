# No.131 耐久の土台：使用回数を耐久100に置き換える

- ブランチ：`arm-durability`
- 先に読む：[00_全体と進め方.md](00_全体と進め方.md)（減る値の表と決めたこと）

## 今の作り

- `src/game/arm.cpp` の `ARM_MAX_USES`（触手3・ハンマー2・ナックル3・C4 2・ガンランス8・刀3）を、装備したとき
  `m_Uses[hand].Reset(TuningCalcArmUses(...))` で入れる。`ArmUseCalc`（`src/physics/armusecalc`）は残りの数を持つだけ。
- 各腕は `Arm::ConsumeUse(count)` で「このフレームで使った数」を足し、`ArmManager::Update` が `m_Uses[hand].Consume(arm.m_Used)` で減らす。
  残りが 0 になると `BreakExhaustedArm` が、動作が終わったあとで素手に戻す。残りが 0 の手は新しい入力を受けない（つかみ中だけ例外）。
- 今は**当たったときだけ**減る腕が多い（`m_UseConsumed`・`m_SpinConsumed`・`m_IaiConsumed` で1動作1回にしている）。
  例外：ハンマーの空中の跳ねとナックルの空中の突進は当たらなくても1回、刀の長押しは飛んだときに1回、C4 は爆発1回ごと、ガンランスは弾1発ごと。
- ガード：`ArmManager::UpdateGuards` で、パリィできずに防いだら（`PARRY_BREAK_ARM`）GAME ではその手を素手にする。
- DEBUG と、試合の設定の「無制限」の段では `HasUnlimitedUses()` が true で減らない（`GetRemainingUses` は -1）。

## やること

### 1. 入れ物を耐久にする

- `arm.cpp` の `ARM_MAX_USES` をやめ、`ARM_MAX_DURABILITY = 100`（素手は 0）にする。装備したら 100 を入れる。
- `ArmUseCalc` はそのまま使う（`Reset(100)`・`Consume(減る量)`・`IsExhausted()` が 0 で true）。
  コメントを「残り使用回数」→「残り耐久」に直す。クラス名・ファイル名は変えない。
- `Arm::ConsumeUse(int count)` を `Arm::ConsumeDurability(int cost)` に置き換える。中で `TuningCalcDurabilityCost(cost, GetTuning())` をかけてから
  `m_Used` に足す（無制限・DEBUG では足さない。今の `GetRemainingUses() >= 0` の判定と同じ）。
- `GetRemainingUses` は `GetDurability` に名前を変える（`Arm` と `ArmManager` の両方。DEBUG・無制限は -1、範囲外は 0 のまま）。
  呼んでいる所（`hud.cpp`・`game.cpp`・各腕）も合わせる。

### 2. 試合の設定（`src/physics/tuningcalc`）

- `TuningCalcArmUses` を `TuningCalcDurabilityCost(int baseCost, const MATCH_TUNING& tuning)` に置き換える：
  `baseCost <= 0` なら 0、それ以外は `ceil(baseCost ÷ 倍率)` で最低 1（無制限の段は元の値。呼ぶ側で減らさない）。
- `USE_VALUES` などの段の並び・数は変えない（通信で送るのは段の番号だけ）。`TUNING_ARM_USES` のコメントを「腕の耐久の持ちの倍率」にする。
- `src/core/main.cpp` の `TUNING_LABELS` の「腕の使用回数」を「腕の耐久の持ち」にする。
- `tests/Proto1Tests/tuningcalc_test.cpp` の使用回数のテストを、減る量のテストに置き換える
  （例：×1 で 34 → 34、×2 で 34 → 17、×0.5 で 15 → 30、×1.5 で 5 → 4、無制限の段の判定）。

### 3. 腕ごとの減り方（値は 00 の表。各腕の .cpp の「調整用の値」に置く）

共通の作り：動作の始めに「この動作で減らしたか」の印を下ろし、当たった瞬間に「当たり」の値を減らして印を立てる。
動作が終わる（待機に戻る・`Interrupt` で中断される）ときに印が立っていなければ「外れ」の値を減らす。
吹っ飛ばされて中断したときも外れとして減らす（使ったら減る）。

- **触手**（`tentacle.cpp`）
  - 単押し：相手をつかんだ（`Grab` 成功）か、足場に付いた（`event.Anchored`）ら 34。何もつかめずに戻ったら 15。
    つかんだあとの投げでは減らさない。
  - 長押しの回転：1人でも当たったら 50、誰にも当たらずに回り終えたら 25。
- **ハンマー**（`arm_hammer.cpp`）
  - 地上の単押し：当たったら 50、外れたら 25。
  - 空中の単押し（跳ね）：振った瞬間に 50（当たっても重ねない。今の `m_UseConsumed` の流れ）。
  - 長押しの衝撃波：1人でも効いたら 50、誰にも効かなければ 30。
- **ナックル**（`arm_knuckle.cpp`）
  - 単押し：当たったら 34、外れたら 15。
  - 地上の長押し（突進）：当たったら 50、外れたら 25。
  - 空中の長押し（突進）：始めた瞬間に 50（当たっても重ねない。今の流れ）。
- **C4**（`arm_c4.cpp`）
  - 爆発1回ごと：`Explode` の `affected`（効いた相手の数）が 1 以上なら当たり、0 なら外れ。
    通常の爆弾は 34 / 15、大きい爆弾は 50 / 25。
  - 場外へ落ちて爆発せずに消えた爆弾は1つにつき 5。消えた数が今の `m_Bombs.Step` の戻り値で分からなければ、
    `src/physics/c4calc` の `Step` に「場外で消えた数」を返す引数を足す（既存のテストが通ればよい）。
- **ガンランス**（`arm_gunlance.cpp`）
  - 単押しの弾：撃つたびに 5（当たり外れで変えない。今と同じ場所）。
  - 長押し：相手を突き刺せた瞬間に 50。撃ち込みの3発（`StepImpale` の `ConsumeUse`）では減らさない。
    `m_Calc.StartImpale(GetRemainingUses())` で残りの数だけ撃っていたのをやめ、いつも最大の3発を撃つ（`gunlancecalc` の引数は残す場合、十分大きい値を渡す）。
  - 突進が誰にも刺さらずに終わったら 25。
- **刀**（`arm_katana.cpp`）
  - 単押しの斬撃：当たったら 34、外れたら 15。
  - 長押し：飛んだ瞬間に 40（今の `StartDash` 付近の `ConsumeUse`）。通り道か着地の一閃が1人でも当たったら、1回だけ 10 足す（合わせて 50）。

### 4. ガード（`arm.cpp` の `UpdateGuards`）

- パリィ（`PARRY_SUCCESS`）は減らない（今のまま）。
- パリィできずに防いだ（`PARRY_BREAK_ARM`）ら、素手にする代わりにその手の耐久を `GUARD_DURABILITY_COST = 50` 減らす
  （`TuningCalcDurabilityCost` を通す。DEBUG・無制限は減らない）。0 になったら今の振動を出して素手にする。
  `parrycalc.h` の `PARRY_BREAK_ARM` のコメントを「パリィできずに防ぎ、耐久が減る」に直す（名前は変えなくてよい）。

### 5. 画面と通信

- `hud.cpp`：腕の名前の横の残り回数を、耐久の数字（0〜100）と、その下の細いバー（幅 ＝ 耐久 ÷ 100）にする。
  DEBUG・無制限（-1）のときは今と同じく出さない。素手は出さない。
- `src/net/lockstepcalc.h`：`ArmUses` のコメントを「左右の残り耐久（無制限は -1）」にし、`LOCKSTEP_VERSION` を 9 → 10 にする。

## テスト

- `TuningCalcDurabilityCost` のテストを足し（上の例）、計算をわざと壊して落ちることを1回確かめて戻す。
- 腕ごとの減らし方は `src/game` の中なのでテストしない。既存のテストが全部通ること。

## 管理者が遊んで確かめること

- GAME（SOLO）で、各腕を当てたとき・外したときに、画面の耐久の数字が 00 の表のとおりに減る。0 になると動作のあとで素手になる。
- ハンマーの空中の跳ね・ナックルの空中の突進は2回で壊れ、刀の長押しは当たらなくても 40 減る。
- 耐久が 50 未満でも強攻撃が使える。ガンランスの突き刺しは耐久が少なくても3発撃ち込む。
- パリィできずにガードすると 50 減り、2回目で素手になる。パリィでは減らない。
- デバッグ用ウィンドウの「腕の耐久の持ち」×2 で減り方が半分になり、無制限で減らない。
