# No.132 パリィとガードを見て分かるようにする

- ブランチ：`parry-feedback`
- 先に読む：[00_全体と進め方.md](00_全体と進め方.md)
- 前提：No.131 がマージ済み

## 今の作り

- `src/game/arm.cpp` の `ArmManager::UpdateGuards` で、防いだ攻撃を `ParryCalc::OnHit` が `PARRY_SUCCESS`（パリィ）か
  `PARRY_BREAK_ARM`（パリィできずにガード。No.131 で耐久が 50 減る）に分ける。違いはパッドの振動だけで、画面では分からない。
- `ArmManager::Draw` は、構えている間だけ肩の前に小さな球（受付中は `PARRY_COLOR`、それ以外は `GUARD_COLOR`）を描く。

## やること（管理者が選んだ「光＋文字」）

- 防いだ瞬間に、結果と残り時間を `ArmManager` に覚える（`m_GuardFeedbackSeconds`・`m_GuardFeedbackParry`・光の位置）。
  `Reset` で消す。見た目だけなので、通信の確かめ（ハッシュ）には入れない。
- **光**（`ArmManager::Draw`）：防いだ手の肩の前（今の球と同じ位置）に、広がりながら薄くなる球を描く。
  - パリィ：黄色（`PARRY_FLASH_COLOR{ 1.0f, 0.9f, 0.2f, 1.0f }`）、半径 0.3 → 1.2、0.3 秒。
  - ガード：灰色（`GUARD_FLASH_COLOR{ 0.6f, 0.6f, 0.6f, 1.0f }`）、半径 0.3 → 0.8、0.3 秒。
  - 薄くするのは色のアルファ（`ShapeDrawSphere` が半透明を描けなければ、色を暗くしていく）。
- **文字**：そのプレイヤーの頭の上に「PARRY!」（黄色）か「GUARD」（灰色）を 0.6 秒出し、少しずつ上へ動かして消す。
  - `ArmManager` に読む関数を足す（例：`GUARD_FEEDBACK GetGuardFeedback() const`。表示中か・パリィか・経過の割合。構造体のメンバーは全部コメントする）。
  - 描くのは `hud.cpp`。頭の位置（足元 ＋ 背の高さ ＋ 0.4）を、その画面のカメラでスクリーン座標に写して描く。
    今の HUD にワールド → 画面の写し方がなければ、`Camera` のビュー・射影行列で写す小さな private 関数を `Hud` に足す。
    画面の後ろ側（カメラの後ろ）なら描かない。分割画面ではそれぞれの画面のカメラで写す。
  - 文字は今ある `Number2DDrawText`（「!」が無ければ足す）か、腕の名前と同じ `Text2D` の作り方を使う。
- 調整用の値（`arm.cpp` と `hud.cpp` の上）：光の色・半径・秒、文字の秒・大きさ・上へ動く量。
