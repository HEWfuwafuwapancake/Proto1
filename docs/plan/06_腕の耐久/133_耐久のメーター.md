# No.133 デバッグ用ウィンドウの耐久のメーター

- ブランチ：`durability-meter`
- 先に読む：[00_全体と進め方.md](00_全体と進め方.md)
- 前提：No.131・132 がマージ済み

## 今の作り

- デバッグ用ウィンドウ（`src/core/debugwindow`）には、試合の設定の選択欄（行0〜7）と「ふつうに戻す」ボタンがある。
  ゲームとの受け渡しは `src/core/main.cpp` が行う（`DebugWindowTakeSelection` で読み、`DebugWindowSetSelection` で見せる）。
- No.131 のあと、DEBUG では耐久が減らない（`GetDurability` が -1）。

## やること

### 1. デバッグ用ウィンドウにメーターを2つ足す（`core`）

- 選択欄の下に「1P 左手の耐久」「1P 右手の耐久」の行を足し、それぞれ横長のつまみ（`TRACKBAR_CLASS`。0〜100）と、今の数字を置く。
  Common Controls を使うので、必要なら `InitCommonControlsEx`（`ICC_BAR_CLASSES`）と `comctl32.lib` の追加を行う。
- 関数（Doxygen の日本語コメントを付ける）：
  - `void DebugWindowSetMeter(int hand, const char* armName, int value, bool enabled)`：
    今の腕の名前・耐久を見せる（ユーザーの変更通知は出さない）。`enabled` が false なら灰色で動かせない。
  - `bool DebugWindowTakeMeter(int hand, int& value)`：前に読んでからユーザーがつまみを動かしたら true と新しい値を返し、通知を消す。
- ユーザーがつまみを動かしている間は、ゲームからの `SetMeter` で位置を上書きしない（ドラッグ中に戻されないように）。

### 2. ゲームとつなぐ（`main.cpp`・`game`）

- 毎フレーム、1P（スロット0）の左右の腕の名前と耐久を `DebugWindowSetMeter` で見せる。
- `DebugWindowTakeMeter` で値が来たら、1P のその手の耐久をその値にする（`ArmManager::SetDurability(int hand, int value)` を足す。0〜100 に収める）。
  `Game` に1P の `ArmManager` へ渡す public 関数が要れば足す（`main.cpp` は `Game` を通すだけ）。
- 変えられるのは**オンラインでないとき**（SOLO・LOCAL VS・DEBUG）で、その手が素手でないときだけ。
  ONLINE 中と素手のときは `enabled = false`（表示だけ）。オンラインで変えると DESYNC するため。
- GAME で 0 にしたら、今の流れ（動作が終わったら素手）で壊れる。

### 3. DEBUG でも耐久を減らして見せる（`arm.cpp`）

- DEBUG（`GAME_RULE_DEBUG`）でも耐久を減らし、メーターと画面の数字に出す。ただし **0 になっても壊れず、0 のままでも使える**
  （今の「DEBUG は無制限」の遊びやすさを残す）。数字キー・十字キーで付け直すと 100 に戻る。
- 試合の設定の「無制限」の段は、今までどおり減らない（-1）。
- そのため、`HasUnlimitedUses()` を「減らない（無制限の段）」と「壊れない（DEBUG）」の2つに分ける
  （例：`IsDurabilityLocked()`・`CanBreak()`）。`GetDurability` は DEBUG でも実際の値を返し、無制限の段だけ -1 にする。
  ガードで 0 になっても、DEBUG では素手にしない。
- HUD は DEBUG でも耐久の数字とバーを出す（十字キーで選んでいる手の枠はそのまま）。

## テスト

`core` の画面と `game` の受け渡しだけで新しい計算はないので、テストは足さない。既存のテストが全部通ること。

## 管理者が遊んで確かめること

- DEBUG で攻撃すると、メーターと画面の耐久が減る。0 になっても腕が残って使える。
- メーターのつまみを動かすと、その手の耐久がすぐ変わる（ドラッグ中に勝手に戻らない）。
- GAME（SOLO）でつまみを 0 にすると、動作のあとで素手になる。素手の手のメーターは灰色。
- ONLINE 中はメーターが灰色で動かせない。
