## 分担と同時に進めるやり方

1. **Claude** が、タスクごとに「クリップの約束」（名前・ファイル・フレーム・長さ・ループ・どの状態で流すか）を書いて保存する。
2. 約束が決まったら、2人が**別のフォルダで同時に**作業する（触るファイルが重ならない）。
   - **Claude**：`Proto1` のフォルダで、Maya MCP でクリップを作り FBX に書き出す。触るのは `assets/models/`・`assets/models/source/`・`tools/maya/`・`docs/` だけ。
   - **Codex**：別のフォルダ（git worktree の `Proto1-codex`）の別ブランチで、コードとテストを書く。触るのは `src/`・`tests/`・`Proto1.vcxproj(.filters)` だけ。FBX がまだなくても、ファイルがないクリップは代わりのクリップで動く。
3. 両方が終わったら、Claude が Codex のブランチを自分のブランチにマージし、Release のビルド・テスト・わざと壊す確認・画面確認をして、1つの PR にする。
