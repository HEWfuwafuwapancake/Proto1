# No.138 やられのアニメ（のけぞり・吹っ飛び中・しびれ・つかまれ中）

攻撃を受けたときの体の動きを足す。今は吹っ飛び中・つかまれ中は「落下」、しびれは待機のまま震えるだけで、やられているのが分かりにくい。
描画だけの変更（当たり判定・通信・チェックサムは変えない）。

## クリップの約束（Claude が作る・Codex がコードで使う）

24fps。全身のクリップで、左右の手の区別はない。ルートは動かさず、その場で再生する形。

| SKINNED_CLIP の名前 | ファイル（`assets/models/`） | `.mb` のフレーム | 長さ | ループ | 動き | ファイルがないときの代わり |
|---|---|---|---|---|---|---|
| `HitFlinch` | `mekagirl_hit_flinch.fbx` | 3001〜3009 | 0.333 秒 | しない（最後の姿勢で止める） | 当たった瞬間に胸を後ろへ反らし、頭がのけぞり、両腕が前へ投げ出される | `Fall` |
| `HitLaunched` | `mekagirl_hit_launched.fbx` | 3101〜3113 | 0.5 秒 | する | 体を後ろへ丸めたまま、手足をばたつかせる | `Fall` |
| `HitStun` | `mekagirl_hit_stun.fbx` | 3201〜3225 | 1.0 秒 | する | 前かがみで膝を少し曲げ、腕をだらんと下げ、頭をゆっくり左右に揺らす | `Idle` |
| `HitHeld` | `mekagirl_hit_held.fbx` | 3301〜3317 | 0.667 秒 | する | 足をばたつかせ、両腕で振りほどこうともがく | `Fall` |

- ループするクリップは、最後のフレームを最初と同じ姿勢にする（今の走りなどと同じ）。
- 長さは作りながら少し変わるかもしれない。コードは長さを決め打ちせず、のけぞりを見せる秒数だけ `fighter.cpp` の「調整用の値」に置く。

## どの状態でどれを流すか（上が優先）

1. つかまれ中（`IsHeld()`）→ `HitHeld`
2. 吹っ飛ばされてから `FLINCH_ANIM_SECONDS`（0.33 秒）の間 → `HitFlinch`（再生位置＝吹っ飛ばされてからの秒。続けて当たったら頭から流し直す）
3. しびれ中（`STATUS_STUN`）→ `HitStun`
4. 吹っ飛び中（`m_Launched`）→ `HitLaunched`
5. どれでもない → 今までどおり（`MotionCalc` の走り・ジャンプなど）

- 「吹っ飛ばされた」は `Fighter::SetLaunchVelocity` が呼ばれたとき（`Hit`・`Launch`・`Push` が通る）。
- やられのクリップは全身（`request.Clip`）に流す。腕の攻撃クリップの重ね方（`Upper`・`Off`）は今のまま（吹っ飛び中も腕は使える）。
- のけぞりへ切り替えるときだけ、つなぐ秒数を短くする（`HIT_BLEND_SECONDS` 0.05 秒。ほかは今の `ANIMATION_BLEND_SECONDS`）。

## コードの変更（Codex）

| ファイル | 変えること |

| `src/render/animcalc.h` | `SKINNED_CLIP` の `GunlanceImpaleRight` と `Count` の間に4つを足す。**`AnimCalcIsAttackClip` は今 `< Count` なので、`<= GunlanceImpaleRight` に直す**（直さないと、やられのクリップが攻撃クリップ扱いになる） |

| `src/render/motioncalc.h / .cpp` | やられのクリップを選ぶ関数を足す（DirectX 不使用）。入力は「つかまれ中か・しびれ中か・吹っ飛び中か・吹っ飛ばされてからの秒・のけぞりの秒数」、出力は「使うか・クリップ・再生位置（ループは負）」。優先は上の表の順 |
| `src/game/character.cpp` | MEKAGIRL のクリップの表に4つのファイルを足す（MEKA は足さない＝代わりで動く） |
| `src/game/fighter.h / .cpp` | 吹っ飛ばされてからの秒（描画だけ。`SetLaunchVelocity` で 0 に戻し、`UpdateAnimation` で進める。リスポーンでは大きな値にする）を持ち、`UpdateAnimation` で上の関数を呼んで `request.Clip`・`request.ClipTime` を差し替える。調整用の値 `FLINCH_ANIM_SECONDS`・`HIT_BLEND_SECONDS` |
| `tests/Proto1Tests/motioncalc_test.cpp` | 主な動きだけのテストを足す：つかまれ中がほかより優先／当たってすぐはのけぞり（再生位置が経過秒）／しびれが吹っ飛び中より優先／どれでもなければ使わない |
| `docs/dev/01_DX11基盤の構成.md` | 「キャラのアニメ」の節に、やられのクリップと優先の順を足す |
