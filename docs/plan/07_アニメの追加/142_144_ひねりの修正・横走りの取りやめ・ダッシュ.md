## No.142 攻撃クリップの体のひねりを直す（左右が逆に見える）

**原因**：No.103 で作った攻撃クリップ9種類（`tools/maya/build_weapon_clips.py` の `CLIPS`・`LEFT_CLIPS`。刀の居合・アサルト、ハンマーの叩き・叩きつけ、ガンランスの射撃・突進・突き上げ、ナックルの殴り・突進）は、体と腰の左右の回転（`torso` と `hips` の2つ目の値）の符号が逆。
スクリプトの約束は「ry ＋：左へ回す」だが、値は「＋で右へ回す」つもりで書かれている。
Maya で測ると、右の殴りの当たる瞬間（`knuckle_punch_r` の 7 フレーム）に右肩が 2.8 下がり、左肩が 5.4 前に出ている。腕は右なのに体は左で殴る形になる。
No.138〜141 のクリップ（`build_reaction_clips.py`・`build_more_clips.py`）は正しい向きなので変えない。

**やること**
- `build_weapon_clips.py` の9種類×左右で、`torso` と `hips` の左右の回転の符号を反転する。攻撃していない腕の向き（`counter_arm`）は、反転後の値で正しく逆へ振れるか確かめる。
- ついでに No.138〜141 と同じくらいダイナミックにする（ためを深く、振る瞬間は `'lin'` で一気に、振り切ってから少し戻す）。**区切りのフレーム（各腕の `*_CLIP_SECONDS`）は変えない**ので、コードは変えない。
- Maya MCP で `mekagirl_motion.mb` に作り直し、`assets/models/mekagirl_atk_*_{l,r}.fbx` に書き出す（No.103 の9種類×左右＝18個）。
- 確認：右の殴りの当たる瞬間に右肩が前（左肩が後ろ）。左右とも代表のフレームを Maya で撮って見る。

- `src/render/animcalc.h`：`SKINNED_CLIP::StrafeLeft / StrafeRight` を消す。`src/render/skinnedmodel.cpp` の代わりのクリップの指定も消す。
- `src/game/character.cpp`：`mekagirl_strafe_l/r.fbx` の読み込みを消す。`src/game/fighter.cpp`：`STRAFE_ANGLE` を消す。

## No.144 ダッシュのアニメ

今はダッシュ専用のアニメがない。地面では走りのクリップを速く回し（ダッシュの速さ 18 ÷ 全速 6 ＝ 約3倍速）、空中では落下のまま。ダッシュは 0.2 秒で約 3.6 進む（`fighter.cpp` の `DASH_SPEED`・`DASH_SECONDS`）。

**クリップ**（24fps・全身・ループしない。左右の区別なし）

| SKINNED_CLIP | ファイル（`assets/models/`） | `.mb` のフレーム | 区切り（フレーム） | 動き |
|---|---|---|---|---|
| `Dash` | `mekagirl_dash.fbx` | 5601〜 | 飛び出し 2・進む 3・止まる 4 | 一瞬で低く沈んで前へ飛び出す。上半身は約40°前傾、両腕を後ろへ流し、前の脚の膝を突き出す。止まるときに軽く踏ん張る |
| `AirDash` | `mekagirl_air_dash.fbx` | 5701〜 | 飛び出し 2・進む 3・止まる 4 | 体を水平近くまで倒し、片腕を前、もう片腕と脚を後ろへ伸ばして矢のように飛ぶ |

- 進む区間（2〜5 フレーム）が `DASH_SECONDS`（0.2 秒）に合うよう、飛び出し 2・進む 3 で 5/24 ≒ 0.21 秒。止まる 4 フレームはダッシュが終わってから見せる。

**コード**
- `src/render/motioncalc.h / .cpp`：ダッシュの経過秒・地面か空中かを入力にして、クリップと再生位置を返す関数を足す（DirectX 不使用）。ダッシュ中と、終わってから止まる区間の間だけ使う。
- `MOTION_INPUT` にダッシュ中かとダッシュの向きを足し、ダッシュ中は脚（モデル全体）をダッシュの向きへすぐそろえる（真後ろへのダッシュも、前向きの姿勢でそちらへ向き直って飛ぶ）。
- `src/game/fighter.cpp`：ダッシュの経過秒を描画だけの値で持ち、やられのクリップより下・走りより上の優先でダッシュのクリップを流す。腕の攻撃クリップは今までどおり上に重ねる。調整用の値（止まる区間の秒数など）は「調整用の値」に置く。
- `src/render/animcalc.h`・`skinnedmodel.cpp`・`character.cpp`：クリップを2つ足す（ファイルがないときの代わりは `Run`・`Fall`。ループしない）。
- `tests/Proto1Tests/motioncalc_test.cpp`：主な動きだけ。地面のダッシュ中は `Dash`、空中は `AirDash`、脚がダッシュの向きにそろう、ダッシュが終わって止まる区間を過ぎると今までのクリップに戻る。

4. `tasks.md`・Notion・`handoff.md` を直し、PR を出す。

## 実装したこと（2026-11-13、Claude。PR #199）

- **No.142**：プランの「9種類×左右を全部反転」は、測ると半分ほどが逆になった（左手用の多くと、右手の刀のアサルト・ガンランス3種は、もとの向きが正しかった）。そこで「当たる瞬間に、攻撃する側の肩が前へ出る」を基準に、逆だった8本だけ反転した：右手の居合・ハンマーの叩き・叩きつけ・殴り・突進、左手のアサルト・叩きつけ・射撃。全18本で攻撃側の肩が前（+1.0〜+14.7cm）になったことを Maya で測った。動きは、最初と最後以外のキーの体の傾き・ひねりを 1.25 倍、沈み込みを 1.2 倍にした（区切りのフレームは同じ）。Maya MCP の画面撮影は T ポーズのまま更新されなかったので、確認は骨の位置の数値で行った。
- **No.143**：プランどおり。横走りのコード・テスト・FBX・`.mb` の 5001〜5199 のキーを消し、`MotionCalc` を No.141 の前の形に戻した（やられの関数は残す）。
- **No.144**：クリップは新しい `tools/maya/build_dash_clips.py`（地面の前傾は約39°、空中は約75°）。`MotionCalcDash` がダッシュを始めてから 9/24 秒の間だけ `Dash`／`AirDash` を選び、`MotionCalc` は脚をダッシュの向きへすぐそろえる（上半身は狙いへ上限 75° までねじる）。ジャンプや腕の突進でダッシュをやめたらクリップもやめる。吹っ飛び中のダッシュは、やられ（吹っ飛び中）のクリップを優先する。
- 確認：Debug / Release x64 警告0、`run-tests.ps1` 両構成 364 件通過。`MotionCalcDash` と脚の向きを壊して、足した3つのテストが落ちることを確かめて戻した。ゲームの画面は管理者が確かめる。
