# 腕ダフルアームズ　４人対戦マップ実装基準
2026-11-24 改訂案。対象は「ソラツギ中央郵便局」「汐跡市場の三本橋」。PDFの７～14ページにも同じ規定を収録する。数値は白箱（単純形状で対戦できる試作）の受け渡し基準で、管理者の採否確認前。試遊目標と、アートの最終素材の承認は別に扱う。

## 07 座標と地形判定
原点は両面とも中央。図の右が +X、上が +Z、高さが +Y。床面を引くときは次の順序を使う。

| 項目 | 実装時の規定 |
|---|---|
| 単位・倍率 | 1 u は現行ゲームの座標１単位。台帳は標準倍率。サイズ設定 s ∈ {0.7, 0.85, 1, 1.2, 1.5} のとき、地形照会は x = 世界X/s、z = 世界Z/s で行う。地点・区画の XZ も s 倍。Y、キャラ半径0.5、Ｇ受付半径２、速度と時間は固定。 |
| 地形の組み方 | 以下で a = abs(x)、b = abs(z)。各面の表を上から順に調べ、最初に一致した行の上面 H を使う。範囲の両端を含む。該当なしは空洞。中央市場の低い床の下や橋の下に、長方形の既定床を重ねない。 |
| 支持と落下 | 上面支持は足中心１点。下降中に前の足Y ≥ H ≥ 新しい足Y なら足Yを H にし接地。接地中は連続する坂面に追従。下り段差・床なしへ出れば元の高さから落下。Y < −15 で既存の場外処理を１回発火。 |
| 側面 | 高い側が実体の段差では、足が上縁より低い体の水平移動を半径0.5のカプセルで止め、残りを壁に沿わせる。上縁以上なら乗れる。坂の低い端と床の継ぎ目は連続。地盤の可視下面は Y = −6、側面の実体は下面から上面まで。 |
| 橋面と復帰 | 市場の地割れ上（a < 4）に張る３橋は上面のみの片面足場。下から上へ抜け、下降時に乗る。復帰用の腕は外周・穴に面した床の露出縁を従来の射程と照準で取る。床同士の継ぎ目は対象外。Ｇ入力は地上専用。 |
| 地形を参照する機能 | 着地・飛び道具の遮蔽・カメラの地形接触・CPUの足場照会に同じ輪郭と高さを渡す。実体の側面は遮蔽する。看板・窓枠・水面・雲・背景の街区は衝突、遮蔽、腕の吸着先から除く。 |
| 読み順 | 見た目と対戦の狙いは１～６ページ、座標・境界・動作は７～12ページ、受入例は13～14ページ。位置の検査は固定更新末尾、標準倍率で誤差 ±0.01 u。場外や起動の大小比較自体に許容幅を加えない。 |

## 08 ソラツギ中央郵便局の配置台帳
中央台 → 屋根 → 坂 → 基準床の順で解決する。ベルトは基準床にだけ効果を付ける。

| 対象 | 平面形・床高・効果 |
|---|---|
| 仕分け台 | a ≤ 8、b ≤ 8、a+b ≤ 14 の八角形。H = 1.2。上面と全周の垂直な側面を持つ。ベルトの終端で台に接したら止まり、台上へはジャンプする。 |
| 左右の集配棟 | 14 ≤ a ≤ 22、b ≤ 7。H = 6。西は X < 0、東は X > 0。屋根は全面歩行可、壁は四辺。坂と屋根が同じ高さで接する辺から歩いて出入りできる。棟内に入れる扉は置かない。 |
| 西と東の坂 | 西は −22 ≤ x ≤ −18、7 ≤ z ≤ 17。H = 0.6 × (17−z)。東は 18 ≤ x ≤ 22、−17 ≤ z ≤ −7。H = 0.6 × (17+z)。坂全幅で同じ高さ。 |
| 基準床と雲海 | a ≤ 26、b ≤ 26、a+b ≤ 46 なら H = 0。残りは空洞。屋上映像の縁取り、タイル目地、搬入口の枠には壁を付けない。 |
| ベルト２本 | 基準床かつ a ≤ 3、8 ≤ b ≤ 17。固定更新開始時に接地し、その回に跳ばない通常移動・待機・ガード中だけ、Z方向に −sign(z) × 3/60 u を水平移動へ加えてから壁解決。ダッシュ・吹っ飛び・Ｇ中は加算ゼロ。 |
| ＰとＧ | P1→P4 は (−12,+17),(+12,+17),(+12,−17),(−12,−17)。Ｇ番号も北西・北東・南東・南西の順。各象限の符号を保ち、始点 (±12,±10, 高さ0) から屋根 (±16,±5, 高さ6) へ。 |
| 腕カプセル | 区画中心 (±4,±3.5)、床高1.2。４区画とも３×３。候補点と抽選順は11ページで共通定義。屋根とベルトに補給点を追加しない。 |

## 09 汐跡市場の三本橋の配置台帳
橋と坂を置いてから、残った領域に岸の路面を張る。低い搬入橋を横切る Y = 0 の透明床がないことを確認する。

| 対象 | 平面形・床高・効果 |
|---|---|
| 低い搬入橋 | a ≤ 10、b ≤ 4。H = −3。地割れ上は幅８の橋、両岸の部分は掘り下げた荷道。b = 4 の線まで低い床に含む。 |
| 搬入橋の坂 | 10 ≤ a ≤ 16、b ≤ 4。H = (a−16)/2。a = 10 で −3、a = 16 で 0。坂と荷道から横へ出るときは高い路面の側壁に従う。 |
| ２本の高い橋 | a ≤ 4、10 ≤ b ≤ 14。H = 3。北（z > 0）が市電、南（z < 0）がシャッター。坂は 4 ≤ a ≤ 12、10 ≤ b ≤ 14、H = 3 × (12−a)/8。橋と坂の共有線 a = 4 は橋面扱い。 |
| 建物の基礎 | 氷蔵庫は −27 ≤ x ≤ −21、4 ≤ z ≤ 10。切符売場は 21 ≤ x ≤ 27、−10 ≤ z ≤ −4。両方 H = 1.2。平らな上面と四方の側壁を持つ。 |
| 路面と地割れ | 4 ≤ a ≤ 30、b ≤ 24 は H = 0。これまでの行に該当しない領域はすべて空洞。中央線 x = 0 上の開口は b > 14 または 4 < b < 10。外周にも受け皿を置かない。 |
| Ｐ・Ｇ・補給 | P1→P4 は (−17,+9),(+17,+9),(+17,−9),(−17,−9)。Ｇ番号も同じ象限順。始点 (±8,±7, 高さ0) → 同じ象限の橋面 (±3,±12, 高さ3)。補給区画中心 (±7,±2)、床高 −3。 |
| 南橋の空き缶 | 固定更新末、接地先が南の高い橋面に変わった瞬間に１回発火。徒歩・Ｇ着地・ジャンプ着地が対象。４人共通で１回鳴らし両端を60更新揺らす。更新 f で鳴れば次は f+120 から。同時進入は１回。居続ける間は再発火しない。 |

## 10 グラップルの入力と軌道
補助触腕は全員が使える。照準・カメラ方向・腕の装備から独立させ、60 Hz の対戦更新で同じ位置に着地させる。

| 段階 | 条件・遷移・優先順位 |
|---|---|
| 受付 | △／キーボード G の押した瞬間。進行中・基準床 H=0 に接地・始点との水平距離 ≤ 2・待機または通常歩行中・再使用可なら候補を探す。攻撃、硬直、拘束、ガード継続、ダッシュ中は失敗。復活無敵だけでは拒否しない。失敗入力を予約しない。 |
| 同時入力 | 同じ更新の新規行動は、有効なＧをジャンプ・ダッシュ・ガード開始・左右攻撃より優先。Ｇが成立しなければ通常入力をそのまま処理。以前からの状態と再使用時刻を先に確認。同時に申し込む人は P1→P4 の順に割り当てる。 |
| 着地点の選択 | 名目着地点 D の次に D+(d,0)、D+(0,+1.05)、D+(0,−1.05) の順に世界XZで試す。郵便局は d=1.05×sign(Dx)、市場は d=−1.05×sign(Dx)。目標面の縁から0.5以上内側で、他人の体・予約と重ならない最初の点を予約。 |
| 重なり | 着地する体の高さ区間 [H,H+1.8] と相手の体の高さ区間が内部で重なり、水平距離 < 1.0 なら占有。予約も同寸法。全候補が塞がれば不発、クールダウンを消費しない。起動後に入り込んだ人は着地時にもう一度調べる。 |
| 27更新の移動 | 受付直前の足元 S から、n=0 を出発サンプル、n=1 を受付した更新の末尾とする。n=1～9 は XZ=S、Y は S.y→H+0.6 を等速。n=10～24 は Y=H+0.6、XZ は S→予約点を15等分。n=25～27 は XZ固定、Y を H へ３等分して接地。 |
| 割込みと着地 | 移動中は入力による移動・攻撃・ガード・ベルト・体押しを停止。被弾・拘束が成立したらその位置で予約を解放して通常の被弾処理へ。無敵で無効の命中は継続。到着時に占有なら同じ表から再選択。全塞がりなら予約点の Y=H+1.8 から速度０で通常落下。 |
| 再使用と表示 | 更新 f で受理なら再使用は f+72 から。押し続けても再発しない。着地した次の更新から通常入力可。各人の画面で起動できるＧとその着地点を点灯し、失敗・中断・着地で予約を残さない。ポーズ・通信待ち中は更新数を進めない。 |

## 11 開始位置とカプセル抽選
４人の同時処理はプレイヤースロットの昇順。全端末で同じマップ・倍率・入力・シードを使い、同じ候補順で判定する。

| 項目 | 再現する規定 |
|---|---|
| 試合開始 | P1～P4を台帳の対応点に足Y=0で配置。初期の体と視線の水平正面は各点から原点へ。腕・％・得点は既存GAMEの開始処理。地形固有の予約、発音抑制、再使用時刻は試合ごとに初期化。 |
| 場外と復活 | 足Y < −15 で従来の得点処理。４人個人戦では最後に有効な攻撃を当てた相手に１点、自滅だけなら加点０。同点は同順位。復活待ち1.5秒、無敵２秒。復活の選択点はＰの４地点だけ。 |
| 安全な候補 | 現行 SpawnCalc::ChoosePoint に P1～P4 順で渡す。活動中の他人との最短３次元距離 ≥ 10 を安全とし、既存の試合シードで安全候補を抽選。全候補が危険なら最短距離が最大の候補、同値なら若い番号。同時復活は先に復活した人を含める。 |
| 補給の16地点 | 区画中心を北西・北東・南東・南西順に並べる。各中心に XZ オフセット (−1,+1),(+1,+1),(+1,−1),(−1,−1) を加える。両方を倍率 s で拡縮し、足場の H に置く。これで３×３の４区画に各４点、計16点。 |
| 抽選の順 | ArmCapsuleCalc の既存乱数を使う。新２面では空き地点を上記の順で列挙し、NextInt(空き数) で１点を選んでから既存 DrawType()。拾われた地点は再び空き。満杯の補充は何もせず乱数も進めない。位置と腕の種類は同じ試合シードで再現する。 |
| 個数と拾得 | 個数設定の少ない順に、初期数4/8/12/16、補充間隔3/1.5/1/0.6秒。標準は８個、以後1.5秒ごとに１個、同時上限16。拾得は既存の中心高0.7・半径0.65と腕の装着処理。同フレームで同じ物に触れれば若いスロットが取得。 |
| ホストと再戦 | GAMEのステージ候補は郵便局→市場。初期は郵便局、ロビーのルール内で主催側が選ぶ。DEBUGは従来の浮島。再戦は選択中の面、同期開始時はマップID・倍率・試合シードを全員で共有。演出用乱数を対戦用抽選に流用しない。 |

## 12 美術と音の受け渡し
簡易モデルでも戦闘中に読める輪郭とサインを共通化する。色は sRGB のベース色、寸法は標準倍率。

| 要素 | 必須の造形・表示 |
|---|---|
| 郵便局 | 床 #C7DACF、左右の集配棟 #77A69C、仕分け台 #E8ECC0。棟は同寸の直方体２棟、中央は八角形。棟の南北側に留め金を２個ずつ置く。南北のベルトには中央を向く山形を各３本。 |
| 市場 | 岸 #CBB799、低い荷道 #9CAB9C、南橋 #B37D5A。北橋は窓枠の見える市電１両の屋根、南橋は波板を継いだ板。氷蔵庫と切符売場は天井のない基礎。どちらの橋も欄干で移動や吹っ飛びを止めない。 |
| Ｇと補給 | 地上のＧ印は基準床に直径1.0の円。郵便局は金属の二重環、市場は白い結び目。点灯中は操作ボタンと着地点の菱形を同時表示。カプセルの◆とＰ番号は仕様図の記号。ゲーム内のカプセルは既存モデル、Ｐ番号はプレイヤー表示を使う。 |
| 縁と描画 | 郵便局の外周には橙色 #FFBA97 で幅0.20の帯。市場の岸と橋は落ちる側に幅0.15の欠けた白線。線は床と同じ高さの装飾。穴の真下に歩けそうな足場・道路を描かない。位置合わせは俯瞰図と８～９ページを基準にする。 |
| 缶と合図 | 南橋の両端 (−3.5,−12),(+3.5,−12) に缶を１組ずつ配置。発火後の経過 k=0～59 で傾きは 15°×(1−k/60)×sin(2πk/12)、終了で０。単発の金属音を橋中央から１回再生。無音でも２組の動きで横入りを判別できる。 |
| ４分割での確認 | ４人ローカルの各画面で、Ｇの受付中に始点と着地点の形を識別できること。屋根に立つ人物を地上側の入口から見通せること。窓枠や縁の帯に当たり判定がないこと。建造物の寸法は装飾の厚みで変えない。 |
| 最終素材の範囲 | ６ページの立体見本でシルエット、上表で色と必須部品を合わせる。テクスチャの傷、ロープの編み方、音色、照明、遠景の建物配置まで同一にする場合は、承認済みの同一モデル・画像・音源とシーン設定を配布する。現版の美術検収は上記の項目単位。 |

## 14 入力と４人同時処理の受入例
時間は対戦の固定更新で数える。フレーム番号・開始状態・押すボタンを指定し、４人ローカルと通信再生で比較する。

| 初期状態と操作 | 期待結果 |
|---|---|
| Ｇの距離と入力 | 郵便局の北西Ｇに対し (−12,12) で△を１回押すと成立。(−12,12.01) または空中では不成立。武器を両手に装備してロックオン中でも同じ。Ｇ＋ジャンプは有効範囲ならＧ、範囲外なら通常ジャンプ。 |
| 軌道の基準点 | 郵便局北西Ｇの中心から名目点へ。n=9 の足は X=−12,Z=10,Y=6.6。n=24 は X=−16,Z=5,Y=6.6。n=27 は同じXZで Y=6、接地。移動中に有効な被弾を入れると予約が消え、27更新目への強制移動は起きない。 |
