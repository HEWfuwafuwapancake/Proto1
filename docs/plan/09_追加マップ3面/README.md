# 追加マップ3面（ネオンビル群・コロシアム・廃駅）

別の人に頼んだマップ（2026-11-26 受け取り。元はブラキオンファイトのプロジェクト一式）を、Proto1 に入れたときの記録。
`01_〜03_*.txt` と `*.png` は届いた仕様書と画像そのまま。寸法・配置は仕様書のとおり（標準倍率 1.0。XZ はマップの広さの倍率を掛け、高さは変えない）。

## Proto1 での作り

| 部分 | 場所 |
|---|---|
| 見た目 | `assets/models/maps/neon.glb`・`coliseum.glb`・`coliseum_column.glb`・`station.glb`（届いた GLB から、使うノードだけを残したもの。コロシアムは柱1本を別ファイルにした） |
| 当たり判定・開始位置 | `src/physics/mapcalc.cpp` の台帳（仕様書の寸法をそのまま書いた） |
| 回した箱・円い床・片面の足場の下をくぐる | `src/physics/stagecalc.cpp`（`STAGE_REGION` の `Yaw`・`Radius`） |
| ジャンプ台・倒れる柱の当たり | `src/game/mapgimmick.cpp` |
| 柱の倒れ方 | `src/physics/pillarcalc.cpp` |
| 腕の攻撃を柱に当てる | `Arm::StrikePillars`（各腕の命中処理で、相手と同じ範囲の判定を使う） |

- GLB の頂点の色はライトを焼き込んだリニアの色なので、読み込むときに sRGB に直し、ライトを切って描く。
- 元のゲームは面の向きをそろえずに裏の面も描いていたので、景観はカリングを切って描く（`SetCullEnable`。切らないと床のモザイク・タイル・苔などが消える。No.205）。
- 霧は元のシェーダーと同じ：カメラから 65 離れると、マップごとの霧の色へ 0.55 だけ寄せる。ネオンは色を 0.55 乗した形のまま霧を掛け、中央に赤い光を足す（`stage.cpp` の `MAP_LOOKS`、シェーダーの b6 `FogBuffer`。No.205）。
- 元のゲームと変えたこと：
  - ホログラム・松明・舞う葉などの小さな動きは、GLB に入っている止まった形のまま描く。
  - 片面の足場（倒壊ビル・待合所の屋根）は Proto1 の橋と同じく、下から跳ぶと通り抜ける。
  - 柱は、耐久が減るほど色を暗くして傷みを見せる（ひびの線は描かない）。
  - 柱が倒れ始めたとき・倒れ終わったとき・人に当たったときの音は、今ある効果音（腕が壊れた音・ハンマーの音）を使う。
- 調整する値：柱の耐久・予兆・倒れる時間は `pillarcalc.cpp`、柱が当たったときのダメージ・吹っ飛び、ジャンプ台の高さは `mapgimmick.cpp` の「調整用の値」。
