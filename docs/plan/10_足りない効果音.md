# 足りない効果音の一覧

ゲームの中で**音が鳴ったほうがよいのに、まだ専用の効果音がない場所**をまとめた一覧です。
サウンド担当への依頼と、どの音から作るかを決めるのに使います。BGM はここには入れていません。

- 作った日：2026-11-27（No.207 のあと。メカガールの声を消したあとの状態）
- 今ある効果音は `assets/sounds/se/` と `src/audio/se.cpp` の `SE_TABLE`

---

## この一覧の読み方

**優先度**は3段階です。上から順に作ると、遊んだときの手ごたえが早く良くなります。

| 印 | 意味 | 目安 |
|---|---|---|
| ★★★ | **ないと手ごたえが弱い**。何が起きたか音で分かってほしいところ | 最初に作る |
| ★★ | **あると分かりやすい**。見れば分かるが、音があると気持ちいい | 次に作る |
| ★ | **仕上げ**。完成度を上げるための細かい音 | 最後に作る |

**置き場所**は、各章の見出しの下に書いた `assets/sounds/se/` の中のフォルダです（今のフォルダ分けに合わせています）。

---

## 素材を作るときのお願い

- 形式は **16bit PCM の WAV**（MP3 などはゲームでそのまま鳴らせません）。
- 同じ場面で何種類か鳴らし分けたいときは、名前の最後に `(1)` `(2)` … を付けてください。ゲームが鳴らすたびにランダムに1つ選びます。
- **ループする音**（燃えている・環境音など）は、つなぎ目で音が途切れないように作ってください。
- 戦闘の音は、聞く人からの距離で小さくなり、左右にも振り分けて鳴らします。**モノラル**で作ってもらえると左右の振り分けがきれいに効きます。
- 声（キャラのボイス）は今は使いません（No.207 で消しました）。

## 音が届いたら（プログラム側）

1. WAV を上の置き場所に入れる。
2. `src/audio/se.h` の `SE_ID` に名前を足し、`src/audio/se.cpp` の `SE_TABLE` に1行（ファイルと音量）足す。
3. 鳴らしたい場面で `SePlay` または `SePlayAt` を呼ぶ。
   詳しい足し方は [dev/01_DX11基盤の構成.md](../dev/01_DX11基盤の構成.md) の「効果音の足し方」にあります。
4. この一覧の、作った音の行を消す（全部そろったらファイルごと消す）。
