## 1. 共通の仕組み（最初に作る土台）

### 1-1. パーティクル（`src/game/effect.h / .cpp` の `EffectManager`、計算は `src/physics/particlecalc.h / .cpp`）

- 今の描画の部品（`ShapeDrawSphere` / `ShapeDrawBox`。半透明は今のブレンドで描ける。色のアルファで薄くする）で、小さな球・箱を飛ばす。テクスチャのビルボードは作らない（プロトタイプなので形だけで十分。足りなければあとで考える）。
- 1つの粒：位置・速さ・重力の効き・寿命・大きさ（始め → 終わり）・色（始め → 終わり）・形（球 / 箱）。
- 出し方は「**出し方の型**（`EFFECT_ID`）＋位置＋向き＋色」で呼ぶ。例：`EffectManager::Spawn(EFFECT_ARM_BREAK, pos, dir, color)`。型ごとの数・速さ・広がり・寿命は `effect.cpp` の「調整用の値」に表で書く（`se.cpp` の `SE_TABLE` と同じ形）。
- 同時に出す粒は**上限 512**（超えたら古い粒から消す）。1粒＝1回の描画なので、重くなったら数を減らす。
- **オンライン**：見た目だけなので、試合の乱数（`randomcalc`）は使わず、パーティクル専用の乱数を使う。通信の確かめ（ハッシュ）には入れない。
- 「光が広がって消える球」（No.132 のパリィの光）もこの仕組みの1つの型にまとめる。
- テスト（`particlecalc`）：粒が寿命で消える・重力で落ちる・上限を超えたら古い粒から消える、の3つだけ。

### 1-2. ヒットストップ（計算は `src/physics/hitstopcalc.h / .cpp`、使うのは `Fighter` と腕）

- 当たった瞬間に、当てた人と当てられた人の**動き・腕・吹っ飛びの開始を数フレーム止める**。止まっている間は、当てられた人の体を小さく震わせる（今ある `GetStunShake` と同じ考え）。
- 止める長さは**吹っ飛びの強さ（与えた %）で決める**：弱 3 フレーム／中 6／強 10／場外になる一撃 14（調整用の値）。
- 試合の動きが変わるので、**全員の PC で同じに計算する**（入力だけを送るロックステップのため）。フレーム数で数え、ハッシュに入れる。
- 試合の時計・ほかの人・カプセルは止めない。
- テスト（`hitstopcalc`）：強さからフレーム数が決まる・数え終わると動き出す、の2つだけ。

### 1-3. 画ぶれ（`src/game/camera.cpp`。計算は `src/physics/cameracalc` に足す）

- decisions.md の通り、**揺れは最後のカメラの位置に上乗せする**（追従のバネ（SmoothDamp）の計算には入れない）。
- 揺れの強さ（0〜1）を持ち、時間で減らす。揺れの形は決まった波（サインを数本重ねる）で作る（乱数を使わない）。
- 強さは足し算で重ね、上限 1。強さの目安：被弾 中 0.3／大 0.6／場外になる一撃 1.0／柱が倒れた 0.5。
- オプションに「画面の揺れ」（なし・弱・ふつう）を足すかは、遊んでから決める（今は作らない）。
- テスト（`cameracalc`）：時間で 0 に戻る・重ねても上限を超えない、の2つだけ。
