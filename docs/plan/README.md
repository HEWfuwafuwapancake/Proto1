# 企画書と仕様

Proto1（ブラキオンファイト。企画名は「腕ダフルアームズ」）の企画と、タスクごとの仕様をまとめたフォルダです。

## まず読むもの

| ファイル | 中身 |
|---|---|
| [01_企画の要点.md](01_企画の要点.md) | ゲームの概要・このプロトで確かめたいこと・やること／やらないこと・ルール。**実装するときはこれを基準にする** |
| [03_新しいアームの仕様.md](03_新しいアームの仕様.md) | 8種類の腕の操作と効き方。腕のプランを作るときに読む |
| [10_足りない効果音.md](10_足りない効果音.md) | まだ専用の効果音がない場所の一覧（場面ごと・優先度つき）。サウンド担当への依頼と、どの音から作るかを決めるときに読む |
| [企画書_腕ダフルアームズ.pptx](企画書_腕ダフルアームズ.pptx) | 元の企画書（草案・1枚） |
