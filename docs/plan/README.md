# 企画書

Proto1（腕ダフルアームズ）の企画に関する資料です。

| ファイル | 内容 |
|---|---|
| [01_企画の要点.md](01_企画の要点.md) | 企画の要点・このプロトで確かめたいこと・やること／やらないこと・ルール・操作方法。**実装するときはこれを基準にする** |
| [企画書_腕ダフルアームズ.pptx](企画書_腕ダフルアームズ.pptx) | 元の企画書（草案・1枚） |

- 企画の元ファイル（Word / PowerPoint / PDF など）はこのフォルダに入れる。50MB を超えるものは、管理者に相談して Git LFS の対象にする。
- 企画が変わったら、`01_企画の要点.md` と `docs/tasks.md` も合わせて直す。
