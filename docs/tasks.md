## 進め方

1. 1つのタスク ＝ 1つのフィーチャーブランチ ＝ 1つの PR。
2. **プラン → 管理者の確認 → 実装 → テスト → 完了チェック** の順に進める。
3. 新しいタスクは、この表に足してから始める。番号は続きの番号（今の最後は No.206）。
4. 終わったら状態を ✅ にして、[archive/tasks_done.md](archive/tasks_done.md) の「完了（新しい順）」の先頭へ移す。

状態：⬜ 未着手 / 🔄 進行中（実装は済んで、管理者や実機での確認を待っているものも含む）

優先度は ① 遊びの目的（ぶっ飛ばして点を取る）に直結するか、② ほかのタスクの前提になるか、③ 大きな設計変更や外部ライブラリが要らないか、で決める。
