# 操作一覧

ゲームの外で読む操作の一覧。コントローラーがなくても、キーボードだけで全部の操作ができる（マウスはなくてもよい）。
試合中に画面の右へ出す一覧は、オプションの「操作の表示」（オフ / キーボード / パッド）で選ぶ。

> キーを変えたら、`src/input/action.cpp` の `ACTION_KEYS`・`ACTION_PAD_BUTTONS`、`src/game/hud.cpp` の `CONTROL_GUIDE_LINES`、この表をそろえる。

## 試合中

| 行動 | キーボード | パッド |
|---|---|---|
| 移動 | W / A / S / D | 左スティック |
| カメラを回す | ↑ ↓ ← →（矢印キー） | 右スティック |
| ジャンプ | Space | × |
| ダッシュ | C | ○ |
| 左腕 | J または 左クリック | L1 |
| 右腕 | K または 右クリック | R1 |
| ガード（左 / 右） | Z / X | L2 / R2 |
| ロックオンの切り替え（ハード・ソフト・フリー） | F | R3 |
| 相手を替える（ハードロック中） | ← / → | 右スティックを左右に弾く |
| 腕を替える（DEBUG のルールだけ） | Q（左手）/ E（右手）を押してから数字キー 1〜0 | 十字キー |
| 試し打ち：相手（ダミー・CPU）の % を 100 → 150 → 50 → 0 と替える（オフラインだけ） | F5 | なし |
| 試し打ち：相手を 1P の目の前に横一列で呼ぶ（オフラインだけ） | F6 | なし |
| 試し打ち：CPU を止める・動かす（オフラインだけ） | F7 | なし |
| 試合中のメニュー（ポーズ） | R | OPTIONS |
| 振動のオン・オフ | V | SHARE |
| TIME UP から結果へ | Enter | ○ |

- 腕は単押しと長押し（ため）で効き方が変わる。腕ごとの効き方は [03_新しいアームの仕様.md](../plan/03_新しいアームの仕様.md)。
- ← → はハードロック中は相手の切り替え、ソフトロック・フリーではカメラの左右になる。
- キーボードだけで遊ぶときは、左手で W A S D・Space・C・Z・X・F、右手で J・K と矢印キーを使う。

## メニュー

| 行動 | キーボード | パッド |
|---|---|---|
| 選ぶ（カーソル） | ↑ ↓ / W S（左右は A D） | 左スティック |
| 中身を変える（キャラ・設定の値など） | ← → | 十字キーの左右 |
| 中身を上下で変える（CPU・ダミーの強さ、IP の数値） | Enter で順に回す（IP は数字キーで入力） | 十字キーの上下 |
| 決定 | Enter | ○ |
| 戻る | Backspace | × |
| 終了 / 全画面 | Esc / F11 | — |
